# 方案一：可拒绝的概念证据定位与选择性替换

## 1. 动机与中心问题

原方案将 target 与 safe anchor 做相对比较，然后编辑高分位置。相对比较在目标根本不存在时也会产生最大值。ConceptAttention 原文明确讨论了“目标不在图中仍选择最相似概念”的问题；这个现象用来画热图尚可理解，用来触发擦除则会直接改变正常内容。[ConceptAttention，§5.5](https://arxiv.org/html/2502.04320v2)

本方案的中心问题是：**能否在保持目标检出能力的同时，使无目标生成尽量不发生编辑，并把误触发与最终误伤分别测量？**

完整方法包含：只读概念证据定位、当前场景安全供体 patching，以及**以目标缺席样本校准的拒绝机制**。拒绝机制负责决定“是否应该编辑”，空间图负责决定“编辑哪里”。

## 2. 资源与符号

沿用 [共用符号](06_shared_algorithm_and_experiments.md)。目标 `e`、安全概念 `a` 和保留集合 `R` 固定。分别准备：

- `D_dev`：确定查询词、温度、层集合、区域阈值和池化规则的开发样本；
- `D_cal^0`：独立的无目标校准样本，包含模型原生生成过程的完整读出；
- `D_test`：目标、近邻保留和普通 prompt 的留出测试样本。

校准样本的“无目标”按实际生成内容核对，不能只因 prompt 没写目标词就自动标为无目标。可用人工或独立评估器在离线核对；部署过程中只使用模型自身读出。

## 3. 第一步：多对照的逐层概念证据

先按共用 C1–C3 计算各层概念输出和分数。为降低单纯二选一的强制分配，定义目标相对于安全和背景集合的对数优势：

\[
r_{n,\ell}(i)=s_{n,\ell,e}(i)
-\log\sum_{c\in\{a\}\cup R}\exp s_{n,\ell,c}(i).
\tag{1}
\]

使用 `D_dev` 的无目标部分，按噪声区间 `b(n)`、层分别计算中位数 `m_{b,ell}` 与稳健尺度 `v_{b,ell}>0`：

\[
z_{n,\ell}(i)=
\frac{r_{n,\ell}(i)-m_{b(n),\ell}}{v_{b(n),\ell}}.
\tag{2}
\]

尺度可取 IQR 加数值下限。这里标准化的是标量读出，不混合不同层的特征坐标。开发集固定这些参数后，不再用校准集重新调层或选词。

聚合：

\[
\bar z_n(i)=\sum_{\ell\in L_{loc}}\omega_\ell z_{n,\ell}(i),
\quad
q_n(i)=\sum_{\ell\in L_{loc}}\omega_\ell
\mathbf1[z_{n,\ell}(i)>\tau_{loc}].
\tag{3}
\]

基础版 `omega` 同权。`q_n` 是跨层一致性，不解释成独立投票的后验概率。

候选区域为：

\[
M_n^{region}(i)=
\mathbf1[\bar z_n(i)>\tau_z]\,
\mathbf1[q_n(i)>1/2].
\tag{4}
\]

若实验显示多数投票降低小目标召回，保留 `bar z` 阈值版作为同一方案的简化选项。不能通过强行保留 top 百分比区域来保证每张图都有编辑位置。

## 4. 第二步：校准是否有足够目标证据

为每个时间步构造图像级统计：

\[
R_n=\operatorname{TopKMean}_{i}\bar z_n(i),
\qquad k=\max(1,\lceil\kappa P\rceil).
\tag{5}
\]

`TopKMean` 对最大的 `k` 个读出求均值，既不完全依赖一个极端像素，也不让小目标被全图均值稀释。`kappa` 在开发集固定，并比较最大值、TopKMean 和区域面积统计。

为了控制完整采样过程中“至少误编辑一次”的情况，在每个无目标校准轨迹 `j` 上计算：

\[
A_j=\max_{n\in W}R_n^{(j)}.
\tag{6}
\]

设校准集有 `m` 条轨迹，给定误触发水平 `alpha`，取

\[
k_\alpha=\lceil(m+1)(1-\alpha)\rceil,
\quad Q_\alpha=A_{(k_\alpha)}.
\tag{7}
\]

当 `k_alpha>m` 时取 `Q_alpha=+infinity`；数据量不足以支持这个误触发水平，不能把最大观测值假装成更严格的阈值。

最终 gate 和掩码为：

\[
G_n=\mathbf1[R_n>Q_\alpha],
\qquad M_n(i)=G_n M_n^{region}(i).
\tag{8}
\]

### 这一校准具体能说明什么

在校准与测试无目标轨迹交换性、模型与采样设置相同、读出和全部超参数预先固定的条件下，秩论证给出：

\[
\Pr(\text{无目标轨迹至少触发一次编辑})\le\alpha.
\tag{9}
\]

理由是：第一次编辑前，部署轨迹仍与原生轨迹一致；第一次触发必然要求该原生轨迹的 `max R_n` 超过 `Q_alpha`。这是标准次序统计量校准性质，本方案将其用于首次误编辑控制，不把它作为新的统计理论。

式（9）不覆盖分布变化、其他模块预先编辑的轨迹或更换 query bank 后的读出。第一次编辑以后的轨迹也已改变，不能逐步套用原校准集来声称新的覆盖保证。实际跨域误触发仍需独立报告。

## 5. 第三步：上下文安全供体与末层替换

若 `M_n` 为空，直接使用 probe 的原 prediction。若非空，以当前 `x_n`、同一 `sigma_n` 和场景保持的 `p^-` 运行安全供体，取得最后编辑点的 `O^-`。

\[
O'_{n,\ell^*}(i)=O_{n,\ell^*}(i)
+\eta M_n(i)[O^-_{n,\ell^*}(i)-O_{n,\ell^*}(i)].
\tag{10}
\]

以 `eta` 的开发集固定值起步，比较硬替换和 blend；无需为了此方案再加入在线强度搜索。只重放最后编辑点之后的用户后缀，使用原 CFG 和 scheduler 更新一次 latent。

## 6. 完整算法

```text
开发：固定 query bank、L_loc、温度、稳健尺度、TopKMean 和区域参数
校准：在独立无目标原生轨迹上计算 A_j=max_n R_n，确定 Q_alpha
部署每步：
    user＋concept probe -> 各层 z -> bar_z、q、R_n
    如果 R_n <= Q_alpha：使用未编辑 prediction
    否则计算 M_n；为空时同样不编辑
    若非空，从当前 latent 获得 p^- 的安全供体 O^-
    在最后编辑点用固定 M_n 和 eta 执行式（10）
    重放用户后缀，以所得 prediction 更新一次 scheduler
```

多目标版为每个目标单独构造 pairwise 读出。若要控制“任一目标触发”的整体误触发，在式（6）对 `n` 和目标 `e` 同时取最大值；不能把每目标 `alpha` 直接当作整个系统的 `alpha`。原始分数经独立开发集标准化后再合并校准。

## 7. 开销与 UVR 的差别

与基础两分支方法相比，本方案新增的在线计算只是统计量与阈值判断。概念 probe 是定位本身的成本。空掩码跳过供体；非空时为 `一次 user probe＋一次 safe donor＋一次末层后缀`，详见共用成本公式。

离线需要额外无目标校准轨迹。不同 checkpoint、guidance、query bank 或大幅改变步数时重新校准。

UVR 以预收集视觉 anchors 和相似度阈值定位；这里使用在线文本概念对照，研究完整轨迹首次误编辑、空目标拒绝和保留近邻上的选择性。GLoCE 也有概念 gate，因此“加一个门控”不能单独作为新意。[UVR §4.1](https://arxiv.org/html/2606.06875)、[GLoCE §3.2](https://arxiv.org/html/2503.12356)

## 8. 能支撑贡献的实验

1. 固定 donor、patch 点和强度，比较二概念 softmax、加背景查询、只有标准化、完整首次误编辑校准。
2. 在相同目标召回／擦除率下，报告无目标误编辑率、近邻成功率和正常图像改变幅度。
3. 用多种 `alpha` 画实际首次误编辑率；同分布与跨模板／跨分辨率结果分别报告。
4. 比较软图平均和二值投票，检查小目标、局部属性和全局风格三类任务。
5. 校准阈值固定后再扩大目标数量，报告重新校准成本和整体误触发。

拟主张是“读出热图的相对优势不等于编辑证据；轨迹级拒绝能改善选择性”。若收益仅来自把阈值调高，且相同召回下普通阈值具有相同保留表现，则本方案只应保留为工程底座。
