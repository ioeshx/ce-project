# 方案二：内容匹配的安全供体与区域传输

## 1. 动机与中心问题

空间定位准确之后，直接复制 anchor 的同位置 token 仍可能改变人物身份、姿态、物体数量或局部纹理。其原因包括供体条件过于简单，以及图文前缀在不同条件下发生空间漂移。

本方案研究：**如何把安全内容送到目标区域，同时保留当前样本中已经形成的主体和布局？** 完整方法为概念分支定位、当前上下文安全供体，以及**内容匹配与可拒绝的 patch 传输**。

PER 从同一特征图的非目标位置取替代表示；FOMO 用成对条件的内部表示构造局部安全目标。两者都说明供体与选择性表示替换值得研究，但并未使跨条件的同位置 token 自动成为合适供体。[PER §3.5](https://arxiv.org/html/2606.31699)、[FOMO §3.2](https://arxiv.org/html/2609.39605)

## 2. 第一步：定位当前目标与构造配对条件

用共用 C1–C5 或方案一计算 `M_n`。首轮固定最后编辑点 `ell*`，使供体匹配的效果不与选层变化混在一起。

构造 `p^-` 时只改变应擦除语义。例如保留“一个人坐在蓝色椅子上、面向左侧、室内光照”，把目标身体属性改成穿着普通衣物。首轮由人工提供配对 prompt，固定修改规则。

从**同一个当前** `x_n` 分别计算用户和安全条件，获得编辑点的：

\[
(O^p,V^p),\qquad(O^-,V^-).
\tag{1}
\]

`O` 是待替换的 attention 输出，`V` 是用于内容匹配的 image value 描述子；它们不混用。两条件的投影参数相同，均位于同一个层和同一个 head 拼接坐标中。

对 safe donor 也运行只读概念分支，检查该分支目标证据与安全概念证据。这样“换了 prompt”不自动等于“取得安全 donor”。这会增加 donor 的概念分支计算，不能隐藏在零成本匹配中。

## 3. 第二步：以结构描述子匹配供体

接收位置集合 `I={i:M_n(i)=1}`。供体候选集合取其邻域，并要求供体的目标证据低于阈值：

\[
J=\{j:\operatorname{dist}(j,I)\le r,
\ H^-_{n,e}(j)<\tau_e^-,
\ H^-_{n,a}(j)>\tau_a^-\}.
\tag{2}
\]

`dist` 以归一化 token 网格位置计算。阈值按固定 safe 条件校准；不要求整张 donor 图都属于 anchor 类。无合格供体时显式产生匹配失败。

以单位化的 value 为初始内容描述子：

\[
z_i^p=V_i^p/(\|V_i^p\|+\epsilon),
\quad z_j^-=V_j^-/(\|V_j^-\|+\epsilon).
\tag{3}
\]

这是一项可检验的设计：value 可能混合内容与待擦除属性，不能把它先验地视为纯结构。实验分别比较 value、key、attention 输出描述子。

匹配代价为：

\[
C_{ij}=\lambda_f(1-\langle z_i^p,z_j^-\rangle)
+\lambda_s\|u_i-u_j\|_2^2
+\lambda_e H^-_{n,e}(j),
\tag{4}
\]

`u_i,u_j` 是归一化网格坐标。局部候选和空间项限制远处背景被搬到人物上的情况；内容项容许轻微姿态变化造成的位移。

## 4. 第三步：带空供体和容量约束的传输

引入空供体 `bottom`，表示该位置保持原值。令 `T_{ij}` 是将接收位置 `i` 的质量分配给候选 `j` 的非负权重，求解：

\[
\begin{aligned}
\min_{T\ge0}\quad&
\sum_{i,j\in J\cup\{\bot\}}T_{ij}C_{ij}
+\varepsilon_{OT}\sum_{i,j}T_{ij}(\log T_{ij}-1),\\
\text{s.t.}\quad&\sum_jT_{ij}=1,\\
&\sum_iT_{ij}\le b_j,\quad j\in J.
\end{aligned}
\tag{5}
\]

空供体代价 `C_{i,bottom}=c_null`，不设容量上限。普通供体容量 `b_j` 限制多个接收位置反复复制同一个 token。即使候选不足，空供体也保证运输问题有解。求解可采用容量约束的 KL 投影／标准凸优化；普通等边际 Sinkhorn 不能不加修改地当作式（5）的实现。

式（5）使用已有的熵正则运输工具，研究变量是**当前样本的空间供体对应关系和可拒绝替换**，而非提出新的 OT 算法。

将传输结果还原成供体表示：

\[
\widehat O_i^-=\sum_{j\in J}T_{ij}O_j^-
+T_{i\bot}O_i^p.
\tag{6}
\]

对空供体占比很高的样本记录 donor failure；默认保持这些位置，不把“没能编辑”当作擦除成功。可在固定额外供体预算内尝试另一条预定义 safe prompt。

## 5. 第四步：局部 blend 与后缀重放

在原用户前缀对应的末层状态上执行：

\[
O'_i=O_i^p+\eta M_n(i)(\widehat O_i^- -O_i^p).
\tag{7}
\]

随后运行原用户后缀并推进一次 scheduler。区域外 `AV` 不变；这个局部等式不保证后续采样的区域外像素完全一致。

soft transport 的供体是凸组合，不能据此声称一定留在模型原生激活流形内。另比较有容量约束的离散最小费用匹配版本；不能简单逐行 argmax 后仍声称保留了式（5）的容量约束。

## 6. 完整算法

```text
每个启用采样步：
    从当前 x_n 得到 user＋concept probe、M_n、O^p、V^p、末层重放状态
    若 M_n 为空：直接使用 probe prediction
    从同一 x_n、safe prompt p^- 得到 O^-、V^- 及 donor 概念读出
    在目标邻域筛选安全供体 J；构建空间＋内容匹配代价
    加入空供体，以容量约束运输求 T
    按式（6）形成匹配供体；按式（7）只改目标区域
    重放用户后缀并执行原生采样更新
    记录真实供体质量、空分配比例、移动距离和编辑量
```

多目标且 safe 修改相容时，可使用一条同时替换所有目标的 `p^-`，分别约束每个区域的 donor 语义。若不同目标要求互相冲突的 safe 内容，单一 donor 不适用，应分开供体并明确按目标数增长的成本。

## 7. 开销

一次 user probe、一次带概念读出的 donor、一次末层后缀重放。运输额外内存为 `O(|I||J|)`；4096 token 的全图两两矩阵在多层、多步上可能昂贵，默认每个接收位置只保留局部窗口内的 `k` 个候选，存储降为 `O(|I|k)`，但需使用支持稀疏候选的求解器。

若匹配仅用于末层，前缀不需要为每层保存全部大张量；只保留定位标量图和末层所需表示。供体候选数量、求解迭代和额外 safe prompt 数均计入时延。

## 8. 与已有工作的差别和可检验主张

- 相对 UVR：不依赖离线 unsafe patch 库来生成补丁；研究当前场景中的 safe donor 对应关系。UVR 的信息流调制与这里的表示搬运不同。
- 相对 PER：供体来自当前 latent 的配对 safe 条件，且有结构代价和空分配；不是从同图非目标位置均匀抽取。
- 相对 FOMO：研究推理时、逐样本的 donor 匹配；不将内部表示对齐蒸馏进 LoRA。
- OT、图像编辑中的特征对应和空间约束均为已有工具；需要额外查新和实验来判断具体组合的贡献，不能把“使用 OT”本身作为创新。

## 9. 必要实验

固定同一定位图、patch 点和强度，依次比较：

1. 离线 anchor 均值；
2. 单独安全概念 prompt 的同位置供体；
3. 完整场景 safe prompt 的同位置供体；
4. 加空间最近邻；
5. 加内容匹配；
6. 完整容量与空供体机制。

主指标为相同擦除率下的身份、姿态、布局和局部纹理保留。另报告供体中目标残留、空供体比例、平均移动距离及匹配计算量。设置局部微小偏移和明显布局变化两组，判断收益是否真正来自对应关系。

若“完整 safe prompt＋同位置复制”已经达到同样结果，运输应删去，保留上下文供体作为更简单的实现。若 value 匹配反而复制目标属性，需更换描述子或把方案四的保留坐标用作描述子；这属于后续有证据的组合。
