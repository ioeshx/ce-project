# 一手文献、实际机制与候选方案的区别

核对日期：2026-11-04。方法判断以作者论文正文、官方代码为依据。下表描述已有操作；五套新方案的组合和待验证主张见各自正文。

## 1. 与原方案最接近的工作

| 文献与正文入口 | 原文实际机制 | 对本轮设计的影响 |
| --- | --- | --- |
| [ConceptAttention](https://arxiv.org/html/2502.04320v2)，§4.1、§5.3–5.5；[官方代码](https://github.com/helblazer811/ConceptAttention) | 只读概念流、复用文本参数、attention 输出点积定位、多层聚合；包含 SD3.5 实验 | 定位是基础构件。原文目标缺席混淆，直接关联方案一；可读性仍需与干预效果分开验证 |
| [UVR](https://arxiv.org/html/2606.06875)，§4.1–4.2 | 明确遵循 ConceptAttention 的输出空间定位；离线视觉 patch anchors、相似度阈值、连通域／膨胀、attention 调制和注噪 | “内部输出定位＋局部抑制”已有直接先例。其离线区域构造使用 Grounded-SAM；本轮在线文本概念流和上下文 donor 是不同资源与操作 |
| [NLCE](https://arxiv.org/html/2603.25994)，§4.2–4.3 | U-Net 每步第一次提取 cross-attention gate，第二次跨层抑制；再做局部特征清除 | 两次前向、空间 gate、各层共享区域都已有。仅把此流程移到 SD3.5 不足以作为主要增量 |
| [PER](https://arxiv.org/html/2606.31699)，§3.3、§3.5 | SAE 检出目标位置；以同一次前向中非目标位置的 patch 表示替换命中位置 | 定位与 patching 分开已有先例。方案二研究跨条件的内容对应，方案四研究 token 内保留，须与这种简单 donor 基线比较 |
| [FOMO](https://arxiv.org/html/2609.39605)，§3.1–3.3 | 视频 attention 输出的 anchor 相似区域；局部 safe 表示目标、LoRA 对齐、区域外 value 保留 | 输出空间定位与局部安全表示已有组合。本文候选聚焦推理时操作；需要比较定位、供体及保留机制，不能只靠是否训练来判断优劣 |
| [ActErase](https://arxiv.org/html/2601.00267v2)，§3.2–3.3 | 成对条件产生 FFN 激活，构造比较掩码并 patch；多概念合并已有讨论 | 当前 AV／距离方法与它有机制近邻关系。改成 attention 输出和 CA 掩码，属于需要证明收益的变量变化 |

### UVR 与你的原始组合逐项比较

| 维度 | UVR | 你的可实现基线 B0 |
| --- | --- | --- |
| 定位参照 | 离线收集的目标视觉 patch 输出 | 在线 target／safe／背景概念输出 |
| 读出空间 | attention 输出 | attention 输出 |
| 掩码 | anchor 相似度阈值及空间处理 | 逐层概念对比图，多层平均或投票 |
| 擦除动作 | attention 信息流调制、特征注噪 | safe 条件供体的局部 AV 替换／blend |
| 在线额外资源 | anchors 与调制机制 | 概念 sidecar；实时 donor 需要额外条件前向 |
| 核心应比较项 | 定位质量、擦除、保留和代价 | 同左，并分离 donor 匹配与 patch 点的影响 |

上表说明实现有明确差别，也说明总体范式已有覆盖。合适的研究问题是这些差别解决了哪个具体缺口，而不是将基础组合命名为全新的总体范式。

## 2. 对“第三个点”的直接近邻

| 文献 | 与候选的关联 | 需要避免的重复主张 |
| --- | --- | --- |
| [GLoCE](https://arxiv.org/html/2503.12356)，§3.1–3.3、附录 D.3 | 局部门控、闭式低秩编辑与保留；包含 DiT 验证 | 自动 gate、局部性、低秩矩阵本身不新。方案一需证明空目标拒绝，方案四需证明当前状态约束的作用 |
| [Localizing Knowledge in DiTs](https://arxiv.org/html/2505.18832v2)，§3–4 | 知识相关层定位、实际输出的干预分析、局部微调 | 选层与“因果”用语已有。方案三的贡献需来自固定定位和写入后的预算内响应选择 |
| [Double Projections](https://arxiv.org/html/2604.10032)，§4 | 安全代理构造、保留方向零空间中的约束变换 | 投影、闭式解、保留子空间均已有。方案四研究在线 AV／动态读出的具体约束问题及最终生成效应 |
| [SafeRoPE](https://arxiv.org/html/2604.01826)，§3.2–3.4 | head 风险子空间、风险评分、关键 head 选择、Q/K 旋转 | 稀疏 head、自适应风险门控和低秩安全干预已有。与 AV patch 的编辑变量、训练资源和成本分别比较 |
| [Concept Corrector](https://arxiv.org/html/2502.16368)，§4.2–4.3 | 检查中间预测图像的目标，再在后续生成中实施 Concept Removal Attention | 在线检测—纠正已有。方案五应证明内部读出、重现定义和有限预算控制的具体价值 |
| [ETC 作者项目页](https://seohoiki3215.github.io/ETC_project_page/) | 在概念嵌入分布上使用 affine optimal transport 并训练多专家擦除模块 | “将 OT 用于概念擦除”已有。方案二的变量是空间 token 对应、当前 donor 及空分配，而非嵌入分布映射 |

这组文献足以限制本轮贡献的表述范围；相同算法的完整查新还应包括图像编辑和一般 activation steering。没有检索到同名缩写，不是方法原创性的证据。

## 4. 五个可检验的差异应如何写进论文

| 方案 | 若实验支持，可以陈述的具体结论 | 最直接的证据 |
| --- | --- | --- |
| 一 | 完整采样上的空目标拒绝改善目标召回与误编辑之间的权衡 | 同召回下的误触发／近邻保留；首次触发率与校准水平的关系 |
| 二 | 当前场景的 donor 对应比同位置替换更能保留局部结构 | 固定 mask 与擦除水平后，姿态／身份／布局改善；供体移动与匹配消融 |
| 三 | 概念可读层和有效干预层不完全相同，响应选层提高单位成本收益 | 热图质量—干预收益关系；末层／随机／热图选层／响应选层对照 |
| 四 | 空间目标区域内部的保留坐标约束优于整 token 替换 | 冻结约束、重算读出、最终视觉结果三层证据；同区域保留提升 |
| 五 | 按实际重现分配有限修改预算，减少恢复目标与重复过度编辑 | 相同 donor／能量预算的固定 schedule 对照；重现、编辑量、最终指标 |

论文贡献围绕其中一条主结论和必要支撑展开，不把所有常用构件各列为一条发明。若增量在同预算实验中消失，保留更简单的版本。

## 5. 推荐优先级

首先比较当前距离方案和 CA 定位底座，判断目标缺席误触发与 donor 错位是否严重。随后用较小开发预算检查末层、若干中层和全层，优先决定是否值得深入方案三。若同一位置内的身份／姿态破坏明显，则方案四比再加一个空间后处理更贴近问题。

方案五只在观察到实际跨步重现后展开；方案二只在供体对应关系确实是瓶颈时引入运输。这个顺序使新增机制由测到的问题驱动，最终方法的每一项都能说明作用。
