# 对原方案的评估与应先修正的定义

## 1. 原方案可以作为明确的研究基线

你的方案可精确定义为：在当前采样状态加入只读概念分支，查询待擦除概念和安全替代概念；聚合本步多个层的概念定位分数；构造一张空间掩码；将最后一个干预位置的图像 attention 输出，局部换为安全条件下得到的同位置输出。

主干生成模型可以保持冻结。概念分支复用已有参数，安全供体通过额外条件前向获得。这是一个可实现的推理时概念抑制方法。若部署时关闭这些模块即可恢复原模型，应按“推理时擦除／安全控制”评价，而不将其解释为模型权重已经永久遗忘。

## 2. 先区分两种 anchor

| 名称 | 用途 | 示例 |
| --- | --- | --- |
| **安全概念查询** `a` | 在概念分支中与目标查询 `e` 比较，提供读出对照 | `nude` 与 `clothed` |
| **安全供体条件** `p^-` | 在生成模型中产生可用于替换的图像表示 | 在原人物、动作、场景描述中，将裸体属性改成穿衣属性 |

一个安全概念词不等于一条场景匹配的供体 prompt。直接以 `clothed` 单独前向，其图像表示可能包含不同的人物、姿态和布局。建议从原 user prompt `p` 构造最小语义变化的 `p^-`，并保持同一个当前 latent、噪声水平、guidance 和模型版本。

`nudity` 与 `clothed` 是语义对照，不能把后者视为统计独立的 unrelated 概念。背景、脸部、手部、其他主体等也可能既不属于目标区域，也不属于衣物区域。若只对这两个词做 softmax，每个位置仍被迫分配给二者之一；因此需要目标缺席校准，或加入明确的保留／背景查询。

对于隐式描述，最小编辑 `p^-` 需要预先确定的任务规则、模板或单独的文本重写组件。本文的首轮实验使用明确提供的配对 prompt，不假定模型会自动、无误地生成安全供体条件。若后续引入 LLM 重写，应把它作为单独资源和误差来源报告。

## 3. 需要明确替换的到底是什么

当前位置的“image token”可能指：

1. attention 内部的 value `V`；
2. 多头拼接后的 attention 输出 `AV`；
3. 输出投影后的 attention 残差；
4. 整个 block 的图像残差状态；
5. 模型最终 velocity／noise prediction。

它们的维度可能相同，语义和后续作用却不同。当前工程使用 **输出投影前的图像 `AV`**，本组方案默认延续这个位置。公式记为 `O`；主干残差状态记为 `X`。二者不混用。

若直接替换整个残差状态 `X`，会同时替换该位置累积至今的多种信息，比替换本层 `AV` 的干预范围更广。它应作为独立基线，而非实现时可随意互换的细节。

## 4. 跨层平均可读图，不等于跨层平均表示

在层 `ell` 先分别计算概念匹配，再聚合标量空间分数。这避免对不同层的通道坐标直接相加。即使各层隐藏维度相同，其坐标基也不是天然可互换的。

以下三种算法必须分开命名：

- **软图平均**：各层先做概念维 softmax，再平均，最后阈值化。
- **二值图多数投票**：各层先阈值化，平均二值图后以 `> 0.5` 判定。
- **先平均原始向量再计算分数**：包含跨层交叉项，通常不等价于前两者。

ConceptAttention 提供的是逐层读出和多层聚合依据；原论文并未验证你的跨层二值多数投票擦除策略。投票中的层共享输入和前序状态，票数不能被解释为相互独立的统计证据。

例如三层目标分数为 `0.90、0.49、0.49`，以 `0.5` 为阈值，软平均为 `0.627`，产生掩码 1；先二值化后只有一票，产生掩码 0。两种算法应分别实验。

全层同权平均也不是必然最优。较浅层可能缺少可靠语义，部分深层则更接近生成细节。首轮比较全层、后段层、验证集选择的层集合，固定集合后再评估测试集。[ConceptAttention，§4.1、§5.3](https://arxiv.org/html/2502.04320v2)

## 5. 只在每步末层 patch：合理的起点，不是充分性结论

末层 patching 有两个实际优势：定位图已经可用；相对于早层替换，后续层内传播较短，便于控制本步的直接影响。

它也有具体缺口：

- 若目标信息已存在于进入末层的残差状态，只修改最后一项 attention 写入，可能不足以改变目标。
- 最后一个 dual-stream block 不一定是模型最后一个 block。FLUX 后面还有 single-stream blocks，二者必须区分。
- 下一采样步仍读取原 user prompt，模型可能重新形成目标概念。
- 高 saliency 表示该层输出可被概念查询读出，不能直接证明修改该层会改变最终概念。

因此，应把末层、若干深层、稀疏有效层和原有全层替换列为不同的干预策略，在相同掩码下比较。方案三专门研究选层，方案五专门研究跨步重现。[Localizing Knowledge in DiTs，§3–4](https://arxiv.org/html/2505.18832v2)

### 一个两维反例

设进入末层的图像状态为 `X=(10, 1)`，第一维承载待抑制信号；末层 attention 写入为 `O=(0.1, 0.2)`，安全供体为 `O^-=(0, 0.2)`。忽略其他项时，替换后状态由 `(10.1, 1.2)` 变为 `(10, 1.2)`，第一维的主要部分仍然存在。

这个例子只说明“修改最后写入”与“移除已经累积的状态”在计算上不同；实际模型里哪个位置有效，需要生成干预实验确定。

## 6. anchor 必须来自同一个当前生成状态

每步供体定义为：

\[
O^-_{n,\ell}=\operatorname{ReadAV}_{\ell}
F_\theta(x_n,\sigma_n,p^-).
\]

其中 `x_n` 来自当前已经受此前编辑影响的实际轨迹。不能拿独立 safe 采样轨迹上的 `x_n^-` 直接当作同状态反事实，也不能假定同 seed 就保证内部空间位置一直对齐。

现有离线多 seed 均值是低成本原型基线，适合比较；它与当前上下文供体不等价。实时供体还可能在不同条件前缀后产生空间漂移，因此“同 latent”是重要控制条件，但不是完整的空间对齐保证。方案二处理后一个问题。

## 7. 全层热图与前向重跑的执行条件

若想把最终掩码应用到早期层，第一次前向无法使用尚未计算的深层信息，需要重放受影响的前缀和后缀。

若只在最后一个可用 `AV` 位置干预，所有用于聚合的读出都可以在该点已经齐备。此时可以：

1. 先获得安全供体，再执行 user＋concept 前向，在末层 hook 中直接完成聚合和替换；或
2. 完成未编辑 user 前向，保存 patch 点所需状态；若掩码非空，再获得安全供体，并仅重放 patch 点之后的后缀。

第二种还能复用未编辑 velocity，且在掩码为空时跳过供体。缓存必须包含所需的图像残差、文本状态、调制条件、位置编码以及 FLUX 单流 block 的 MLP 通道，不能只保存一块 `AV` 后凭空重建整个 block。

所以“全层平均必然需要完整重跑用户模型”是过强的说法。是否需要，取决于**掩码信息何时齐备，以及 patch 点位于何处**。

## 8. 与 UVR 等工作的实际重合

UVR §4.1 明确引用 ConceptAttention；它使用离线目标视觉 patch anchors，在 attention 输出空间定位，再调制信息流和注噪。你的在线文本概念分支、同状态安全供体替换，与它的实际实现有差别。但“内部表示定位＋局部干预”这一层面的思路已有先例。[UVR](https://arxiv.org/html/2606.06875)

还需要同时考虑：

- NLCE：每步先观测再干预，使用空间 gate；
- PER：检测后替换局部 patch 表示；
- FOMO：输出空间定位与安全内部表示对齐；
- ActErase：成对条件的激活差异与激活替换；
- GLoCE：局部门控与低秩编辑。

因此，不能只比较 UVR。各工作的核对位置及具体差异见 [文献表](07_related_work.md)。

## 9. 怎样增加一个有研究价值的点

| 已观察到的问题 | 值得增加的机制 | 应证明的结果 |
| --- | --- | --- |
| 安全图像也出现目标热区 | 目标缺席校准与拒绝编辑 | 在相同召回下减少误触发和安全图像改变 |
| anchor 替换改变人物姿态／身份 | 当前场景供体与匹配 | 在相同擦除率下提高非目标属性保留 |
| 高热图层改了也不影响结果 | 实际干预响应选层 | 同预算下比末层、随机层和热图选层更有效 |
| 同一块区域内的正常信息一起丢失 | 保留约束的最小改动 | 同一区域内的身份、姿态等保留改善 |
| 擦除后下一步又恢复目标 | 时序触发与有界控制 | 降低重现，同时减少无效重复编辑 |

这些机制对应五篇方案。先测问题是否存在，再确定主线。一个清楚、可复现的核心发现和一个解决机制，可以形成完整贡献；模块数本身不提供证据。
