# CWC：将概念相关的 DiT 条件写入离线编译为轻量擦除模块

**方法定位：面向 flow matching 文生图 DiT，冻结生成模型，只在缓存激活上拟合小模块；部署时自动触发，支持单概念和多概念。**

核心做法是：离线固定某个 block 的图像输入，比较原文本条件与去除目标后的文本条件分别产生的图像残差，把两者之差作为纠正目标；再将这种纠正压缩到少数 block 的低维模块中。在线模块读取正常前向中的图像状态和本次残差，判断目标概念是否相关，并预测当前样本需要减去的写入。

CWC 是本次提出的研究方案，全称为 **Counterfactual Write Compilation，反事实写入编译**。本文给出方法和验证条件，尚无实验结果。

## 1. 使用方式与论文主线

离线开发者确定擦除集合，例如 `{Pikachu}` 或 `{Pikachu, nudity, 某艺术风格}`，制作并拟合一个固定的擦除包。部署后接口为：

```text
离线：compile(base_model, forbidden_set, paired_examples) -> erasure_pack
部署：load(base_model, erasure_pack)
生成：generate(prompt, seed, sampling_settings) -> image
```

生成请求只携带通常的 prompt、随机种子和采样参数。目标集合已经写入擦除包，用户无需另行提供 target concept 或 anchor。prompt 本身可以包含目标名称，也可以通过外观、别称或上下文间接描述目标。

论文的中心问题是：**能否用少量、固定图像状态下测得的条件写入差分，训练出无需在线概念条件的低开销纠正器？** 主要贡献应围绕这种离线编译能力，以及擦除率、保留能力和计算成本之间的关系展开。

## 2. 干预单位：一个 block 本次写入的图像残差

以 FLUX 类 DiT 为首个实现对象。一个 block 接收图像 token、文本 token，以及包含时间、文本池化信息和 guidance 信息的调制条件，并产生更新后的图像状态。将图像输出减去图像输入，得到这个 block 的图像残差，记为 `r`。

离线为同一场景准备一对 prompt：

- `p+`：包含要擦除的目标，既包括直接名称，也包括间接描述。
- `p−`：去除该目标，保留场景、动作、构图和其他应保留的概念。

例如，角色擦除可以将具体角色换成普通卡通动物；nudity 擦除可以在同一人物与场景中改成穿着衣服。每个目标使用多种去目标表达，作为离线参照。

沿 `p+` 的正常采样轨迹，在选定噪声水平保存当前 latent 和 block 的图像输入 `x`。再用**同一个 latent、同一个噪声水平**运行 `p−` 的前缀，取得该层的去目标文本状态。随后重放当前 block，始终使用原来的图像输入 `x`，仅替换文本状态和文本产生的调制条件：

\[
\Delta r = r(x,y^+,m^+) - r(x,y^-,m^-).
\tag{1}
\]

其中 `y` 是进入该 block 的文本 token；`m` 中的噪声时间与 guidance 设置保持相同，文本池化分量随 prompt 改变。模型没有独立文本池化分量时，只替换实际存在的文本条件。

**固定图像输入是关键操作。** 两次局部计算从相同的图像状态出发，差分描述改变文本条件后，本 block 的图像写入如何变化。它避免把两条独立生成轨迹的构图差异直接当作概念差分。

这里的“反事实”指这个明确的局部替换实验。替换后的写入是否足以消除最终图像中的目标，由完整采样验证。

## 3. 离线流程

### 3.1 准备目标样本、近邻负例和组合样本

每个目标先准备少量 prompt 对，覆盖不同场景和表达方式，并检查基础模型实际生成的内容。门控标签依据需要阻断的视觉概念标注。

保留样本同时包括通用 prompt 和容易误伤的近邻。例如，擦除 Pikachu 时加入普通黄色动物、其他卡通角色及黄色物体；擦除 nudity 时加入穿衣人物、肖像和允许保留的身体相关场景。目标词出现在文字排版、否定表达或引用中，也应按最终视觉任务单独标注。

多概念集合加入两类组合：多个目标共同出现；目标与应保留概念共同出现。为前一类制作**一次去除所有已配置目标**的 `p−`。这直接提供联合擦除的监督。

### 3.2 找到少数有效的 block 与噪声时间窗

先利用正常前向与去目标前向中缓存的特征变化筛选候选 block，再执行式（1）的局部重放。候选排序用于缩小搜索范围。

对候选位置做完整采样实验：在指定噪声时间窗内，把原来的图像残差换成局部重放得到的去目标残差，随后继续正常生成。保留能降低目标出现率、同时保持其他主体和场景的位置。联合验证选出的少数位置，起步预算为 2–4 个 block。

该步骤确定的是**有生成干预效果的位置**。已有研究发现 DiT 的不同概念具有不同的 block 分布，因此位置和时间窗均由离线实验选择。[Localizing Knowledge in Diffusion Transformers](https://arxiv.org/abs/2505.18832)

### 3.3 压缩写入差分，拟合小型纠正器

每个入选 block 建立两个低维基：

- `U`：对所有目标、组合样本及选定时间窗的 `Δr` 做截断 SVD，保留主要纠正方向；分解前不减去差分均值，使平均纠正也能进入低秩基。
- `V`：对缓存的图像输入做 PCA，提供当前图像状态的低维上下文。

起步均取 8 维，并在验证集上检查压缩后的纠正效果。在线对第 `j` 个图像 token 读取：

\[
q_j = [V^\top(x_j-\mu_x),\ U^\top(r_j-\mu_r)].
\tag{2}
\]

两个均值来自离线缓存。对低维读数的标准化参数同样保存在擦除包中。

在缓存上拟合两个小预测头：

1. **门控头**：读取所有 `q_j` 的均值、逐维最大值与当前噪声水平，输出擦除集合内各概念的相关性分数。用目标标签和近邻负例监督，并在留出的保留样本上校准触发阈值。
2. **纠正头**：一个小型两层 MLP，输入当前 token 的 `q_j`、上述全局统计及噪声水平，输出 `U` 坐标下的纠正系数。目标样本拟合 `UᵀΔr_j`；保留样本拟合零。

纠正头对每个 token 分别输出系数，因此能随图像状态、空间位置和噪声水平改变纠正方向与幅度。全部拟合在已缓存的低维数据上完成，生成模型不参与反向传播。

### 3.4 用编辑后的状态校准一次

运行拟合后的擦除包，检查新轨迹上的触发率和最终结果。对偏差较大的样本，在新的图像状态上重新测量式（1），补入缓存并进行一轮小模块拟合。

这一步处理编辑后状态分布的变化。补采时沿用该样本应阻断的目标标签；纠正监督重新计算。标签表达的是当前请求中的擦除任务，不能因最终目标已被成功抑制就直接改为负例。

## 4. 在线流程

每次生成按原流程编码 prompt、初始化 latent 并采样。在选定 block 和时间窗执行：

1. 保存本次图像输入 `x`，完成该 block 的正常计算，得到原图像残差 `r`。
2. 计算式（2）的低维读数，由门控头判断擦除集合中是否有目标相关。
3. 门控关闭时，使用原残差；门控开启时，由纠正头预测各 token 的系数 `a_j`，更新：

\[
r'_j=r_j-g\,U a_j,\qquad g\in\{0,1\}.
\tag{3}
\]

4. 将 `x + r′` 作为当前 block 的图像输出，继续后续 block。当前 block 的文本输出沿用正常前向结果。
5. DiT 输出 velocity，原 scheduler 按 checkpoint 的时间与符号约定更新 latent。

门控使用固定擦除包内的预测头识别内部生成状态，无需在线编码目标词、构造 anchor prompt 或调用外部识别模型。每个选定位置重新判断，后续重新出现的目标写入可以再次触发纠正。

```text
普通 prompt → 文本编码 → 原 DiT 前向 → 原 velocity → 原 scheduler
                              │
                     少数 block／时间窗
                              │
                    读取图像输入与本次残差
                              ↓
                      低维门控与纠正头
                              ↓
                     更新本次图像残差
```

## 5. 单概念与多概念如何统一

单概念使用一个门控输出和一个纠正头。

多概念在同一 block 共用 `U`、`V` 和一个联合纠正头。门控提供各概念分数，任一概念超过校准阈值就开启纠正；联合纠正头根据当前状态输出一次总纠正。组合样本的监督是原条件与“一次去除所有相关目标”条件的写入差分。

这一设计使联合擦除直接学习于组合样本。每个位置只产生一次更新，无需给多个独立编辑器安排执行顺序。多个概念共享视觉特征时，如何避免重复削减，由联合监督和近邻负例共同约束，并通过组合测试检验。

增加新概念时，更新离线集合和缓存，重新拟合联合小模块。复用已有缓存可以减少准备成本；新增概念需要补充样本、检查干预位置和联合纠正秩。

## 6. 计算开销与适用模型

在线每个启用位置的主要工作是两次低秩读取、一个小 MLP，以及门控开启时的一次低秩写回。额外计算随图像 token 数线性增长；整个采样过程的**额外 DiT 调用次数为零**。

例如，图像隐藏维度为 3072、两个秩均为 8 时，`U` 与 `V` 合计 49,152 个参数，以 BF16 存储约 96 KiB／block。4 个 block 的基矩阵约 384 KiB，小预测头和统计量另计。端到端延迟还受额外 kernel 和显存访问影响，实验中直接测量。

时间窗按实际噪声水平配置。FLUX 的双流 block、单流 block，以及 SD3 类 MMDiT 均可按“固定图像输入、替换文本条件、读取图像残差”实现局部重放；每个 checkpoint 单独制作擦除包。首轮以 FLUX.1-dev 验证，再在 SD3.5 类 flow matching DiT 上检验流程迁移。两者的层编号和编译参数分别标定。

FLUX.1-dev 沿用其 guidance 条件。使用显式 CFG 的模型，在现有条件分支上接入纠正模块，沿用原 CFG 组合，并在相同 guidance 设置下标定擦除包；基础采样器已有的分支属于基线计算。

## 7. 与相关方法的关系及论文创新点

已有研究提供三项直接依据：DiT 的 attention 输出包含可解释的概念信息；概念生成对某些 block 的干预更敏感；预计算后的内部表征干预能够支持低开销控制。[ConceptAttention](https://proceedings.mlr.press/v267/helbling25a.html)、[Localizing Knowledge](https://arxiv.org/abs/2505.18832)、[SafeRoPE](https://arxiv.org/abs/2604.01826)

已有 DVE 也预计算概念差分，并在推理时修正 velocity；AcFlow 则学习由概念描述驱动的内部 activation flow。因此，论文创新应具体落在以下设计及其证据上：[DVE](https://arxiv.org/abs/2602.01089)、[AcFlow](https://arxiv.org/abs/2609.10723)

- **监督单位**：固定 block 图像输入后，测量文本条件导致的局部写入差分。
- **编译能力**：从少量缓存中拟合自动识别与状态相关纠正，部署接口只接收普通生成请求。
- **联合擦除**：直接学习多个目标共同移除的总写入变化，在线执行一次低秩更新。

## 8. 决定方法是否成立的实验

| 问题 | 核心比较 | 应得到的证据 |
|---|---|---|
| 少数局部写入是否足以擦除？ | 原模型与精确局部重放 | 在完整采样中降低目标出现率，并保留混合场景中的其他内容 |
| 小模块是否能替代离线重放？ | 精确重放、低秩重放、编译模块 | 区分位置选择、低秩压缩和预测误差各自造成的损失 |
| 固定图像输入有什么作用？ | 本方法与独立轨迹差分；相同小模块 | 在相近擦除率下改善场景和近邻概念保留 |
| 自动触发是否有效？ | 显式名称、间接描述、保留近邻；门控全开作消融 | 同时报告触发召回、误触发率及最终目标出现率 |
| 联合编译是否改善多概念擦除？ | 单概念编辑器叠加与联合模块 | 比较单目标、目标组合、目标与保留概念共现三类结果 |
| 是否满足部署成本？ | 原模型与擦除包；相同采样设置 | 报告总延迟、显存、模块大小、离线 DiT 调用量与小模块拟合时间 |

首轮先做精确局部重放。若它在预算内找不到有效的小规模干预位置，后续编译就缺少有效监督。若精确重放有效而低秩版本明显变弱，则需要调整纠正秩；若低秩重放有效而编译模块变弱，则检查状态预测和门控。

本方法的核心假设是：选定目标存在少量有效干预位置，所需写入纠正能够低秩压缩，并能从当前内部状态预测。实验分别检验这三点。部署作用范围为离线配置的概念集合；完整采样中的擦除效果与近邻保留能力是最终判断依据。
