# 最小实验、对照与停止条件

本文件是预先设计的实验协议，不包含已运行的模型结果。下列规模和阈值是用于研究决策的建议值，不是由已有结果反推的最优设置。

## 1. 先区分四个问题

1. 速度参照是否真的对应想要的概念变化？
2. 少量输入动作能否实现这个参照？
3. 一两个检查点的修改能否影响最终图像，而不是只拟合一个瞬间？
4. 在相当的擦除效果下，保留能力与计算成本是否有实际优势？

如果第 2 项不成立，不先跑大规模 benchmark；如果第 1 项失败，不通过优化输入系数掩盖参照的误判。

## 2. 数据与划分

第一轮先选一个风格与一个对象类别，例如 Van Gogh 和 church。先把对象任务定义为类别特征移除/替换；若研究整对象删除，则另建移除对象的成对 prompt 和保留指标，不能在实验后更换任务解释。

每个概念的文本划分按**上下文模板家族**区分：

| 划分 | 建议规模 | 用途 |
| --- | --- | --- |
| 方向准备 | 16 对目标/对照文本 | 只构造原生条件编辑方向 |
| 校准 | 8 对目标/对照文本，另 8 个近邻良性 prompt | 选择扰动幅度、预算、正则、DVE 阈值和检查点 |
| 机制测试 | 8 个显式目标 prompt + 8 个良性 prompt | 测量未见上下文的输入响应 |
| 图像试验 | 12 个显式目标、8 个隐式目标、12 个近邻良性、8 个远端良性 prompt | 初步比较擦除与保留 |

中文、同义词和不同模板属于不同测试子集。避免仅把人名或场景词替换后，就把高度相似模板分到准备和测试两侧。最终测试 prompt、seed 和外部评估标签不参与方向、anchor 或超参数选择。

## 3. 阶段 A：输入可实现性，先不解码大量图像

先在 FLUX.1-dev 上进行两个概念的机制实验。每个概念用机制测试的 16 个 prompt、一个 seed，共 32 条基础轨迹。保存生成进度约 0、0.3、0.6 的 latent，一阶采样器下记录全部原生时间与 guidance 设置。

在这些**相同状态**上测输入响应，不为每种扰动另跑整条轨迹。先使用实际原生通道数对应的方向数，上限 `K=4`，不搜索大量隐层或方向。

### A1. 已知成对 prompt 的理想参照

目标 prompt 都有人工作出的最小对照版本。直接以同状态下对照 prompt 的速度为参照，不启用 DVE 门控。这个设置只诊断输入的控制能力，不是完整部署方法。

若连这个容易定义的目标都无法近似，就不能把失败全归因于 DVE 判断不准。它也用于对照“直接使用对照 prompt”：如果后者更好且更便宜，复杂输入拟合对显式提示没有额外价值。

### A2. DVE 参照

在相同状态上换为 DVE 的选择性纠正目标，复用同一组输入响应，重新求系数并真实验证。比较结果时分别标记：DVE 未触发、触发但输入不可实现、局部拟合成功。

机制测试中的 prompt 标签只是预期语义，不是“该条轨迹最终确实生成了目标”的真值。图像阶段才对实际输出进行独立判断。

### A3. 需要记录的量

- 真实前向后的参照残差，与修改前的残差比较；不要只报告线性预测残差。
- 每通道的输入 RMS 修改量、系数、预算触边比例与实际响应范数。
- 当前检查点的拟合与后续保存状态上的拟合，区分即时效果和跨步漂移。
- 近邻良性 prompt 上的门控误触发，以及因此产生的非零条件修改。
- 减半重试、最终拒绝、数值无响应的比例及其原因。
- 所有条件分支前向次数与准备耗时。

可用 `1 − 修改后残差 / 修改前残差` 表示速度拟合改善。它可以为负值；修改前残差接近零的样本标为不适用，不用它们抬高均值。这个数不是概念擦除率，也不是可证明的语义保留比例。

### A4. 阶段性决策

一个可预先采用的继续条件是：在前两个位置、非零目标修正的显式目标样本中，真实速度残差的中位下降达到 50%，且多数样本不依赖输入预算上限才出现效果。分别报告两个概念，不能用其中一个概念的成功掩盖另一个失败。

若只在线性预测中成功、真实前向失败，先检查扰动尺度和精度；允许在校准集上作一次修正。若仍不能实现，就暂缓主线。不要连续增加方向数、拟合回合与时刻，直到预算失去原意。

## 4. 阶段 B：有限规模最终图像比较

使用每概念 40 个图像试验 prompt、两个 seed，在同一模型上先比较八个系统：原模型、最小 prompt 替换、固定输入方向、Semantic Steering、完整在线 DVE、早期 DVE、缓存 DVE、IRDE。

两个概念合计 `2 × 40 × 2 × 8 = 1,280` 张图像，不计此前准备和校准。如果预算更小，可以减少每个子集的 prompt 数，但保留这八个系统，尤其不能删去便宜的输入基线和 DVE 成本缩减变体。

固定输入方向使用与 IRDE 相同的方向字典，只在校准集选固定系数；它隔离了速度响应拟合本身的收益。直接 prompt 替换在显式目标子集有可靠最小替换，在隐式子集只能使用预先定义的规则，并记录覆盖率。

### B1. 擦除有效性

报告目标出现率、按原模型实际生成目标的样本条件化后的抑制率，以及各 prompt 子集结果。若原模型本来就画不出目标，不能将其统计为方法擦除成功。

对象可用既有任务评估器并辅以盲评；风格至少使用独立风格判定与人工抽查，不能只用编辑前后 LPIPS 变大来说明成功。评估器不参与方向构造、门控或输入系数拟合。

### B2. 三种保留要分开

**目标 prompt 的非目标内容：** 主体、姿态、对象关系、场景、数量是否保留；用删除目标短语后的文本做对齐参考，并进行成对盲评。对原始有害或指定目标文本的对齐下降，不必然代表保留变差。

**近邻良性概念：** 例如 church 与普通楼房，指定艺术家与其他画风，特定身份与其他人物。它们是误擦除最容易被总体质量指标掩盖的部分。

**远端良性内容：** 无关场景的生成质量与多样性。试验阶段主要报告成对差异、对齐和人工偏好，不用少量图像的 FID 宣称总体生成能力保持不变。

### B3. 对参照、输入位置和成本的归因

若 IRDE 的目标出现率接近 DVE，但近邻保留或非目标内容更好，这支持输入约束的价值。若只是出现率更高、图片变化更小，可能仅是擦除更弱，需要比较匹配擦除程度的工作点。

如果固定输入方向或最小 prompt 替换已经得到相同效果，IRDE 的在线求解没有得到支持。若优势仅来自较保守的 DVE 阈值，也不能归因于输入编辑。

## 5. 阶段 C：跨结构与任务扩展

通过前两阶段后，再扩展到以下模型。只验证前两行不足以充分支持对单流结构的适用性。

| 模型 | 实验角色 | 实施时需固定的设置 |
| --- | --- | --- |
| FLUX.1-dev | 第一轮主模型，含多种条件通道 | 原生条件包、蒸馏 guidance、步数与 scheduler |
| SD3.5-medium | 更换条件组合与多模态实现 | 所有 sequence/pooled 通道及真实 CFG |
| 未蒸馏 Z-Image | 单流 S3-DiT 的关键验证 | 实际 checkpoint、原生编码器输出、mask 和 guidance |
| FLUX.1-schnell 或 Z-Image-Turbo | 可选的少步压力测试 | 独立报告查询开销，避免混入长采样的效率结论 |

单流与 flow matching 的模型选择依据见 [论文说明](LITERATURE.zh-CN.md)。不要求同一个数值向量跨模型迁移；要求方向构造、响应测量和拟合规则可以复用，只重新计算原生输入方向及必要尺度。

扩展任务包括多个风格、多个对象、人物身份与成人裸露属性。身份与裸露评估可以使用外部评估工具，但严格留在离线评价阶段。不能因评估使用分类器，就将其混记为方法的运行组件；也不能只用与参照相同的文本相似度评价自己。

大规模保留评估再使用固定 COCO 子集，最终可扩至 10K 或采用与基线一致的规模。FID、CLIP 等同一实验重算，不能横向比较两篇论文不同分辨率、seed、预处理与数值尺度下的表格。

## 6. 鲁棒性协议

至少分四类：显式词与同义词、没有概念名的间接描述、长上下文和语言切换、针对启用模块的自适应攻击。

Ring-A-Bell、MMA-Diffusion、P4D 等既有 prompt 可用于迁移测试，但必须报告其来源模型及是否重新优化。迁移 prompt 不能代替对 IRDE 的自适应攻击。

攻击者若只能提交字符串，按字符串权限评价；若允许直接提交连续 embedding，则另设更强权限的结果。主方法无法阻止拥有完整权重和代码的使用者卸载该模块，这不应与启用模块时的 prompt 鲁棒性混为一谈。

至少让自适应攻击可以针对检查点和输入编辑优化，并让其面对同样的生成预算。若梯度攻击困难，可用有预算的黑盒搜索交叉检查，避免将难以求梯度误认为概念已消失。攻击期间所有额外模型或评估器均记入攻击协议，不接入 IRDE 的生成路径。

## 7. 最有信息量的消融

| 消融 | 回答的问题 |
| --- | --- |
| 同一方向字典：固定系数 vs 实测响应系数 | 在线拟合有没有独立收益？ |
| 显式片段编辑 vs 全部可编辑 token 广播 | 精确词定位的收益与隐式覆盖的代价是什么？ |
| 单条件通道 vs 所有原生通道 | 是否存在未干预通道的残留作用？ |
| 理想成对参照 vs DVE 参照 | 失败主要来自门控/参照还是输入控制能力？ |
| `K=1/2/4`，检查点 `m=1/2/3` | 效果是否必须依靠扩大查询预算？ |
| 线性预测 vs 真实候选验证 | 局部近似在什么范围有效？ |
| 保持条件修改 vs 中后期释放修改 | 后期复发与过度修改是否冲突？ |
| 同一方向下不同合理 anchor | 收益是否只是选择了更容易的替代目标？ |

不把所有消融做成新的完整方法模块。先完成最能区分原因的前四项，再按失败证据决定后续工作。

## 8. 成本报告

每个系统同时报告准备阶段和在线阶段，不只写单图平均延迟：

- 原生编码器调用、准备期 DiT 前向、是否存在反向传播、缓存大小。
- 每张图的 conditional/unconditional 前向次数、实际触发检查点和减半重试数。
- 相同硬件、精度、分辨率、batch 下的预热后延迟分布和显存峰值。
- 批处理试探与逐分支试探的不同配置。

对同一硬件上未实测的设置，只给前向计数，不推断秒数。DVE 缓存的构建样本数、分辨率、时间网格，以及能否跨 seed 复用，也必须公开。

## 9. 是否值得继续写成论文

建议在校准前固定一组实用标准，例如：

- 局部输入可实现性通过阶段 A；
- 图像试验在擦除出现率上与完整 DVE 的差距不超过 5 个百分点，并在匹配擦除强度后仍显示保留优势；
- 在方向数和检查点均受限时，实测成本具有实际价值，同时与缓存 DVE、Semantic Steering 的不同成本定位讲得清楚；
- 至少包含一个真正单流 flow DiT 的验证，且规则无需重新设计。

这些 5 个百分点和 50% 等数值只是试验决策阈值，不是统计显著性的替代品。小试验先报告置信区间与失败案例，确认趋势后再扩大样本。

出现以下任一情形，应重新评估这条主线：

1. 小幅输入编辑无法实现参照，只有明显条件失真时才有效。
2. 需要几乎每步重新测量或大量新方向，成本优势消失。
3. 缓存 DVE、固定输入方向或简单改写在同预算下占优。
4. 保留改善完全来自更弱的擦除或不同门控。
5. 跨结构失败，必须重新依赖内部层、attention head 或额外模型。

若最终有效发现是“某些输出擦除方向无法由少量输入编辑实现”，也可形成有价值的诊断结论，但应调整论文问题与标题，不能把它包装成已解决的输入端擦除方法。
