# 论文依据、近邻方法与创新性边界

本文件区分三个层次：论文原文中的方法；由原文得到的研究判断；本轮提出但尚未验证的假设。本地历史检索表仅用于定位论文，方法判断以原文为主。核对日期为 2026-10-26。

## 1. Semantic Steering：应借鉴什么

**论文：** [Semantic Steering for Controllable Generation: Tuning-Free Concept Erasure in Multimodal Diffusion Transformers](https://arxiv.org/abs/2608.12829)，arXiv:2608.12829v1。

**本地原文：** `papers/pub/2026_ACCEPTED_ACM_MM_2026_2608.12829_Semantic_Steering_for_Controllable_Generation_Tuning_Free_Concept_Erasure_in_Multimodal_Diffusion_Transformers.pdf`。本轮读取完整 PDF 提取文本，不只使用 `papers/metadata/` 中的开头两页。

### 1.1 实际方法

原文 §3.2、式 (3)–(4) 与 Figure 2 的操作顺序是：准备目标与安全替代的成对文本，在 DiT 中间 block、某个中间采样时刻提取表征；聚合两侧不同文本片段的内部 token 表征，跨文本对求差并缩放；推理时把得到的同一个方向注入连续的早中期 blocks 的文本 token 输出。

§3.3 与 §4.3 的消融明确讨论了构造层、注入层范围和采样时刻。SD3.5 的报告设置包括在 block 10、`t=0.5` 构造，注入 blocks 3–10；这是一组实验设置，不是所有 DiT 都应采用的通用层号。主实验包括 SD3.5-medium 与 FLUX.1-dev。

它虽然使用“文本 token”，干预对象仍是 **DiT 内部随图像状态演化的激活**，不是输入 prompt 字符串，也不是原生文本编码器的最终输出。向量注入不需要额外完整 DiT 分支，在线成本很低。

### 1.2 对本轮最有价值的启发

- 目标/对照成对设计比孤立概念词更有机会减少上下文干扰。
- 修改文本相关表示可以影响整幅图像，无需逐个图像 token 定位。
- 某些语义干预可以跨采样步复用，值得测量复用范围。

### 1.3 不能直接继承的结论

**“中间层最有效”不能推出“输入端同样有效”。** 原生文本条件还没有经历 DiT 的图文交互；同维数向量也不意味着坐标系可交换。

**线性插值训练路径不能保证学到的所有生成轨迹精确为直线。** 更不能单凭这一点证明内部语义方向在所有时刻与所有 prompt 下恒定。论文有相关经验支持，但本方案仍需测量输入响应随时间的变化。

**在两种模型上可用，不等于不依赖结构。** 该方法仍需找到可编辑的内部文本表示，并选择层或范围。研究输入/输出接口，是在减少这种依赖，而不是否定原方法的效果。

**安全 anchor 本身也会改变分布。** 例如身份替代不应无意中固定人口属性；风格替代若始终使用同一画风，也需要报告输出多样性。

## 2. DVE：应借鉴什么

**论文：** [Differential Vector Erasure: Unified Training-Free Concept Erasure for Flow Matching Models](https://arxiv.org/abs/2602.01089)，本轮方法依据为 v1。

**本地完整文本：** `papers/dit_primary_expanded_20261024/text/2602.01089.txt`。对应完整 PDF 位于 `papers/downloads/2026_ARXIV_2602.01089_Differential_Vector_Erasure_Unified_Training_Free_Concept_Erasure_for_Flow_Matching_Models.pdf`。

### 2.1 实际方法

原文 §4.1–§4.2、式 (6)、(8)、(9)：在同一个 latent、同一个时刻下，求安全 anchor 与目标概念的条件速度差；把用户速度在该方向上的投影与阈值比较；需要纠正时沿差分方向修正用户速度。

关键有两点：**方向取决于生成模型的实际输出；纠正具有选择性。** 它不需要某类 attention 或特定 block，因此已经具有比内部激活方法更弱的结构依赖。主实验使用 FLUX.1-dev；不能把“接口原则上可接入”写成已经在所有 flow DiT 上得到验证。

本地全文定位：方法约第 259–465 行；缓存与早期纠正约第 437–597 行；Appendix A 约第 1607–1695 行。文件摘要见 `sources.json`，避免行号随版本变化造成混淆。

### 2.2 成本缩减不是本轮的新发现

原文 §4.3 已提出：

- 通过少量代表 prompt，按 timestep 平均并缓存差分速度，推理时免去概念分支。
- 只在生成前期进行纠正，跳过后续步骤。

§5.4/Table 6 给出实际结果：其特定 FLUX 设置中，基础模型、完整在线 DVE、缓存 DVE、前 8 步纠正 DVE 的单图延迟分别为 5.45、16.37、5.49、8.56 秒。它们是原文设备和设置下的数字，本轮没有复测。缓存的速度优势伴随该表中部分质量与擦除指标的下降。

所以，“只在早期做”“离线缓存”“不进入内部 block”都不能作为 IRDE 独有贡献。比较成本时必须保留这些 DVE 变体。

### 2.3 关于投影门控，应保持什么判断

原文 Appendix A.1 用三个几何情形解释选择性，包括无关速度与概念差分近似正交。这有直观意义，但真实用户速度含有场景、构图、基础生成动态等共同成分。一个投影符号不自动等价于图像中是否出现该概念，也不自动成为跨模型可比较的风险概率。

因此，本轮首先沿用 DVE 门控，将它作为共同参照，单独记录漏检、误触发与近邻保留问题。若换成新的概念分数，必须另做消融，不能把门控改进误算为输入编辑的效果。

### 2.4 理论说明不应被扩大使用

Appendix A.2 引入速度 Jacobian 的低秩结构，并**假定**差分向量处于其语义子空间，接着用局部展开分析偏离。这个结论依赖相应定义和假设，不能推出“只影响目标概念”或“最终画质不会受损”。语义子空间本身还包含多个概念，限制在其中也不等于只改变一个概念。

该段对随时间变化的投影子空间求导时，也需要处理投影算子本身的变化；若将其视为固定的局部近似，应明确适用范围。本轮不以此建立新的全局安全或保留定理。

### 2.5 时间与符号需要核对

两篇重点论文采用的时间叙述不同。DVE v1 的正文中，数据/噪声插值、训练目标方向和采样更新的符号还需结合实际实现逐项对齐。实现 IRDE 时应先复现其目标速度修正，再转换到统一的生成方向；不能翻转速度符号后仍机械沿用原阈值和不等号。

这一点属于复现与接口检查，不作为“发现论文错误所以新方法成立”的论据。

## 3. 为什么主方案选择连接输入动作与输出响应

两篇论文分别证明某些内部语义差和输出速度差可以用于控制生成。它们并没有替本轮回答：**哪一种原生输入编辑，在当前生成状态下，能引起怎样的速度变化？**

IRDE 在这里增加一个可直接测量的中间步骤。输入方向只提出候选动作；最终是否采用以及采用多大幅度，取决于冻结模型的实际响应。输出速度参照没有被重新命名为新检测器，也没有把内部 steering 方向直接搬到输入坐标系。

然而，有限差分、局部线性近似、最小二乘以及响应匹配都是已有数值工具。论文的贡献必须来自这个问题的具体证据、方法效果和有用边界，而不是这些工具本身。

## 4. 必须正面对比的近邻

下表中的本地论文通过原文的方法部分核对；SAFREE 的概括依据其一手论文摘要与可读正文片段。旧架构上的实验不是本轮实验目标，提及这些方法是为了界定已有技术。

| 方法 | 与输入方案的重叠 | IRDE 必须说明的区别 |
| --- | --- | --- |
| [SAFREE](https://arxiv.org/abs/2410.12761) | 文本有害子空间过滤、自验证与采样侧干预 | 输入端、无训练和自适应并不新；关键应是实际速度响应对输入动作的校准 |
| GrOCE，arXiv:2511.12968 | 上下文文本关系、图引导选择性抑制 | 不再增加语义图；以当前 DiT 的输入响应选择修改，而非只依赖文本相似度 |
| [STG](https://arxiv.org/abs/2510.24012) | 采样过程中修改文本 embedding | 其安全函数作用于预测的干净图像并指导 embedding；IRDE 不使用外部图像安全函数和该反向梯度 |
| CRG，arXiv:2606.29801 | 从生成模型动态估计概念存在，再做负引导 | “生成模型自己提供概念证据”并不新；本轮的区别需落在输入动作的实现与验证 |
| PGCE，arXiv:2603.08271 | 成对上下文、多种概念原型、文本引导 | 图像 prototype 与文本 prototype 学习已存在；IRDE 主版本只用原生文本差与少数在线系数 |
| DP，arXiv:2604.10032 | 解析求解、擦除与保留约束，含现代模型的 embedding 编辑 | 小矩阵解析求解并不新；区分解析权重修改和每请求条件响应拟合 |
| HiRM | 从文本编码器侧控制目标概念，迁移到 FLUX | 输入侧或文本侧本身不构成创新；IRDE 不定位并训练特定编码器层 |
| [SHIFT](https://arxiv.org/abs/2604.09213) | 现代 flow Transformer 的 steering，含 pooled 分支 | 原生 pooled 条件也不是空白位置；需区别方向构造、条件识别和当前速度响应 |
| Erase but Preserve，arXiv:2608.12806 | 优化连续 anchor embedding，并在生成中替换目标表示，含 Z-Image | “可学习安全替代”已有强近邻；IRDE 主版本不学习永久 anchor，也不依赖显式目标片段在线匹配 |
| CASteer | 从成对条件构造跨步/跨层 steering 方向，有 DiT 相关实验 | 不把“成对方向 + 多步复用”当成原创；区别在实际干预接口 |

这里的区别是本轮提案的设计意图，尚不是对这些方法的性能结论。

## 5. 本轮补充核对的来源

### 5.1 相关但不是相同任务的输入敏感性工作

[Controllable Diverse Sampling through Pullback Directions](https://arxiv.org/abs/2610.14294) 的一手摘要已明确提出，利用条件 embedding 到图像映射的局部 pullback 几何寻找高敏感方向，以增加多样性。本轮仅核对摘要，未完成其全文比对。

这足以说明“利用输入到输出的局部敏感性”不是可无条件认领的新思想；不能据此断言它已经实现或没有实现 IRDE 的具体擦除流程。

### 5.2 新出现的 prompt 侧擦除近邻

[ASFCE: Adaptive Semantic Field for Training-Free Concept Erasure](https://openreview.net/pdf?id=2T1rIKmssO) 的一手检索结果显示了匿名稿摘要与开头，涉及语义场识别和上下文适配 anchor。本轮直接全文访问遇到 OpenReview 验证页面，因此只把它列为待做全文创新性核对的近邻，不据此确认架构、效果或公开发表状态。

主方案不依赖这篇未完成核对的稿件。正式投稿前需要重新读取其全文，以及继续检索与当前输入响应拟合更接近的工作。

### 5.3 单流 flow matching 模型的依据

[Z-Image 技术报告](https://arxiv.org/html/2511.22699v5) 的架构部分与 §4.3，以及 [作者仓库](https://github.com/Tongyi-MAI/Z-Image)，分别支持单流 S3-DiT 结构、flow matching 训练和可用模型变体的选择。

因此实验计划增加未蒸馏的 Z-Image，避免只在 FLUX 与 SD3.5 这类具有相近多模态结构的模型上声称架构无关。具体 checkpoint、版本和可编辑条件张量需在实施时锁定。其原生文本编码器即使使用 Qwen 系列，也属于模型自身组件，不等于额外接入 Qwen VLM 裁判。

## 6. 可以提出与暂时不能提出的贡献

**值得检验的贡献：** 在受限输入动作中近似实现差分擦除；用真实速度响应而非文本几何选择动作；测量输入控制能力及其跨时间、跨结构的变化；在相当擦除程度下改善保留，或在明确预算下减少在线速度分支。

**当前不能声称：** 首个 DiT 输入擦除、首个无外部分类器的生成动态检测、首个无训练自适应文本编辑、首个早期/缓存擦除、严格遗忘证明、全面优于 DVE 或 Semantic Steering。

若最终仅剩“用有限差分求系数，近似 DVE”，应将其定位为一种有效实现或诊断研究，而非在缺少证据时包装成新的概念擦除原理。
