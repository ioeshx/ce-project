# CRA：符号、公式与完整执行流程

日期：2026-10-29。本文件展开本轮提出的 [CRA 原方案](./CRA_20261029_fresh_proposal.md)，未读取本目录其他既有方法。以下公式定义一个可以实施和验证的算法，效果尚待实验验证。

## 1. 研究目标与符号

目标是：部署时输入普通 prompt，在尽量保留其他内容的情况下，降低一组预先配置概念的生成概率。CRA 使用两个小模块：区域定位器 D 与动作结果预测器 Q；DiT 主干参数始终冻结。

| 符号 | 含义 |
| --- | --- |
| \(p\) | 用户的普通生成 prompt |
| \(e(p)\) | 原模型已经计算的文本条件 |
| \(\mathcal C=\{c_1,\ldots,c_K\}\) | 离线构建时确定的待擦除概念集合 |
| \(K\) | 配置的概念数量 |
| \(\theta\) | 冻结的 DiT 参数 |
| \(N,L,M,d\) | 采样步数、DiT block 数、图像 token 数、隐藏维度 |
| \(n,\ell,i,k\) | 采样步、block、图像 token、概念索引 |
| \(x_n,t_n\) | 第 n 步的图像 latent 与 flow 时间 |
| \(H_{n,\ell}\in\mathbb R^{M\times d}\) | block 输入处的图像隐藏状态 |
| \(T_{n,\ell}\) | 对应的文本隐藏状态，适用于联合图文流 |
| \(R_{n,\ell}\in\mathbb R^{M\times d}\) | 原 block 本次计算的完整图像残差 |
| \(m_{n,\ell,i}\in\{0,1\}\) | 第 i 个图像 token 是否进入干预区域 |
| \(\mathcal W_w\) | 第 w 个短采样窗口 |
| \(a_w\in\mathcal A=\{1,1/2,0\}\) | 此窗口的残差写入强度 |
| \(\psi,\phi\) | D 与 Q 的辅助参数 |

使用 flow 时间约定：\(t_0=1\) 为噪声端，\(t_N=0\) 为数据端，生成时 \(t_{n+1}<t_n\)。block 之间的残差更新与采样器推进 latent 的更新是两个不同层级。

## 2. 生成过程：CRA 在哪里起作用

以 Euler 采样说明接口：

\[
x_{n+1}=x_n+(t_{n+1}-t_n)\,
v_\theta^{\mathrm{CRA}}(x_n,t_n,e(p)).
\tag{1}
\]

这里 \(v_\theta^{\mathrm{CRA}}\) 表示启用内部门控后的 DiT velocity 输出。采样器仍沿用原模型配置。式（1）的时间差为负，与从噪声端走向数据端的约定一致；实现时使用模型原生的时间定义和求解器。

在某个 block 中，先正常执行：

\[
(H^{\mathrm{raw}}_{n,\ell+1},T^{\mathrm{raw}}_{n,\ell+1})
=B_{\theta,\ell}(H_{n,\ell},T_{n,\ell},t_n,e(p)),
\qquad
R_{n,\ell}=H^{\mathrm{raw}}_{n,\ell+1}-H_{n,\ell}.
\tag{2}
\]

CRA 修改该 block 的图像输出，再将其送入后续 block。它控制式（2）的残差，随后所有 blocks 共同形成式（1）中的 velocity。

对于双流 DiT，\(R\) 可以取完整图像 block 的输出减输入；对于单流 DiT，只截取图像 token 对应行。\(R\) 已包含原模型的 modulation gate，CRA 在其外面额外乘一个标量。FLUX 官方实现提供了这些残差出口：[双流与单流 block 代码](https://github.com/black-forest-labs/flux/blob/main/src/flux/modules/layers.py)。

## 3. 定位器 D：从实际生成状态定位目标相关区域

先对每个 token 构造一个低维特征：

\[
z_{n,\ell,i}
=f_{\psi,\ell}\!\left(
\operatorname{norm}(h_{n,\ell,i}),
\operatorname{norm}(r_{n,\ell,i}),t_n
\right)\in\mathbb R^q,
\qquad q\ll d.
\tag{3}
\]

\(h_i,r_i\) 是 \(H,R\) 的第 i 行。\(f\) 可以用 32–64 维瓶颈和浅层网络实现。这里的降维用于辅助模块提取特征，完整残差仍在原来的 d 维空间中执行门控。

每个概念对应独立 sigmoid 输出：

\[
s_{n,\ell,i,k}
=\sigma\!\left(u_{\ell,k}^{\top}z_{n,\ell,i}+b_{\ell,k}\right),
\qquad
m_{n,\ell,i}
=\max_{k=1,\ldots,K}
\mathbf 1\!\left[s_{n,\ell,i,k}\geq\tau_k^{\mathrm{loc}}\right].
\tag{4}
\]

\(\tau_k^{\mathrm{loc}}\) 是第 k 个概念的定位阈值。掩码是所有已配置目标区域的并集。独立 sigmoid 允许多个概念同时激活。

### D 的监督从哪里来

离线生成最终图像后，用目标检测或分割获得各概念的区域，映射到 token 网格，记为 \(b_{j,i,k}\in\{0,1\}\)。j 表示一条生成轨迹。

\[
\mathcal L_D
=\mathbb E_{j,n,\ell,i}
\left[\frac1K\sum_{k=1}^{K}
\operatorname{BCE}(s_{j,n,\ell,i,k},b_{j,i,k})\right].
\tag{5}
\]

其中 \(\operatorname{BCE}(u,y)=-y\log u-(1-y)\log(1-u)\)。实际训练可平衡目标与背景样本。

最终区域向中间 token 的映射是近似监督。D 学到的是“该位置的内部状态与最终目标区域的关联”，其定位能力需要在未见提示和种子上检验。全局风格可使用图像级判定、整体掩码，另行验证。

## 4. 核心操作：决定本次残差允许写入多少

选定少量 blocks，记为 \(\mathcal L_*\)。每个短窗口 \(\mathcal W_w\) 包含一段连续采样步。只有当 \(n\in\mathcal W_w\) 且 \(\ell\in\mathcal L_*\) 时执行：

\[
\boxed{
h_{n,\ell+1,i}
=h_{n,\ell,i}
+\underbrace{\left[1-(1-a_w)m_{n,\ell,i}\right]}_{g_{n,\ell,i}}
r_{n,\ell,i}.
}
\tag{6}
\]

\(g_i\) 是实际写入系数：

| 掩码与动作 | 实际执行 |
| --- | --- |
| \(m_i=0\) | \(h_i^{out}=h_i+r_i\)，本次更新正常执行 |
| \(m_i=1,a_w=1\) | \(h_i^{out}=h_i+r_i\)，正常写入 |
| \(m_i=1,a_w=1/2\) | \(h_i^{out}=h_i+\tfrac12r_i\)，减半写入 |
| \(m_i=1,a_w=0\) | \(h_i^{out}=h_i\)，阻止本次写入 |

相对于原始输出，本次改变量恰好是：

\[
\Delta h_{n,\ell,i}
=-(1-a_w)m_{n,\ell,i}\,r_{n,\ell,i}.
\tag{7}
\]

因此，干预方向来自当前样本的原生残差，抑制强度限定在 0 到 1 之间。对于未选中的 token，本次出口的改变量为零；后续 attention 仍可能使其他位置受到间接影响。

式（6）限制的是新增更新。如果输入 \(h_i\) 已经包含足够的目标信息，令 \(a_w=0\) 也未必能擦除它。这正是需要通过终点实验选择窗口、blocks 和动作的原因。

### 为什么在窗口内固定强度

每个窗口入口只选择一次 \(a_w\)，窗口内各指定出口复用它；各出口的 \(m_{n,\ell}\) 随当前状态重新计算。

被评估的动作因而具有明确含义：“在这段采样过程中，对 D 识别出的目标相关残差持续采用强度 a”。初版可使用 1–2 个窗口、共 2–4 个 blocks。具体位置通过小规模标定决定。

## 5. 离线反事实：实际执行三个动作，观察最终结果

### 5.1 同一个入口的三种结果

记 \(S_w\) 为窗口入口的完整生成状态，包括当前 latent、已计算的隐藏状态和残差、文本条件，以及求解器需要的历史。固定 D、定位阈值和后续窗口策略 \(\pi_{>w}\)，分别执行三个动作：

\[
I_j^{(a)}
=\operatorname{Decode}\!\left(
\operatorname{Continue}_{\theta}
(S_{j,w};a,\pi_{>w})
\right),
\qquad a\in\mathcal A.
\tag{8}
\]

\(I_j^{(a)}\) 是对应的最终图像。三个分支保留相同 prompt、入口和后续随机数。各分支都按同一个 D 动态生成掩码；干预导致状态不同后，掩码可以相应不同。

这里改变的控制变量是 a，没有额外输入一条 target prompt 或 anchor prompt。

### 5.2 用最终图像定义概念标签与保留标签

对所有目标执行离线标注：

\[
y_{j,k}^{(a)}=\mathcal J_k(I_j^{(a)})\in\{0,1\}.
\tag{9}
\]

\(\mathcal J_k\) 是第 k 个概念的离线标注器，1 表示目标出现。此阶段可以使用目标名称、视觉判别器或人工标注。

再从原 prompt 提取非目标保留描述 \(p_j^{keep}\)，定义保留不达标标签：

\[
b_j^{(a)}
=\mathbf 1\!\left[
S_{\mathrm{sem}}(I_j^{(a)},p_j^{keep})<\gamma_{\mathrm{sem}}
\quad\lor\quad
S_{\mathrm{img}}(I_j^{(a)})<\gamma_{\mathrm{img}}
\right].
\tag{10}
\]

\(S_{sem}\) 评价非目标语义保留，\(S_{img}\) 评价画面质量，\(\gamma\) 为离线评价阈值。局部目标可以增加目标区域之外的背景与布局评价。b=1 表示保留或质量不达标。

例如，原提示要求“某目标角色与一只普通小狗站在草地上”，保留评价应覆盖“小狗、草地、场景关系及画面质量”，而非继续要求目标角色必须出现。\(p^{keep}\) 只用于离线评价，不作为生成条件。

相同入口下的 \(y_{j,k}^{(1)}-y_{j,k}^{(a)}\) 表示该次干预是否消除了目标；\(b_j^{(a)}-b_j^{(1)}\) 则记录保留结果的变化。这些配对结果提供动作监督，不要求残差与语义之间存在全局线性关系。

## 6. Q：把反事实续采样结果压缩成在线预测

### 6.1 输入与输出

在窗口入口，将低维特征、定位分数、残差范数及掩码面积汇聚为摘要：

\[
\xi_w=\operatorname{Pool}
\left(Z_w,\{s_{w,i,k}\},\{\lVert r_{w,i}\rVert\},m_w,t_w\right),
\]
\[
Q_{\phi,w}(\xi_w,a)
=\bigl(\hat p_{w,1}(a),\ldots,\hat p_{w,K}(a),\hat d_w(a)\bigr).
\tag{11}
\]

Pool 可以采用 mean、max 和区域占比，Q 使用浅层 MLP。必要时可拼接原模型已经算好的文本条件的低维摘要，以帮助判断内容保留。

- \(\hat p_{w,k}(a)\)：采用动作 a 并执行后续窗口策略时，最终出现概念 k 的预测概率。
- \(\hat d_w(a)\)：相同执行流程下，非目标保留或画面质量不达标的预测概率。

Q 的预测建立在压缩状态摘要上，其准确性通过标定检验；这里不假设摘要是完整生成状态的充分统计量。

### 6.2 监督训练

将式（8）至（10）的真实结果作为标签：

\[
\mathcal L_Q
=\mathbb E_{j,w,a}
\left[
\frac1K\sum_{k=1}^{K}
\operatorname{BCE}(\hat p_{w,k}(a),y_{j,k}^{(a)})
+\lambda_{\mathrm{ret}}
\operatorname{BCE}(\hat d_w(a),b_j^{(a)})
\right].
\tag{12}
\]

\(\lambda_{ret}\) 控制保留标签的训练权重。训练过程中 \(\theta\) 固定，仅更新辅助网络。

单窗口时，动作之后直接运行原模型到终点。双窗口时，先训练后窗口，再固定其策略，为前窗口收集动作结果。最后用一轮闭环轨迹补充实际部署状态上的样本，更新 Q 与决策阈值。

**收集 Q 的动作数据期间，D 与定位阈值保持固定。**若改变 D 或窗口内执行规则，应重新标定相应动作结果，确保 Q 预测的动作含义与部署一致。

## 7. 在线决策公式

### 7.1 优先选择满足约束、写入量最大的动作

令 \(\tau_k^{risk}\) 为概念 k 的预测残留阈值，\(\tau^{bad}\) 为保留不达标概率阈值，定义：

\[
\mathcal F_w
=\left\{a\in\mathcal A:
\hat p_{w,k}(a)\leq\tau_k^{risk}\ \forall k,
\quad\hat d_w(a)\leq\tau^{bad}
\right\}.
\tag{13}
\]

若集合非空：

\[
a_w^*=\max\mathcal F_w.
\tag{14}
\]

动作的数值就是写入量。因此，正常写入满足条件时选 1；减半已经满足时优先选 1/2。

### 7.2 三种动作都未通过时

可使用预先固定的折中规则：

\[
a_w^*=\arg\min_{a\in\mathcal A}
\left\{
\max_k\left[\hat p_{w,k}(a)-\tau_k^{risk}\right]_+
+\lambda_{\mathrm{bad}}
\left[\hat d_w(a)-\tau^{bad}\right]_+
\right\},
\tag{15}
\]

其中 \([u]_+=\max(u,0)\)，分数并列时选择更大的 a。\(\lambda_{bad}\) 在离线标定后固定。

式（13）的条件基于预测值，不能当作最终擦除保证。式（15）表示候选动作都未通过时的明确执行规则，也不能视为已经满足要求。

### 7.3 一个数值例子

假设部署两个概念，设 \(\tau_1^{risk}=\tau_2^{risk}=0.1\)、\(\tau^{bad}=0.1\)。以下数字仅用于说明决策：

| 动作 a | 目标 1 残留预测 | 目标 2 残留预测 | 保留不达标预测 | 判定 |
| --- | --- | --- | --- | --- |
| 1 | 0.86 | 0.62 | 0.02 | 目标风险超标 |
| 1/2 | 0.08 | 0.06 | 0.07 | 三项通过 |
| 0 | 0.04 | 0.03 | 0.23 | 保留风险超标 |

选取 \(a_w=1/2\)，在该窗口内对目标区域减半写入，对其他位置正常写入。

## 8. 多概念与无需在线输入 target 的含义

\(K=1\) 时是单概念版本。\(K>1\) 时使用式（4）的区域并集，并用式（13）同时检查各个概念。每个出口只对原生残差执行一次式（6），候选动作数量始终为三。

Q 输出各概念的预测残留，\(\max_k\hat p_k\) 是最大单概念风险，不是“任意一个概念出现”的联合概率；正式评测需另外报告联合残留率。

部署包可写为：

\[
\mathcal B_{\mathcal C}
=\left(
\psi,\phi,\mathcal L_*,\{\mathcal W_w\},
\{\tau_k^{loc},\tau_k^{risk}\},\tau^{bad},\lambda_{bad}
\right),
\]
\[
I=G_{\theta}^{\mathrm{CRA}}(p,\varepsilon;\mathcal B_{\mathcal C}).
\tag{16}
\]

\(\varepsilon\) 是初始噪声。\(\mathcal C\) 已在构建部署包时确定，模块权重与输出头保存了待识别的信息。在线调用仅需普通 prompt 与种子。

普通 prompt 本身可以直接或间接描述目标；用户无需额外指定“这次要擦除哪个概念”。此处的预先配置与每次推理时额外输入目标是两个不同阶段。整个方法没有引入 anchor 生成条件。

## 9. 算法流程

### 离线

1. 对目标、隐式表达及邻近保留提示运行原模型，保存候选 blocks 的状态和最终区域标签。
2. 按式（5）训练 D；筛选少量可检测的 blocks 和窗口，再通过真实干预检查其可控制性。
3. 固定 D、定位阈值和动作定义，按式（8）从相同入口执行三个动作，得到式（9）（10）的终点标签。
4. 按式（12）训练 Q；双窗口按从后到前的顺序标定。
5. 进行一轮闭环补样，标定决策阈值，导出式（16）的部署包。

### 在线

```text
输入：普通 prompt p、初始噪声，以及预先构建的部署包

e = 原模型文本编码器(p)

for 每个采样步 n:
    将当前 latent 转为图像 token，并按原模型初始化文本状态

    for 每个 block l:
        正常计算 H_raw、T_raw
        R = H_raw - H

        if (n, l) 属于指定干预出口:
            用 D 计算低维特征、概念分数、区域并集 m

            if 这是当前窗口的第一个干预出口:
                用 Q 批量预测 a ∈ {1, 1/2, 0} 的结果
                按式（13）至（15）选择当前窗口动作 a_w

            H = H + [1 - (1 - a_w) m] ⊙ R
        else:
            H = H_raw

        T = T_raw

    输出 velocity，按原生采样器推进 latent

按原模型解码最终 latent
```

式中 m 沿隐藏通道维广播。在线只运行这一条 DiT 生成流程；三种动作的 Q 预测可以批量计算，三条真实续采样分支仅存在于离线标定阶段。

## 10. 计算量与需要验证的机制

### 在线

相同采样配置下：

\[
\operatorname{NFE}_{\mathrm{CRA}}
=\operatorname{NFE}_{\mathrm{base}}.
\tag{17}
\]

这指完整 DiT 调用次数相同。新增成本来自少量出口的低维特征、D、Q 和残差缩放，实际延迟与显存需要测量。有外部 CFG 时，对原有两个分支按其原生流程标定，共用门控决策；分支状态摘要一并提供给 Q。

### 离线

若基础生成次数为 \(N_{base}\)，一次原生完整生成需要 \(F_{base}\) 次 DiT 前向，第 b 条续采样所需计算为 \(C_b\) 次完整 DiT 前向等价量，则：

\[
C_{off}=N_{base}F_{base}+\sum_b C_b,
\qquad 0<C_b\leq F_{base}.
\tag{18}
\]

在每步一次 DiT 前向的配置下，\(F_{base}=N\)；有外部 CFG 时按原生分支数计量。该式要求入口来自已经计入的轨迹，且缓存可复用；额外生成入口的成本应加入 \(N_{base}\)。原方案的预算展开为 96 次基础生成、16 条筛选续采样、144 条标定续采样，以及闭环阶段 8 次入口生成和 24 条续采样，粗上界为 **288 次完整生成等价量**。原先的 280 次漏计了闭环入口获取，已同步更正。多概念联合标定、正式测试和标签评价另计。

### 两个最关键的机制检验

1. **可控制性**：在相同入口真正执行三个动作后，是否至少有一个动作能同时降低目标残留并保留其他内容？用终点标签选出的最佳候选动作给出该动作集合的经验上限。
2. **可预测性**：在候选动作确实有效的前提下，Q 能否从入口摘要选到有用动作？与相同 D、相同出口、固定动作的方案比较，检验结果监督的贡献。

这些公式只要求对有限动作做实际标定与监督预测。残差衰减的选择性、可检测与可控制时间的重叠，以及低维摘要的预测能力，均由实验决定。
