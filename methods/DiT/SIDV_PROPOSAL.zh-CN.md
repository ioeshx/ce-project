# SIDV：语义索引的局部 velocity 差分擦除

日期：2026-10-26。工作名：**Semantically Indexed Differential Velocity（SIDV）**，仅为本提案的名称。

状态：研究构思，已核对主要相关工作；尚未实现、构建差分表或进行真实 DiT 实验。本方案与 FRS 并列，探索另一条路线。

## 1. 核心切入点

**把“目标概念的平均擦除方向”，改成“当前局部内容所需要的反事实 velocity 修正”。**

DVE 在相同 noisy latent 和时间下，对比 anchor 与目标提示的 velocity，再据此修正生成方向。其 §4.3 已经提出离线缓存每个时间步的平均差分，降低在线开销。因此，“预计算差分”“不增加在线 NFE”本身均不能作为新贡献。[DVE](https://arxiv.org/html/2602.01089)

本方案关注平均缓存可能丢失的状态依赖性：同一角色处于左侧、右侧、正面或侧面时，所需的局部速度修正可能不同。把整张差分场按固定空间位置平均，可能稀释这些变化。这里的“可能”是待检验的动机，不是已经证实的 DVE 缺陷。

拟构建一张很小的表，记录：

> 当 DiT 的某个图像 token 呈现这种内部表示时，对应的 velocity patch 应当怎样变化。

在线利用原有前向已经产生的图像 token 表示查询这张表，修正最终输出的 velocity。没有额外条件分支，没有重生成，没有外部图像判断器，也不训练神经网络控制器。

这是 **冻结生成模型、离线无梯度统计构建、在线非参数 velocity 修正**。聚类与少量超参数选择仍属于数据依赖的构建过程；不能称为完全没有离线成本。

## 2. 与前一方案的区别

FRS 研究隐藏空间中的注入方向如何经过后续网络转化为采样变化，需要测量脉冲响应并校准系数。

SIDV 直接储存生成模型给出的 velocity 差分。内部表示只用来选择适合当前状态的修正，最终干预发生在 velocity 输出端，不注入隐藏向量、不拟合层间控制系数。

它需要读取一处图像 token 表示，以及建立这些 token 与输出 velocity patch 的对应关系。因此，不依赖特定 attention、single-stream 或 double-stream 操作，但也不是完全只访问 velocity 的黑盒方法。不同 DiT 需要轻量的取特征与 packing 适配；字典需按模型分别构建。

## 3. 离线：从生成模型自身得到差分样本

### 3.1 成对提示与保留提示

人工准备少量仅替换目标语义的提示对，例如：

```text
Snoopy sitting beside a golden retriever on a beach.
A generic cartoon dog sitting beside a golden retriever on a beach.
```

另外准备普通狗、其他卡通角色、金毛、人物与风景等保留提示，包含语义近邻及“目标与保留对象共存”的上下文。

替代语义由擦除任务指定。若要擦除整个狗类别，就不能把普通狗当作替代。人工指定的替代提示也不意味着模型生成结果已经被认证为不含目标概念。

### 3.2 在同一状态上计算反事实差分

沿目标提示的原生采样轨迹收集状态。在同一个 `z_k`、同一个时间步和相同原生 guidance 设置下，运行目标提示 `c` 与替代提示 `a`，得到局部差分：

\[
d_{k,i}=v_\theta(z_k,t_k,a)_i-v_\theta(z_k,t_k,c)_i.
\tag{1}
\]

`i` 是输出 velocity 的一个 patch，包含该 patch 的全部 latent 通道。不能用两条不同状态的轨迹输出直接相减；那会混入状态变化。

读取某一 Transformer block 的图像 token 表示 `h`，构成键值样本：

- 目标分支：`(q(h_c,i), d_k,i)`。
- 同状态的替代分支：`(q(h_a,i), 0)`。
- 保留轨迹：`(q(h_r,i), 0)`。

目标分支的所有 patch 均记录真实差分，不把整张图的每个 patch 标成“含目标”。背景 patch 的差分是否较小，也需要测量，不能预先假定。

这里的零值表达的是**希望不修改替代与保留提示的输出**，属于任务约束，不是概念分类标签。若目标分支与保留分支的表示无法区分，查表会产生冲突；该失败情形不能通过换名称回避。

### 3.3 键与字典的最小构造

初版每个采样时间步使用独立字典，避免跨时间直接混合 velocity 幅值。所有空间位置共用该步的字典。

键 `q(h)` 使用逐 token 归一化和一个固定随机降维矩阵，再做单位长度归一化。随机矩阵固定、不学习。可从 128 维开始；这只是起始工程设置，不是已验证最优维度。

在目标差分样本与零响应样本内分别聚类，保存簇的平均键与平均差分，形成例如 64 个差分原型和 64 个零响应原型。聚类只用于压缩采样统计，没有反向传播。应同时保留较大原始样本表作为诊断对照，以检查压缩是否丢失关键模式。

只读取一个 block。候选可先比较网络中部和后部的两个位置，用独立验证轨迹上的差分重建误差与保留扰动选定；不为每一步引入独立的可学习选层器。

不向键显式添加固定二维坐标，使同一种局部内容可以跨位置检索。但 DiT 自身表示可能带有位置编码，因此这不保证真实模型具有平移等变性。跨位置泛化必须单独实验。

## 4. 在线：一次查询，同时得到方向与强度

正常运行一次 DiT，得到用户提示下的原始 velocity `v_p` 与键 `q_i`。对当前步字典中的原型 `(k_j,d_j)` 计算相似权重：

\[
\kappa_{ij}=\frac{1}{K}\exp\left(-\frac{\|q_i-k_j\|^2}{2\tau^2}\right),
\qquad
\widehat d_i=
\frac{\sum_j\kappa_{ij}d_j}{\lambda_0+\sum_j\kappa_{ij}}.
\tag{2}
\]

其中 `tau` 是邻域宽度，`lambda_0 > 0` 是零修正先验的权重。两者用独立的目标／保留轨迹选择，不借助外部概念判断模型。

最终修正：

\[
\widetilde v_{p,i}=v_{p,i}+\alpha\widehat d_i.
\tag{3}
\]

初版从 `alpha = 1` 开始做强度曲线。表中保留 velocity 的实际幅值，不把所有差分归一化为单位方向。

这个构造有三个直观行为：

1. 与某种目标局部状态接近时，取出该状态对应的修正方向和幅值。
2. 与零响应样本接近时，零值在同一次插值中占据权重，修正被压低。
3. 与整个字典都相距较远时，分子趋近零，固定零先验避免算法被迫选择一个不相关方向。

不额外增加二值概念判断器。第二点也不是绝对保护：零响应与非零响应原型重叠时，插值仍可能改动保留内容。

示例：假设离线看到过目标角色的正面与侧面，它们对应两种不同修正。在线出现一个右侧的侧面角色时，理想行为是检索侧面修正并施加到右侧 patch；旁边普通狗的 patch 接近零响应样本，受到较小改动。这是方法想实现的行为，尚不是实验结果。

## 5. 数学只解释真实操作，不附加分布假设

式（2）恰好是下面局部二次问题的解：

\[
\widehat d_i=\arg\min_u
\left[\sum_j\kappa_{ij}\|u-d_j\|^2+\lambda_0\|u\|^2\right].
\tag{4}
\]

它要求修正接近相似状态的反事实差分，同时对无充分支持的修改施加收缩。零响应样本直接参加同一个目标，而非事后再挂一个复杂门控网络。

这是已有的核局部回归思想；公式与求解本身不是创新。它不假设概念线性可分、真实 flow 严格笔直或生成分布服从高斯。

由非负权重还能得到一个简单的实现性质：插值结果位于所有缓存差分与零向量的凸包内，其范数不超过缓存差分的最大范数。此结论针对 `alpha = 1`、CFG 放大之前的插值量，不意味着采样轨迹稳定，更不意味着概念已擦除。

本方案真正需要验证的经验条件只有核心的一条：

> 在合适的 DiT 图像表示中，相近局部状态需要的反事实 velocity 修正也足够接近。

实际表示可能主要编码噪声、位置或普通纹理；相同语义也可能需要方向相反的局部修正。如果上述条件不成立，非参数检索就不能替代实时差分。

不宣称核估计一定优于 DVE 的逐位置平均场。前者把位置共享并按表示分组，后者保留固定位置而跨参考轨迹平均，两者存在不同的偏差与方差，必须直接比较。

## 6. Flow matching 与 CFG 的接入

式（1）始终使用同一模型、同一 scheduler 约定下的原生 velocity。对 Euler 更新 `z_next = z + delta_t * v`，修正造成的本步状态变化就是 `delta_t * alpha * d_hat`。即使 scheduler 使用递减时间，也不应再凭直觉额外翻转差分符号。

对于真正的两分支 CFG，在正条件分支修正，然后照常合成：

\[
\widetilde v_{\mathrm{CFG}}
=v_0+s\big(v_p+\alpha\widehat d-v_0\big)
=v_{\mathrm{CFG}}+s\alpha\widehat d.
\tag{5}
\]

这给出一个明确的代数检验：若 `p = c`、`alpha = 1`，并且查表恰好重建同状态的 `v_a - v_c`，修正后的输出恰好等于替代提示的 CFG 输出。实际查表存在误差，因此这只是对接入方式的检查，不是实际擦除保证。

只对正条件分支读键和施加修正，无条件分支保持原生计算。大 CFG 会放大差分估计误差，必须报告随 CFG 强度变化的表现。

FLUX 的原生 guidance embedding 不等价于上述两分支 CFG。使用其单分支原生管线时，直接应用式（3），不为本方法额外添加无条件分支；构表与部署采用相同原生 guidance 参数。支持真实 CFG 的模型使用式（5）。

初版围绕本项目的 flow matching DiT 开展：bf16、512×512，FLUX.1-dev 为 28 步；其他设置复用相应基线。更换采样时间表、模型或分辨率时，先重新检查字典兼容性，不预设跨配置通用。

## 7. 两个候选贡献及其边界

**候选贡献一：按内部内容组织局部反事实速度场。**

研究对象是状态依赖的、多方向的 velocity 修正。用同一 DiT 的图像表示索引这些差分，把昂贵的在线反事实计算压缩为随当前内容变化的局部查询。缓存方式从“每一步的一张平均场”，变成“每一步的一组内容—修正对应关系”。

**候选贡献二：用零响应反事实样本约束同一速度插值。**

替代分支和近邻保留分支进入相同的差分估计过程，明确表达哪里应接近零修改。与数据支持不足时的零先验结合，在方向选择与保留之间形成一个可分析、可消融的统一估计式。

两者目前都是待验证的贡献表述，不是已成立的新颖性结论。检索、聚类、核回归、局部干预、零响应正则化和缓存各自都有既有基础。

一个尤其重要的退化情形是：如果所有非零值都等于同一方向 `d_bar`，式（2）就退化成 `g(q_i) * d_bar`，即自适应门控的固定 steering。本方案只有在**不同局部状态确实需要不同方向，且检索这些方向显著优于同键同权重下的固定方向**时，才能支持第一项贡献。不能把一个复杂门控器包装成新的速度场方法。

## 8. 与最接近工作的区别

| 工作 | 已有要点 | 本方案需要体现的增量 |
|---|---|---|
| DVE | anchor−target 差分、投影式选择修正，以及逐时间步平均差分缓存 | 内容索引的局部差分重建；需同时比较实时版和缓存版，不能把缓存声称为新增 |
| Semantic Steering | 从内部表示构造 steering 并注入模型 | 内部表示只作索引，值是直接测得的 velocity 差分，干预发生在输出端 |
| GLoCE | 利用图像表示、解析低秩变换与门控实现局部擦除 | 不把局部性或使用图像 token 当作创新；比较隐藏空间固定变换与内容相关输出修正 |
| ActErase | 用成对提示的激活差异确定并应用 activation patching | 保存的是同状态的局部输出差分，不替换 FFN 激活；不能把成对提示或离线构建当作创新 |
| SafeDenoiser | 利用待排除图像集合与核加权构造安全 denoiser | 这里的值为模型自身成对条件的局部 velocity 差分，键为内部图像表示；需承认核加权缓存有先例 |

## 9. 成本：明确区分在线和离线

在线每步保留原生模型调用次数，增加一处取特征、键的降维、相似度矩阵和加权求和。没有额外解码，没有外部模型，没有搜索候选图。

若有 `N` 个图像 token、`K` 个原型、键维度 `d_q`、velocity patch 维度 `d_v`，查表复杂度约为 `O(N K (d_q + d_v))`。此外还有从原始隐藏维度 `d_h` 降到 `d_q` 的 `O(N d_h d_q)` 成本，不能漏算。原生 NFE 不变不等于实际耗时不变，需要测量 hook、矩阵运算和显存开销。

举例，仅假设 `T=28, K=128, d_q=128, d_v=64`，以 bf16 保存每步键值，字典约为 1.31 MiB；降维矩阵和运行时张量另算。这是尺寸计算，不是实测显存。

离线若使用 16 条目标轨迹、16 条保留轨迹、每条 28 步，并在每个目标状态增加一次替代提示前向：单分支模型需要 `32×28 + 16×28 = 1344` 次 DiT 样本前向，约等于 48 次完整 28 步生成的前向量。这里复用目标轨迹已有的输出，并把替代分支的表示同时作为零响应样本。

真正的两分支 CFG 若复用同状态无条件输出，对应计数为 `2×32×28 + 16×28 = 2240`。独立验证轨迹、超参数选择和后续实验另计。批处理可以缩短墙钟时间，不能改变按样本计数的 NFE。

这些数量是初版预算，不是必要样本量结论。它把成本移到每个概念的一次构建中，适合重复使用；只生成一张图时未必划算。

## 10. 实验先检验核心机制，再做完整擦除评估

### 10.1 第一阶段：差分是否可预测

在与构表数据分离的提示模板、seed、对象位置和姿态上，离线计算真实成对差分作为参照。比较：

1. DVE 风格的逐时间步、逐固定位置平均差分。
2. 所有 patch 共享的单一平均差分。
3. 本方案的内容索引局部差分。
4. 同样的查询与权重，但把所有非零值换成同一平均差分。
5. 打乱键值对应关系；以及较大原始样本表对比压缩字典。

报告非近零 patch 的方向余弦、幅值误差、整体重建误差，以及保留提示上的修正能量。不能让大量接近零的背景 patch 掩盖目标相关变化；按真实差分范数分组报告，但不要把“大差分”解释成语义真值。

层选择、带宽和零先验在验证集确定；最终报告使用另一个测试集。再沿实际编辑后的轨迹检查相同量，以暴露原始轨迹构表带来的状态分布偏移。

若状态索引不能在未见状态上优于平均差分，或打乱键值后效果不变，核心动机就缺乏支持。不要靠增加多个门控模块掩盖这个结果。

### 10.2 第二阶段：擦除与保留

先测试一个有明确近邻类别的角色／物体擦除任务，之后再扩展艺术风格等更全局的概念。局部索引对风格擦除是否适用尚不明确。

生成任务至少包含：直接请求目标、别名和描述式请求、目标与保留对象同图出现、近邻保留概念，以及与擦除目标无关的 COCO 提示。最后一组检验通用生成能力的变化，不单独证明擦除有效。

擦除效果与近邻保留可先用人工盲评确认；同 seed 的背景改动可用人工圈定区域的像素误差、SSIM 辅助分析。内部差分重建误差仅是机制指标，不能替代图像层面的擦除判断。本方案的构建与推理不调用外部评估模型。

对比基础模型、DVE 实时版、DVE 缓存版、同键固定方向版本，以及可适配同一 DiT 的局部 steering／擦除基线。统一采样配置，报告质量—擦除—时延曲线，而非只比较一个任意强度。

零响应样本、零先验和近邻保留样本分别消融。至少在两种 flow matching DiT 上重新构表验证，不把跨架构接口可用等同于效果已泛化。

### 10.3 有解释力的可视化

- 同图并列展示原始结果、DVE 缓存结果、同键固定方向结果、本方案结果。
- 每步的局部修正范数、零响应权重占比和主要检索原型分布。
- 同一目标在左／右位置与不同姿态下，真实差分和预测差分的方向一致性。
- 随时间变化的重建误差、保留扰动与实际效果。
- 原型数量—误差—时延曲线，检验收益是否来自更准确的状态匹配。

## 11. 最主要的风险与判断标准

最主要的风险不是公式复杂，而是**语义相似不等于可复用同一局部速度修正**。velocity 还受当前噪声、纹理、姿态和全局上下文影响，键可能无法同时保留这些信息。

其次，成对提示可能改变构图或其他属性，即便固定同一状态，输出差分也未必只包含目标概念。保留零响应可以限制部分误改，却不能保证分离纯净语义。

编辑后的轨迹还可能离开原始构表状态的覆盖范围；远离字典时回到零修正，有利于避免乱改，却也可能让擦除失效。该取舍应通过编辑轨迹诊断和真实图像实验呈现。

本方案值得优先验证的理由是：它把 DVE 的成本问题与差分场的状态依赖性联系起来，有一个直接可测的中间对象。是否形成有分量的方法，取决于“局部状态对应多种有用修正”这一点能否得到实验支持，而不是字典或核函数本身的新颖性。
