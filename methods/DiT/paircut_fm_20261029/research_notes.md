## 1. DiT / flow-matching 直接相邻方法

| 文献 | 已有核心操作 | 对 PairCut-FM 的设计约束 |
|---|---|---|
| [EraseAnything，ICML 2025](https://proceedings.mlr.press/v267/gao25j.html) | 双层优化、LoRA 更新、注意力正则与自对比保留 | 将注意力抑制加入少量 LoRA 训练，已有直接先例 |
| [DVE，2026-02](https://arxiv.org/html/2602.01089v1) | target/anchor 速度差分，按投影选择性修正；另有预计算差分与早期干预版本 | “预计算概念方向、运行时自动触发、无额外概念前向”本身已有覆盖 |
| [SHIFT，2026-04](https://arxiv.org/html/2604.09213) | 在 DiT 中间激活上施加概念 steering，含分类器控制与跨时间分析 | 激活向量加减及分类器门控不能作为本设计的主要新意 |
| [SafeRoPE，CVPR 2026](https://arxiv.org/html/2604.01826) | 从风险 Q/K 建立低秩子空间，选择关键 head，学习风险分数调节的正交旋转 | Q/K 风险识别、关键 head 定位与轻量干预已有覆盖；必须检验类型对编辑相对于单端编辑的价值 |
| [Semantic Steering，2026-08](https://arxiv.org/html/2608.12829) | 中间 block 的不期望/安全文本表征差，向早中期 block 的文本分支注入 steering | “只动少量文本 token、预计算后低开销部署”也已有覆盖 |
| [Double Projections，CVPR 2026](https://arxiv.org/html/2604.10032) | 代理构造与受约束的闭式双投影；包含 FLUX 实验 | 将目标子空间投影到保留空间，已有明确几何编辑路线 |
| [Z-Erase，ICML 2026](https://proceedings.mlr.press/v306/jiang26i.html) | 单流 DiT 的流分离更新与自适应擦除调制 | 单流架构上的擦除稳定性本身已有研究；需要独立标定与验证 |
| [EraseAnything++，2026-03](https://arxiv.org/abs/2603.00978) | 约束多目标优化、梯度协调与 LoRA，扩展至图像和视频 | 本设计将多概念扩展放在共享传输规则与联合标定上 |

**最接近的直接基线是 SafeRoPE。** 两者都利用 Q/K、head 选择和当前内部状态。需要检验的具体差别是：固定某个 key 簇时，是否可以保留它与多数 query 簇之间的注意力作用，仅抑制少量 query–key 聚类组合；固定 query 簇时亦同。若规则实际等价于屏蔽整个 key 簇或 query 簇，实验便没有显示聚类组合编辑的额外价值。

## 2. 跨架构相邻方法与近期重合检查

| 文献 | 已有核心操作 | 本设计的具体区分 |
|---|---|---|
| [GLoCE，CVPR 2025](https://arxiv.org/html/2503.12356) | 预计算低秩编辑与概念门控，按图像位置激活；含 SD3 验证 | 直接比较 value/hidden 编辑与 attention 连接编辑，隔离门控这一共同因素 |
| [ActErase，2026-01](https://arxiv.org/html/2601.00267v1) | 从 prompt 对找 FFN 激活差异，缓存并替换对应激活 | PairCut-FM 保存类型和连接规则，干预时沿用当前样本的 value |
| [Forget-It-All，2026-01](https://arxiv.org/html/2601.06163v1) | 对比显著性定位概念敏感神经元，合并多概念剪枝掩码 | 本设计合并 query–key 聚类组合，不以神经元剪枝为擦除操作 |
| [CASteer，2025 / 2026 修订](https://arxiv.org/abs/2503.09630) | 离线概念 steering 与动态局部干预，包含 DiT 类模型验证 | 自动触发和局部性是共同能力；重点比较实际编辑单位 |
| [GrOCE，CVPR 2026](https://arxiv.org/html/2511.12968) | 构建词汇概念语义图，定位目标簇并处理文本条件 | PairCut-FM 的连接是一次真实 DiT 运算中的注意力传输；在线只查离线表 |
| [Prototype-Guided Concept Erasure，CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/html/Cai_Prototype-Guided_Concept_Erasure_in_Diffusion_Models_CVPR_2026_paper.html) | 聚类概念表征得到多个原型，以负条件引导擦除 | 码本在本设计中只负责离散赋型，编辑由传输对表执行 |
| [HGSS，2026-10](https://arxiv.org/html/2610.07337) | 层级目标 span 定位，借助反事实参考与逐步优化保留属性绑定 | 组合概念与绑定保护已有研究；本设计采用离线验证后固定部署的内部连接规则 |
| [EraseSAE，2026-09](https://arxiv.org/abs/2609.03629) | 视频 DiT 的稀疏特征分解、对比归因与时空掩码擦除 | 本设计使用小型 Q/K 聚类与连接编辑，省去 SAE 训练和在线重建 |
| [Concept Acupuncturist，2026-10-23](https://arxiv.org/abs/2610.32059) | SAE 辅助定位和校正，通过局部微调消除在线模块 | 近期解释性引导擦除的相邻工作；其摘要明确实例化于 U-Net / SDXL-Turbo |

ActErase、FIA、HGSS 等在这里用于核查操作重合；本设计的模型验证范围保持为 flow-matching DiT。

检索结论是：已核查方法覆盖了方向编辑、激活替换、神经元屏蔽、概念门控、语义图处理以及风险 Q/K 旋转。PairCut-FM 将拟贡献限定在“生成结果验证的传输对选择 + 原表征保留的注意力分数编辑 + 查表部署”。新颖性判断仍需结合实现与对应基线实验。

## 3. 可解释性依据与推论的边界

| 原始研究 | 可直接借用的事实 | 本设计提出的推论 |
|---|---|---|
| [ConceptAttention](https://arxiv.org/abs/2502.04320) | DiT 注意力输出表征支持概念定位 | 优先从注意力通信寻找擦除位置；显著图用于辅助检查 |
| [Circuit Mechanisms for Spatial Relation Generation in Diffusion Transformers](https://arxiv.org/html/2601.06338) | 受控任务中的 DiT 通过特定注意力电路读取条件信息；T5 会改变信息组织方式 | 在真实模型中检验 query–key 聚类组合，并覆盖上下文化后的非目标词位置 |
| [Interpreting Large Text-to-Image Diffusion Models with Dictionary Learning](https://arxiv.org/abs/2505.24360) | FLUX 表征可通过 SAE / ITDA 分解和解释，也可用于控制 | 语义结构值得探索；主方案先用轻量码本，效果由干预实验确认 |
| [Attention Sinks in Diffusion Transformers: A Causal Analysis](https://proceedings.mlr.press/v306/wu26ax.html) | 高注意力接收量与生成语义的重要性可以分离 | 使用实际图像结果、随机连接与端点对照共同筛选规则 |

本设计只需要验证一个关键工作假设：在指定模型、采样配置和概念上，存在可被小型码本覆盖、且具有选择性擦除效果的传输对。该假设包含三个可测部分：覆盖率、擦除收益、相邻概念保留。

## 4. 最小实验闭环

### 实验 A：先判断传输对是否值得继续

先在 FLUX.1-dev 上独立处理一个具体身份概念和一个广泛内容概念，例如 Pikachu 与 nudity。使用主方法的有限标定预算，记录每次生成调用及候选淘汰原因。

第一轮回答三个问题：

1. 至多 4 个 head/时间位置是否产生目标擦除效果？
2. 在相同擦除效果附近，是否比 key 簇 value 置零、query 簇 head 输出置零更好地保留相邻内容？
3. 加入相邻保留组后，规则是否仍覆盖新模板与新种子？

两个端点基线沿用相同码本和样本，分别调节屏蔽强度，比较擦除—保留曲线。直接画单个 operating point 无法排除强度选择带来的差异。

如果效果只来自大范围弱化文本条件，应在其他普通文本对齐任务上出现相应下降。这一对照用于排除“丢失条件遵循能力”对擦除率的解释。

### 实验 B：验证部署接口与隐式触发

最终评估仅调用 `pipeline(prompt, seed, num_steps)`。固定部署包后移除 target/anchor 参数与相关额外编码入口。

测试组包括显式名称、别名、不含名称的属性描述、语义相关但正常的内容、目标词出现在背景文字中的场景、完全普通的 prompt，以及多物体和多目标共存场景。标签按实际生成内容评估。

同时记录每张图每个时间区间的匹配数量与命中率，分析两类失败：内部规则未匹配但目标仍生成；内部规则匹配却误伤正常内容。词面命中率与内部匹配率分别统计。

测试 prompt 模板和种子与标定集分开。最终测试结果只用于报告效果。

### 实验 C：验证单概念到多概念扩展

按照 1、2、5、10 个目标逐步扩大概念集合，分别报告：

- 每个目标的残留出现率，以及任一目标出现的图像比例。
- 相邻概念、未擦除身份与普通内容的保留率。
- 目标与保留对象同时出现时的非目标内容完成率。
- 与原模型相同 seed 的保留图像变化，以及人工质量对比。
- 码本/规则包大小、干预 head 数、总预计算成本与在线延迟。

比较单规则包、未经联合标定的规则并集、联合标定后的规则并集。该实验判断多概念收益是否确实来自共享规则与校准，以及代价如何增长。

### 实验 D：验证低成本部署

在同一硬件、模型精度、分辨率、batch size 和采样器下比较原生优化实现与完整方法。预热后报告中位数延迟、P95、峰值显存、实际 DiT 调用数；区分码本匹配与 attention kernel 改动的耗时。

若全表操作导致原生 attention 快速路径失效，额外前向为零仍不能支持“低额外延迟”的主张。先在目标内核上验证选定 head 的 tile 内查表，再扩大概念数量。

重新标定 SD3.5，检查方法是否在另一种 flow-matching DiT 上成立。改变步数、分辨率、guidance 或蒸馏版本时分别记录适配成本。

## 5. 评价与基线选择

概念擦除按任务使用身份识别、内容检测或风格分类，并用人工抽样复核。相邻概念和普通 prompt 的遵循率单独报告；广泛内容概念先固定标注边界。

保留评估同时使用普通样本和目标/保留对象共存样本。仅比较 CLIP 总分无法区分完整保留、漏生成物体与属性迁移。分布质量指标使用足够样本量，预算较小时优先报告配对质量评价与置信区间。

优先复现与当前模型有对应实现的 SafeRoPE、DVE 及其预计算版、SHIFT、Semantic Steering、EraseAnything；GLoCE 与投影编辑可提供另一组擦除—保留参照。所有基线在相同模型、prompt、seed 与采样条件下测试，强度在独立标定集上选择。

最关键的本方法消融是：去掉相邻保留数据、只按富集度选规则、key 簇 value 屏蔽、query 簇 head 输出屏蔽、随机连接抑制、固定全时间干预、分时段干预，以及未经联合标定的多概念并集。

## 6. 需要由结果支持的主张

| 拟作出的主张 | 必要证据 |
|---|---|
| 传输对比单端表征更适合选择性擦除 | 相近擦除率下，两端屏蔽基线的相邻概念保留更差 |
| 实现普通 prompt 自动触发 | 完整部署接口评估，显式/隐式 prompt 的擦除与误伤统计 |
| 支持不同类型概念 | 具体身份、广泛内容、风格等分别标定与评估 |
| 支持多概念 | 逐概念指标、共存场景、规则合并和联合标定结果 |
| 离线成本小 | 实际生成等价成本、GPU 时间与缓存量 |
| 在线额外成本低 | 相对原生优化实现的延迟与显存实测 |
| 利用了因果相关传输 | 图像级干预、端点对照、随机连接对照及独立种子复验 |

方法适用的关键条件是：目标生成依赖可被当前码本区分的传输；干预时间足以阻止目标完成；保留内容仍有可用的信息来源。目标经 FFN、全局条件调制或未覆盖的注意力路径继续形成时，有限规则会留下残留。论文据各模型、概念与配置的实测结果界定能力范围。
