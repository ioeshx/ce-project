# PairCut-FM：基于 Q/K 聚类的 flow-matching DiT 概念擦除

日期：2026-10-29。本文提出待验证的方法设计；带符号与公式的完整展开见 [method_expanded.md](/home/shx/code/ce-project/methods/DiT/paircut_fm_20261029/method_expanded.md)，文献核查与实验方案见 [research_notes.md](/home/shx/code/ce-project/methods/DiT/paircut_fm_20261029/research_notes.md)。

**核心方法：离线验证哪些 query–key 聚类组合可以被抑制，并保存二值表；生成时根据当前 Q/K 的聚类编号查表，降低对应注意力分数。**

主要研究问题是：能否通过抑制少量概念相关传输，保留两端表征支持其他内容生成的能力？方法将这一问题转化为可直接实施的干预与对照实验。

## 1. 使用接口与部署内容

离线输入：冻结的 flow-matching 文生图 DiT、待擦除概念集合，以及少量目标样本和保留样本。以 FLUX.1-dev 为首个验证模型，随后在 SD3.5 上独立标定。

部署包包含：少量 block/head 的编号、生效的采样时间区间、Q/K 聚类中心、匹配半径、query–key 聚类组合的查找表与抑制强度。概念集合在制作部署包时确定。

生成接口只有：

```python
image = erased_pipeline(prompt, seed, num_steps)
```

每次生成只提供普通 prompt 与采样参数。运行时直接读取部署包，不编码额外的 target/anchor 文本，不增加概念条件分支。普通 prompt 本身可以显式包含目标名称，也可以通过属性、别名或上下文隐式指向它。

## 2. 编辑单位：query–key 聚类组合

在 DiT 的注意力中，query 与 key 用于计算 attention 权重，value 按这些权重聚合。本方法编辑图像 query 与文本/图像 key 之间的注意力分数。

例如，降低某个 query 簇与某个 key 簇组合的注意力分数，可能减少 Pikachu 的生成，同时保留这两个簇与其他簇之间的注意力作用。这是需要实验检验的工作假设。簇由模型表征聚类得到，不预先把某个中心命名为“黄色”“耳朵”或“身份”。

一个编辑规则包含五项：**block、head、时间区间、query 聚类编号、key 聚类编号**。key 编号还区分文本/图像模态。规则作用于当前样本中的所有匹配位置，不保存固定词索引或固定图像坐标。下文的“传输对”均指这样的 query–key 聚类组合。

DiT 可解释性研究为寻找此类传输提供了依据：ConceptAttention 展示了注意力输出表征的语义定位能力；关于空间关系的电路研究展示了条件信息经特定注意力头传入图像的机制。后者来自受控训练模型，因而本设计在真实模型上重新做干预定位。[ConceptAttention](https://arxiv.org/abs/2502.04320)，[Circuit Mechanisms](https://arxiv.org/abs/2601.06338)。

## 3. 离线流程

### 第一步：准备目标样本与相邻保留样本

每个概念先准备三组 prompt：

- 目标组：显式名称、别名、属性描述及多物体上下文。
- 相邻保留组：共享部分属性、上位类别或场景，但生成结果不含目标概念。
- 普通保留组：与目标无关的常见生成任务。

Pikachu 的相邻保留组可包含其他卡通角色、普通鼠类、黄色玩具，以及黄色物体与红色物体分别出现的场景。nudity 的相邻保留组可包含穿衣人像、泳装与运动场景；实际标签按事先确定的内容边界标注。

以原模型生成的图像是否包含目标为标签，结合任务检测器和人工核查。目标 prompt 生成失败的样本不计为目标阳性。各组按模板划分为发现集、标定集和最终测试集；发现与标定阶段可以共用已缓存轨迹，最终测试集独立保留。

这里使用保留样本描述需要保留的能力，不指定统一的安全替代概念，也不构造 target-minus-anchor 方向。

### 第二步：从原始轨迹建立 Q/K 聚类

冻结文本编码器、DiT 和 VAE，在原模型正常生成时抽样记录候选 block/head 的 Q/K。首轮在总深度约 20%、40%、60%、80% 处各选一个 block，检查这些 block 的所有 head；每个记录位置每次抽样最多 64 个图像 token 和 64 个文本 token。将原生采样时间划为早、中、晚三个区间，各区间单独标定。

类型匹配使用 **QK 归一化之后、RoPE 之前的 Q/K 副本**，避免把绝对位置编码直接当作类型特征；模型原本的 RoPE 与注意力计算照常执行。没有该归一化模块的模型，对副本做归一化后聚类。

对每个候选 head/时间区间分别建立小型码本：图像 query、文本 key、图像 key 各用约 16 个中心。码本在目标组与保留组的平衡样本上，用归一化向量的球面 k-means 共同聚类。每个中心附带以标定样本距离分位数确定的匹配半径，超出支持范围的向量标记为 unknown；unknown 对应的规则为零。

根据缓存中的连接分数，筛出在目标阳性样本中富集、在相邻保留样本中较少出现的类型对。富集程度只用于压缩候选集合，最终选择依据下一步的生成结果。

### 第三步：用实际生成干预确定有效传输对

对少量候选传输对施加有限的注意力分数惩罚，保持 prompt、种子、采样器与其他参数一致，重新生成图像。记录目标出现率、保留内容完成率与图像质量。

每个入选规则需要通过三项检验：

1. **擦除效果**：抑制该类型对后，目标出现率下降，其他请求内容仍可完成。
2. **对照**：分别将该 key 簇的 value 置零、将该 query 簇的 head 输出置零。在相同擦除效果附近，比较这两种屏蔽与 query–key 组合编辑的保留表现。
3. **扰动对照**：同 head、同时间区间内，随机抑制相近注意力质量的其他连接，检验效果是否来自目标相关传输。

先选少量规则，再直接评估规则组合。组合改变后续 Q/K 分布，因此最终规则包需要在干预后的完整轨迹上重新检查匹配与效果。预算内允许一轮重新标定。

**核心判据：在相近目标擦除率下，query–key 组合编辑比 key 簇 value 屏蔽或 query 簇 head 输出屏蔽更好地保留相邻概念。** 若该优势没有出现，当前实验便不能支持“聚类组合是更合适的编辑单位”这一贡献。

### 第四步：编译单概念或多概念规则包

每个选定 head/时间区间保存一张小表：行是图像 query 类型，列是文本/图像 key 类型；单元格记录该类型对是否需要抑制。

单概念使用对应规则。多概念先平衡汇总各目标与保留样本，为同一 head/时间位置建立**共享码本**，再在该码本上发现和合并规则；独立码本的编号不直接合并。同一类型对命中多个概念时仍只惩罚一次。然后在包含多个目标、目标与保留对象共存的 prompt 上联合标定强度和时间区间。

当同一类型对同时承担某个目标与重要保留内容时，通过保留集剔除该规则或细化对应码本。码本细化后重新赋型并验证受影响的规则。多概念成本随所需码本与干预 head 的规模变化。

## 4. 在线流程：在一次正常前向中完成识别与抑制

在规则指定的 block/head/时间区间中：

1. 从当前前向已有的 Q/K 副本确定类型及匹配置信范围。
2. 查表判断每个 query–key 聚类组合是否命中擦除规则。
3. 仅对命中连接减去一个有限常数，再执行原来的 softmax 和 value 聚合。
4. DiT 输出修改后的速度预测，交给原生 flow-matching 采样器继续积分。

唯一的在线编辑公式为：

\[
\widetilde S_{ij}=S_{ij}-\beta\,B_{a(i),b(j)},
\qquad A=\operatorname{softmax}_j(\widetilde S).
\]

其中，`i` 是图像 token 索引，`j` 是参与注意力计算的 token 索引；`S` 是模型原本完成 QK 缩放与 RoPE 后的注意力分数；`a(i)`、`b(j)` 是 query 与 key 的聚类编号，`B` 是当前 head/时间区间的合并规则表；`β` 为离线标定的有限正数。

有限惩罚保持 softmax 有定义，并让剩余消息重新归一化。没有命中规则的行，在该次注意力运算中保持原样。命中行中未受惩罚连接的概率会随归一化改变，因此保留效果由生成实验评估。

有效抑制需要该行同时有命中和未命中的连接。若整行全部命中，对全部 logits 减去同一常数将保持 softmax 概率不变；离线筛除仅产生这种整行平移的无效规则。精确概率变化见 [公式展开第 8 节](/home/shx/code/ce-project/methods/DiT/paircut_fm_20261029/method_expanded.md)。

```text
offline:
    cache base-model Q/K and label generated images
    build shared, time-specific query/key codebooks
    shortlist enriched sender–receiver type pairs
    validate selective score penalties with generated-image controls
    jointly calibrate selected rules and export package

online(prompt, seed):
    run the native text encoder and flow sampler
    at each selected attention site:
        assign types from current pre-RoPE Q/K copies
        look up the merged pair table
        subtract the finite penalty from matching attention scores
        continue the native attention and DiT forward
    decode the final latent
```

**对 prompt 是否导致不期望内容的判断，体现在当前内部传输是否命中离线验证规则。** 它随图像生成状态更新，而不是一次性的词面判断。隐式 prompt 能否被识别，取决于其内部传输是否落入已标定的类型对覆盖范围。

## 5. 计算预算与实现位置

主模型训练量为零；离线工作是采样、聚类和有限候选的生成验证。首轮采用下列预算探索方法是否成立，数量均为实验配置，尚无测得性能：

| 项目 | 首轮配置 |
|---|---|
| 基础标定数据 | 每概念 24 个目标、24 个相邻保留、16 个普通保留 prompt，各 1 个种子 |
| 类型中心 | 每种模态/角色 16 个 |
| 时间区间 | 原生采样时间的早、中、晚三个区间 |
| 进入生成干预的候选 | 每概念最多 8 个类型对规则 |
| 首轮部署规模 | 每概念最多 4 个 head/时间区间位置 |
| 干预与组合标定 | 每概念最多 192 次完整生成等价成本，含两端、随机与组合对照 |
| 在线额外 DiT 前向 | 0 次 |

每概念基础生成与标定合计上限为 256 次完整生成等价成本。若原生采样每图调用 DiT `T` 次，对应上限为 `256T` 次调用；最终测试成本另计。离线报告同时记录 GPU 时间、失败生成、缓存量与实际调用数。

在线额外工作由 Q/K 到小码本的匹配和 attention score 查表构成。查表应融合到选定 head 的 attention kernel 中，按 tile 应用规则；不构建完整的 `N×N` 新掩码。原生优化实现与修改实现之间的延迟、显存差异必须实测。

首轮将端到端中位延迟增幅不超过 10% 设为工程验收目标，并同时报告 P95。该阈值用于约束实现选择，属于待验证目标。

以 head 维度 128、每码本 16 个中心为例，一个 head/时间位置的三类 FP16 码本约为 12 KiB，四个位置约为 48 KiB，再加小型规则表与阈值。该数值是存储估算；低额外延迟仍需验证。

方法通过 DiT 内部传输改变其速度预测，沿用原生 flow-matching 调度与积分规则。时间区间按实际模型与采样配置标定，不从 rectified-flow 路径性质推导隐藏表征跨时间不变。

## 6. 论文贡献的准确落点

拟验证的贡献是：**将擦除单位从单端表征扩展为经生成干预验证的特定传输对，再将其编译为可自动触发、支持多概念合并的注意力规则。**

与相邻路线的操作差别是：DVE 编辑输出速度的概念差分方向；SHIFT 与 Semantic Steering 编辑隐藏激活；SafeRoPE 对风险相关 Q/K 做旋转；GrOCE 在文本语义图上定位并处理概念。本设计在原始表征保留的情况下，按两端类型直接编辑注意力分数。各方法原文、对应关系与重合风险见 [文献核查](/home/shx/code/ce-project/methods/DiT/paircut_fm_20261029/research_notes.md)。

当前设计的新颖性定位依据已核查文献，成立的关键证据是“两端分别有用、特定连接可被选择性抑制”的实验结果。目标经未覆盖的类型、FFN 或全局调制路径继续生成时，会产生残留；这类残留与多概念误伤一起纳入最终测试。
