# 面向 flow matching DiT 的概念擦除：短续程响应匹配

构思日期：2026-10-27（北京时间）。状态：**2026-10-29 已被用户否决，停止推进实现与实验。**

## 否决决定

否决原因是推理成本及多概念扩展成本。单概念每个完整触发点额外需要七次样本前向，复用下一步输出后仍净增六次；按逐概念的目标／替代分支构造参照时，在线计算还会随擦除概念数增长。无需训练这一属性不足以满足当前对低推理开销的要求。

后续方法优先保持原生生成的完整前向次数，将概念专属工作移到离线预计算或少量训练中，并避免多概念逐个追加完整 DiT 分支。以下内容保留为历史设计，不再代表推荐方向。

## 原方案概述

**短续程响应匹配的速度擦除**，工作名 *Short-Continuation Response Matching for Concept Erasure*，简称 SCRM。

**用同一个 DiT 的两步安全／目标生成差异提供参照，测量一次速度修改经过原提示的下一步计算后实际变成什么，再用一次残差补偿改进这次修改。**

这条路线把研究问题放在“干预如何经过后续生成计算”上。已有 DVE 的即时概念差分作为共同起点；新增部分是短续程参照、原提示下的实际响应，以及针对响应偏差的一次修正。推理只需要原生成模型的条件 velocity 接口，无梯度、无训练、无外部判断模型。

最需要证明的不是补偿公式，而是：**经过原提示续程后出现的响应偏差，是否与最终擦除／保留有关；修正完整向量是否比同预算调强度更有效。**

## 与六项要求的对应

| 要求 | 本轮设计 | 实际边界 |
|---|---|---|
| 优先 flow matching DiT | 在实际 flow 积分步与 velocity 输出上构造两步响应 | 首版使用普通 velocity 模型和 Euler；不直接套到 MeanFlow 的区间平均输出 |
| 尽量架构无关 | 不读取 Q/K/V、attention、文本分支、RoPE 或某个 block | 仍需适配时间方向、latent 格式和原生 guidance |
| train-free／少量准备 | 模型参数不变；只缓存原生文本条件 | 增加在线完整 DiT 前向；需小开发集确定强度与检查位置 |
| 少外部组件 | 所有生成与响应检查复用同一个 DiT | 外部指标可用于离线评估，不参与生成或候选接受 |
| 适量数学和工程 | 两步真实续程、一次向量残差修正、一次真实复查 | 局部反求使用近似；没有全局分布或严格安全定理 |
| 避免与已有论文过度重合 | 避开仅换门控、平均缓存、内部固定 steering 的路线 | 短续程与数值校正都有先例，需由严格对照支持具体增量 |

本轮没有把 SD1.4、SDXL 或 U-Net 兼容性列入实现目标。

## 此前的选题依据

DVE 已经提供架构依赖弱的输出接口。重新增加内部定位器，容易重新引入层、head 或文本路径的依赖；把差分换成旋转、核映射或另一个 gate，也不自动形成新问题。

这里选择直接测量**当前用户状态中，一次编辑经过后续计算的效果**。它能产生一个与原差分不共线的修正，而且可以通过同预算标量拟合判定这个方向变化是否真有价值。

代价也很具体：单分支模型每个完整检查点额外七次样本前向，复用下一步缓存时可减为六次。因此首版只安排两个检查点。它适合检验机制，不能预先称为零开销方案。

## 与已有提案的关系

这是 [FRS](../FRS_PROPOSAL.zh-CN.md) 中“干预需要经过后续生成计算”这一问题的输出接口延伸，不把这个问题重新声称为首次提出。FRS 离线拟合多个内部注入候选；这里在当前用户状态上，用一次全维输出修正处理响应偏差。

它也区别于[重噪自检](../renoise_self_check_20261026/README.zh-CN.md)：不使用重噪重建评分来判断目标存在，不只是在原候选和固定差分候选之间选择，而是构造新的补偿方向。不过，候选复查、短程预测与有限差分都不是独占的新工具。

## 两条没有提升为主方案的路线

1. **真实目标中间状态到安全终点的少量训练桥接。** 与 VisualErase 的视觉轨迹重定向有较大概念重合；仅改成 flow matching、减少训练数据或使用 LoRA，暂不足以支持独立主线。
2. **直接用内部语义原型定位后删除／注入。** 与 Semantic Steering、UVR、GLoCE 及本目录 SIDV 接近，表征可读性也不能替代因果擦除证据。

第一轮如果只发现“强度增大就能解释全部收益”，应把结果归为差分擦除的自适应强度改进。如果响应误差下降无法对应到最终图像改善，则停止扩大这条路线，不追加外部分类器来补救核心假设。
