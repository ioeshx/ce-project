# 面向 Flow-Matching DiT 的文生图概念擦除：重噪自检与速度候选选择

日期：2026-10-26。性质：方法研究提案，尚无真实模型实验结果。

本轮只依据本次提出的约束和 `papers/` 中的论文材料重新思考，没有沿用项目其他对话中的方法结论，也没有修改已有提案。重点阅读 Semantic Steering 与 DVE 的完整 PDF，并对照公开原文。文献证据见 [LITERATURE.zh-CN.md](LITERATURE.zh-CN.md)，具体实验见 [EXPERIMENTS.zh-CN.md](EXPERIMENTS.zh-CN.md)。

## 1. 建议研究什么

**优先研究：用同一个 DiT 检查候选速度修改的后果，再决定是否采用这次修改。**

暂定中文名“重噪自检的速度擦除”，英文工作名 *Re-noised Self-Checking for Velocity Erasure*。名字只用于讨论。

核心问题从“如何构造另一个擦除方向”转向：

> 当前的速度修改，在原用户提示继续起作用之后，是否仍能降低目标概念的残留？

基本流程是：在少量采样步上，构造“不修改”和“沿安全概念差分修改”两个候选；在两个候选的新状态上，分别用原用户提示重新预测 velocity，得到候选干净 latent；把它们重新加噪，在另一个噪声水平上让同一个 DiT 比较目标概念和安全参照的 velocity 重建误差；只在内部检查支持这次修改时采用它。

**真正的新贡献假说是“异状态、异噪声水平的后果检查能够改善速度纠正的选择”，而不是概念差分本身。** 是否能成为论文，取决于它能否在相同计算预算下优于 DVE、固定差分引导及简单的自适应系数。

## 2. 与本次约束的对应

| 要求 | 本提案的处理 |
| --- | --- |
| 优先用于 flow-matching DiT | 从 velocity 输出和 flow-matching 重建目标出发；第一版聚焦线性噪声路径的 rectified-flow DiT |
| 尽量与 DiT 架构无关 | 只调用完整模型的条件 velocity；不读取 attention、隐藏层、文本分支或 single/double-stream block |
| 操控 velocity prediction | 唯一实际施加的改动是交给 sampler 的 velocity 张量 |
| train-free / 少量准备 | 主方案零参数更新；缓存少量文本条件，可做小规模阈值校准 |
| 不依赖外部组件 | 在线检查复用原 DiT；不新增 VLM、CLIP 图像模型、分类器、分割器或 LLM 提示改写器 |
| 数学与工程平衡 | 使用概念差分、候选前向、重噪重建比较；不建立语义流形、全局正交子空间或精确后验模型 |
| 重点参考两篇指定论文 | 继承 Semantic Steering 的成对概念参照思想和 DVE 的输出速度接口，针对两者尚未直接回答的纠正后果进行验证 |

这里的“架构无关”指不依赖内部结构；不代表跨模型共用数值阈值、latent 格式或时间约定。模型自带的文本编码器与 VAE 属于原生成系统，不计为新增辅助模型；自检过程本身不需要 VAE 解码。

## 3. 两篇重点论文带来的判断

### 3.1 Semantic Steering：值得继承成对参照，不直接继承内部注入

[Semantic Steering](https://arxiv.org/html/2608.12829v1) 在中间 block 提取目标与安全概念的文本 token 表征差，将一个向量注入若干连续的早中期 blocks。论文在 SD3.5-medium 和 FLUX.1-dev 上进行实验。

可以继承的认识是：同一背景下的目标/安全成对描述，比孤立的目标词更适合表达“希望改变什么”。但“中间 block 的文本表征”及其注入位置与内部接口有关，不符合本轮最优先的设计目标。

此外，隐藏表征中的静态方向有效，不等于同一个输出 velocity 向量能跨状态、空间位置和时间直接复用。rectified flow 的训练插值为直线，也不保证训练后的每条条件生成轨迹、经过 guidance 后的轨迹以及概念方向都严格不变。

### 3.2 DVE：输出接口已经合适，差分、投影、缓存都已有先例

[DVE](https://arxiv.org/html/2602.01089v1) 在同一 latent、同一时刻，计算安全 anchor 和目标概念的条件速度差，再根据用户 velocity 在差分方向上的投影选择性纠正。其 §4.3 已包含按采样时刻预缓存差分和只在生成前中期纠正；§4.4 已包含多概念组合。

因此，下列做法单独提出时不足以构成本轮的主要贡献：

- 把内部 steering 移到最终 velocity 输出；
- 从目标与安全概念构造速度差，再增加一个投影阈值；
- 对差分做平均缓存、分时间段启用或叠加多个概念；
- 把固定纠正系数换成余弦相似度或手工时间函数。

DVE 的投影是一个即时几何判据。它没有直接比较“采用这次纠正”和“不采用这次纠正”之后的候选结果。另一方面，原 velocity 包含生成所需的整体运输成分，其投影符号不必在每个实际状态上都对应概念是否存在。这是需要实测的问题，不能先认定 DVE 的判据失效。

## 4. 为什么选择“后果自检”这条路线

目前值得验证的三个缺口是：

1. **概念判断**：当前 velocity 的投影，与图像中的概念残留有多一致？
2. **纠正判断**：即使知道当前可能有残留，给定方向的这一次修改是否真的有效？
3. **继续生成**：原提示下一次重新预测 velocity 后，会不会抵消刚才的变化？

第一版用一个紧凑机制同时观察这些问题：**不训练额外检测器，让原 DiT 在候选新状态上重新作预测，并对候选结果进行一次独立噪声条件下的重建比较。**

已有 Diffusion Classifier 使用生成模型的重建误差进行识别；本提案借用这种思想，不主张发明“生成模型兼作识别器”。已有 VESFlow 和 Modular Energy Steering 也会检查预测干净样本并反馈纠正；区别在于，本方案把在线检查留在同一个 DiT 内，以有限候选的前向比较代替外部安全验证器的梯度。更完整的相邻方法对照见文献文件。

## 5. 最小方法：只有两个候选

### 5.1 输入与记号

输入包括原用户提示 `p`、待擦除概念描述 `f`、安全参照描述 `a`、模型和 sampler。不要求用户提示显式出现目标词，也不先做关键词路由或提示改写。

第一版统一使用：噪声水平 `s=1` 为纯噪声，`s=0` 为干净 latent，velocity 是这一噪声坐标下的导数。采样沿 `s` 递减。实际模型的时间输入、sigma shift、输出符号和 packing 由一层公开接口适配。

### 5.2 步骤一：得到一个已有依据的候选方向

在当前相同状态 `(z,s)` 上，用同一模型计算：

\[
d = v(z,s,a)-v(z,s,f),\qquad v^{(\lambda)}=v(z,s,p)+\lambda d,\quad \lambda\in\{0,\lambda_{\rm ref}\}.
\]

`λ_ref` 是开发集确定的一个固定强度，不在每个测试提示上搜索。此处三次预测使用相同的生成 guidance 约定；自检时的原始条件输出另行区分。第一版使用完整差分，不接 DVE 的原始投影 gate，以便独立评价新的选择规则，也让原 gate 可能漏掉的纠正仍有机会被检查。

方向设计是继承部分，不作为创新点。当 `p=f`、`λ_ref=1` 且 guidance 设置一致时，候选 velocity 恰好变成安全参照的 velocity。这也给出最直接的符号检查。

`f` 与 `a` 尽量只改变目标因素。例如 `a portrait of [目标人物]` / `a portrait of a person`。它们可以由人工固定模板构造，不需要大语言模型。安全参照的含义必须由任务规定：去掉画风、匿名化人物、替换对象子类与彻底删除物体是不同目标。

### 5.3 步骤二：让原提示在候选新状态上重新预测

先对两个候选分别执行当前 sampler 的一步，得到 `z_next^(0)` 与 `z_next^(1)`。然后在各自的新状态上，**仍使用原用户提示 `p`** 各做一次完整模型前向。

这一步的目的，是让模型有机会在新的 latent 上重新表达原提示。相比直接评估当前的 `v+λd`，它更接近“这次修改之后会发生什么”。但一次重新预测不能保证整个后续轨迹都不会恢复目标概念，后续实验必须检查这个差距。

用重新预测的 velocity 形成候选干净 latent 估计。在线性 RF 噪声坐标中：

\[
\hat x^{(j)}=z_{\rm next}^{(j)}-s_{\rm next}\,v(z_{\rm next}^{(j)},s_{\rm next},p).
\]

这是局部的 clean estimate，不当成实际终点。第一版不把候选完整采样到终点，否则计算成本容易失控。

### 5.4 步骤三：在另一个噪声条件下，用同一 DiT 自检

对两个候选使用**同一份新高斯噪声** `ε` 和同一个中等噪声水平 `ρ`。`ρ` 与当前候选状态的噪声水平不同，`ε` 也不复用生成轨迹的起始噪声。若选定的 `ρ` 恰与某检查步重合，按开发阶段预先固定的替代规则换用另一个水平；不根据测试候选得分临时挑选。

对每个候选构造一次新的“加噪—预测”问题：

\[
\begin{aligned}
\tilde z^{(j)}&=(1-\rho)\hat x^{(j)}+\rho\epsilon,\qquad u^{(j)}=\epsilon-\hat x^{(j)},\\
R_j&=\operatorname{MSE}\!\left(v(\tilde z^{(j)},\rho,a_{\rm probe}),u^{(j)}\right)
    -\operatorname{MSE}\!\left(v(\tilde z^{(j)},\rho,f_{\rm probe}),u^{(j)}\right).
\end{aligned}
\]

`R_j` 较大，表示目标概念条件相对安全参照更能解释该候选的 velocity 重建任务。它只是**待验证的相对兼容性指标，不是概念概率，也不是精确的条件对数似然比**。

`f_probe/a_probe` 使用事先固定、背景匹配的另一组成对描述，与构造方向的模板区分。初版只用一个 probe 对和一个重噪样本；另一些模板、噪声种子保留给离线检验，不能参与在线候选选择。

共享噪声是为了让两候选的差别更容易比较；它不保证一次采样就足够稳定。`ρ` 可以从开发集上的 `{0.3, 0.5, 0.7}` 选择，所有实验记录实际噪声系数，而不是把网络的整数 timestep 直接当成 `ρ`。

**不能省掉新状态与重噪，直接在当前状态比较两个条件 velocity 的距离，再将它命名为自检。** 那样会退化为已有速度上的仿射投影判据，无法体现对纠正后果的独立检查。精确的退化关系见文献文件。

### 5.5 步骤四：只决定采用哪一个速度

使用一个简单、预先固定的规则：

- 原候选的 `R_0` 不超过阈值 `θ`，采用不修改候选；
- 否则，只有 `R_1 < R_0 - m` 时采用纠正候选；
- 其他情况仍采用不修改候选。

`m` 是避免把微小评分波动视作改善的比较余量。`θ` 和 `m` 是开发集校准的少数标量；`θ=0,m=0` 作为无校准对照，不预设其有效。阈值校准的数据来源、人工检查量和额外前向都计入准备成本。

最终只提交当前 sampler 的一步，丢弃用于候选检查的临时状态。下一次正常采样仍用原提示。纠正只发生在预先安排的检查步上，不把本次差分跨步缓存后持续注入。

这个最小规则没有另加在线保留分类器或多目标加权损失。生成质量和非目标语义的保留，通过开发集选强度及独立测试评价；如果必须引入复杂保留模块才能成立，应重新评估路线，而不是持续叠加组件。

### 5.6 概念伪代码

```text
预先固定检查步、方向提示对、probe 提示对、λ_ref、ρ、θ、m
缓存文本条件；不更新模型参数

for 每个正常采样步:
    v_user = 原提示的生成 velocity(z, s)
    if 当前不是检查步:
        正常提交 sampler 一步
        continue

    d = 参照 velocity(z, s, a) - 目标 velocity(z, s, f)
    for λ in [0, λ_ref]:
        z_candidate = 预览 sampler 当前一步(z, v_user + λ*d)
        v_future = 原提示的生成 velocity(z_candidate, s_next)
        x_candidate = clean_estimate(z_candidate, s_next, v_future)
        R[λ] = 同一 DiT 在独立重噪条件下的目标/参照重建误差差

    根据 R[0]、R[λ_ref] 与固定阈值选择 λ
    仅提交选中候选的当前一步
```

这里的“生成 velocity”包含模型正常生成所需的 guidance；“重建误差自检”尽量使用未经外部 CFG 合成的条件预测，原因见下一节。

## 6. 成立需要哪些条件，怎样处理真实模型

### 6.1 Flow-matching 残差能否识别概念，必须先做实测

CFM 训练目标是拟合已知插值样本的速度。不同文本条件下的残差，可能含有概念信息，但也可能主要反映场景、颜色、构图或候选图像的模糊程度。

因此，不从 FM 训练目标直接推导“残差小就含有该概念”。必须分别验证它对真实生成图像、局部 clean estimate 和已被纠正的候选是否有效。仅在未干预图像上能分类，不足以支持在线选候选。

### 6.2 Guidance 与蒸馏是重要接口差异

SD3.5 的外部 CFG 合成结果与原始条件 velocity 需要区分。第一版自检使用原始条件输出；正常生成与候选前向保留原生成 guidance。

[FLUX.1-dev 官方模型卡](https://huggingface.co/black-forest-labs/FLUX.1-dev) 明确其使用 guidance distillation；因此，这里的自检假说需要额外验证其输出与 CFM 残差的兼容性。自检在固定 guidance 输入下单独校准，并与 SD3.5 的结果分开分析；若该分数在 dev 上失效，应报告适用边界。FLUX.1-schnell 等少步蒸馏模型不作为第一轮的唯一证据。

### 6.3 时间和符号以实际 sampler 为准

本文统一噪声端 `s=1`，因此线性插值的训练目标为 `ε-x`，采样步长为负。不要混用数据到噪声与噪声到数据的正号约定。网络接收的 `t` 与物理噪声系数 `s` 也可能存在缩放或 shift。

第一版用 Euler，确认 `λ=0` 与原 pipeline 一致。对有历史状态的多步 solver，预览分支必须复制其状态，不能污染正式采样器。

更一般的 FM 概率路径需要用其实际加噪函数、路径导数和 clean-estimate 公式；本文的线性公式不宣称能原样覆盖所有 FM 路径。MeanFlow 的平均速度也需单独处理。

### 6.4 检查不意味着永久遗忘

模型权重保持不变。本方案研究固定部署流程中的推理期概念擦除/抑制。实验中的攻击者可以改变提示、种子和公开允许的 guidance 设置，但不能卸载防护流程后再将原模型的生成能力算作该流程被攻破。

## 7. 计算成本：训练少与推理便宜分开讨论

以下以每次条件 velocity 查询计数，双候选、一个 probe 对、一个重噪样本：

| 每个检查步的新增工作 | 查询数 |
| --- | ---: |
| 在当前状态计算目标和安全参照速度 | 2 |
| 在两个候选新状态上，用原提示重新预测 | 2 |
| 对两个重噪候选分别查询目标与安全 probe | 4 |
| 合计 | 8 |

例如基础采样 `T=30`、检查 `K=8` 次，单分支生成模型的名义查询量为 `30+8×8=94`，约为基础的 `3.13` 倍。全程在线单概念 DVE 的相同口径为 `30×3=90`。这使完整版本适合先在接近 DVE 的预算下验证，而不是承诺低开销。

实际 NFE 要展开 CFG 的条件/无条件分支，并统计各分支的复用；把多个候选放入一个 batch 不会让样本计算量变成一次。上述倍数是工作量估计，不是实测时间倍数。显存、峰值 batch 和文本编码耗时单独记录。

`K=4` 的名义查询量为 `62`，但更少纠正是否足够必须实测。第一版不训练控制器、不做 Jacobian、不对完整生成轨迹反向传播，也不缓存带空间坐标的整张 velocity 场。

## 8. 为什么不优先选择另外两条简单路线

| 路线 | 优点 | 当前判断 |
| --- | --- | --- |
| 安全参照中心化：把用户 velocity 相对安全 velocity 的投影推回安全水平 | 简单、输出级、无需外部模型 | 是重要强对照；代数上接近 DVE 的状态相关阈值，单独改公式创新有限 |
| 少量学习每时间段的纠正强度或阈值 | 输出级、参数极少、可能降低在线自检次数 | 作为自检有效后的压缩扩展；若先做，容易变成缺少新机制的 schedule tuning |

也不优先做“把多个方向正交化”“增加一组保护子空间”或“建立最优传输/精确安全后验”。这些方向会增加假设与超参数，而本轮最需要回答的是：**模型内部的可观察信号，能否可靠判断某次速度修改的效果？**

## 9. 什么结果才足以支持论文

建议建立以下证据，其中第 1 项用于机制解释，第 2–5 项检验方法价值：

1. 即时投影分数确实存在可重复、可解释的概念判断偏差；
2. 异噪声水平的重建检查，在这些状态上更能预测最终概念残留；
3. 在两个纠正候选之间，它能预测哪一个更好，而不只是区分目标/非目标图像；
4. 这种选择改善擦除与保留的权衡，且在相同查询量或时间预算下仍成立；
5. 效果能在不同内部结构的 FM DiT 上复现，并包含隐式描述与重新攻击。

即使 DVE 的原分数已经较强，第 2–5 项仍可构成路线的主要实证。反过来，若只是因增加计算量或更强纠正而变好，就不能把结果归功于自检。

## 10. 最先做什么，何时停止这条路线

先做一项小型诊断，不立即搭建完整 benchmark：在同一批目标/非目标状态上，离线产生两个候选并各自完整生成到终点，比较内部评分和独立人工/评测器判断。

重点检查三件事：

- 候选评分下降，最终目标概念是否也下降；
- 评分是否把模糊、空白、主体消失错误地视为成功；
- 相对于同预算固定纠正与 DVE，选择本身是否有收益。

如果这些检查不成立，停止扩展自检机制，保留负结果与诊断结论。不要通过继续增加模板、分支、子空间、损失项和外部模型来掩盖核心评分失败。

当前优先级是：**先证明后果检查可用，再研究检查频率与速度强度；最后才考虑多概念或少量学习。** 可执行的分阶段计划、对照与停止标准见 [EXPERIMENTS.zh-CN.md](EXPERIMENTS.zh-CN.md)。
