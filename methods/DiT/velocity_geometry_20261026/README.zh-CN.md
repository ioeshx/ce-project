# 面向 Flow-Matching DiT 的概念擦除：从单一差分到成对局部速度传输

日期：2026-10-26。本文按本轮要求独立分析，以 `papers/` 中的论文全文和本次核对的作者原文为依据；不把已有方法提案当作前提。

**当前结论：有相减之外的工具，但最值得先做的路线，是保留差分提供的明确编辑方向，改进“怎样识别当前速度需要哪一种修正”。** 单纯把减法换成旋转、SVD 或最优传输，既不能自动改善擦除，也不足以构成新颖性。本文推荐先验证一个简单的候选：**成对核加权速度传输**（Paired Kernel Velocity Transport，PKVT，暂定名）。

它用同一冻结模型，在同一 latent、同一时间上得到多组 target/anchor 的速度；根据用户速度与每组两端的距离，选择并组合局部修正。它既考虑“更接近 target 还是 anchor”，也允许“离所有参考都很远，因此不干预”。核心不需要反向传播、外部视觉模型或内部 attention hooks。

这是一份研究设计，尚未运行真实 DiT 擦除实验。附带的数值检查只验证几何性质和反例；方法是否有效、是否具有足够论文新颖性，分别由实验和进一步的定向查新决定。

## 1. 两篇重点论文提供了什么，也留下了什么

### 1.1 Semantic Steering：表示差分，而非输出速度差分

[Semantic Steering](https://arxiv.org/html/2608.12829v1) §3.2–3.3 从成对提示中提取中间 block 的文本分支表示，对发生变化的 token 做聚合，平均得到 safe−target 方向。归一化后，在连续的早期和中期 blocks 注入，并跨去噪步使用。它已经包含多组成对提示，而非只使用一组词。

值得继承的是**成对上下文控制**：除了目标概念，提示尽量保持一致。其具体的文本分支和 block 选择不符合本轮希望尽量与 DiT 内部架构无关的目标，因此这里借鉴其配对原则，不沿用注入位置。

### 1.2 DVE：差分方向加上单侧投影修正

为避免符号混淆，以下用 `e` 表示 target 的输出速度，`a` 表示 anchor 的输出速度，`u` 表示用户提示的输出速度。三者始终在同一状态、同一时间计算。

[DVE](https://arxiv.org/html/2602.01089v1) §4.1–4.2 的关键规则可写为：

\[
d_{\rm safe}=a-e,\qquad
s=\left\langle u,\frac{d_{\rm safe}}{\|d_{\rm safe}\|}\right\rangle,\qquad
u'=u+\gamma[\tau-s]_+\frac{d_{\rm safe}}{\|d_{\rm safe}\|}.
\]

这里的 `s` 是带用户速度幅值的有符号投影，**不是纯余弦相似度**。论文使用 `τ≤0` 降低对无关生成的影响。

DVE §4.3–4.4 还已经提出按时间缓存平均差分、仅在早中期纠正、多概念独立修正后求和。这些内容应作为已有设计和必要对照，不能重新包装成本方法的主要创新。

### 1.3 真正值得改变的三个对象

| 对象 | 现有思路 | 可以检验的问题 |
|---|---|---|
| 概念表示 | 一根固定 steering vector，或一组 target/anchor 条件定义的速度差分场 | 同一概念是否需要若干种局部编辑模式？ |
| 干预判断 | 原始速度在差分方向上的投影 | 共同的状态相关速度是否影响门控？相对两端的距离能否更有选择性？ |
| 修正构造 | 沿一根方向，或汇总若干独立修正 | 是否应由当前生成选择配对关系，再构造本次修正？ |

“动态”本身不是区别：在线 DVE 的差分已经随状态和时间变化。候选方法必须证明的是**相对两端的判断、有限支持范围和多种配对模式**带来的增益。

## 2. 一个应先验证的小问题：门控对共同速度成分是否敏感

给 `u、e、a` 都加上同一个向量 `b`。差分 `a−e` 不变，DVE 的投影分数会增加 `⟨b, d_safe/‖d_safe‖⟩`。

一个二维例子：

| 情况 | target `e` | anchor `a` | 用户 `u=e` | DVE 分数 `s`，取 `τ=0` |
|---|---|---|---|---|
| 原始 | `(2,0)` | `(0,0)` | `(2,0)` | `−2`，触发 |
| 三者同时加 `b=(−100,50)` | `(−98,50)` | `(−100,50)` | `(−98,50)` | `98`，不触发 |

两种情况下用户速度都恰好等于 target，target–anchor 的相对关系相同。这个变换是**共同分量敏感性诊断**，会改变实际 ODE；不能把它当作两个生成系统完全等价的证明。

这个问题对 flow matching 有具体动机：输出速度同时承担状态运输和条件生成，不能直接当作纯语义 embedding。对于 `x_t=(1−t)x_0+tε`、沿 `t:1→0` 采样的线性路径，标准瞬时速度可写为 `(x_t−E[x_0|x_t,c])/t`，其中有条件共享的 `x_t/t` 项。这个恒等式只用于说明共享成分的来源，不把其数值大小或语义纯度当成假设，也不直接套用到平均速度模型。

**最小诊断对照：成对中心化。** 计算用户相对 anchor、沿 target 方向的位置：

\[
q=\frac{\langle u-a,e-a\rangle}{\|e-a\|^2},\qquad
u'=u+\operatorname{clip}(q,0,1)(a-e).
\]

它在 `u=e` 时把输出改成 `a`，在 `u=a` 时不改；共同平移不会改变 `q`。三次条件前向与单对在线 DVE 相同。

但这只是一个**低成本诊断基线**：它可理解为重新选择投影的原点、阈值和截断，仍沿原来的一根差分方向。并且远离两端、只要在该轴上有分量的用户速度，仍可能被改动。仅有这一步，不足以支撑完整论文。

## 3. 主候选：成对核加权速度传输 PKVT

### 3.1 想检验的核心假设

一个概念在不同场景、姿态、构图下，可能表现为多种速度编辑模式。提前把这些差分平均，会丢掉“当前属于哪一种模式”的信息；不加选择地汇总，也可能引入无关的替代内容。

**候选假设：保留配对关系，以当前用户速度对这些局部编辑进行选择，比统一施加平均方向更有利于擦除与保留之间的平衡。** 这里的“局部”首先指速度空间中的邻域，不预设必须进行空间 patch 定位。

### 3.2 最少需要哪些输入

每个待擦除概念准备 `K` 组成对提示 `(p_e^j, p_a^j)`：每对只改变目标语义，不同对覆盖不同上下文。初试取 `K=1、2、4`；不训练提示生成器。

例如擦除一个特定人物身份，可以准备“该人物的肖像 / 一位普通成年人的肖像”“该人物在室外微笑 / 一位普通成年人在室外微笑”等配对。对象擦除要先确定意图：把“教堂”泛化成“普通建筑”，与让建筑完全消失，是不同任务。风格擦除也要明确替代风格，避免把统一转成某一种画风误算为质量保留。

在每个启用干预的采样步，用**当前用户轨迹上的同一个 `x_t`** 计算 `u` 及所有 `e_j、a_j`。不能用两条已经分叉的 target/anchor 轨迹上的速度直接相减。

### 3.3 核心操作：比较两端，再搬移相应分量

对每对参考，用其自身的差分长度作为距离单位：

\[
k^e_j=\exp\!\left(-\frac{\|u-e_j\|^2}{\sigma^2\|e_j-a_j\|^2}\right),\qquad
k^a_j=\exp\!\left(-\frac{\|u-a_j\|^2}{\sigma^2\|e_j-a_j\|^2}\right).
\tag{1}
\]

得到每组的非负编辑系数，然后组合修正：

\[
\beta_j=\frac{[k^e_j-k^a_j]_+}{\eta K+\sum_{\ell=1}^K(k^e_\ell+k^a_\ell)},\qquad
u'=u+\lambda\sum_{j=1}^K\beta_j(a_j-e_j).
\tag{2}
\]

`σ` 控制参考的作用范围，`λ` 控制总体强度，`η>0` 是“无参考支持时允许不编辑”的固定底量。初试固定 `η=0.05`，只扫少量 `σ、λ`；这些是待验证的初值。差分长度近零的配对跳过，距离、指数和求和用 FP32。有效配对数用于式中的 `K`；没有有效配对时直接返回 `u`。

这个 RBF 核只是相似度权重，不意味着速度服从高斯分布，也不把 `β` 解释成真实的不安全后验概率。

### 3.4 为什么这个构造比“给差分再乘一个系数”多一些内容

1. **相对两端判断。** 同时比较 target 和 anchor，而非仅看用户原始速度是否与某个方向相反。共同平移三者，系数与修正量不变。
2. **允许没有合适参考。** 当用户速度离两端都很远时，两种核值都趋近零，固定底量使修正也趋近零。只用归一化 softmax 会强制选出某个参考，不能得到这个行为。
3. **保留不同编辑模式。** `K>1` 时，当前速度决定本次采用哪些差分；修正不必与全局平均差分共线。同一个概念的不同上下文仍属于同一个擦除任务，不是把 K 个概念的结果简单相加。
4. **直接编辑输出。** 没有特定 block、Q/K/V、单流或双流结构假设；基础接口只有模型前向输出和 sampler。

`Σβ_j≤1`，因此在 `0≤λ≤1` 时，修正范数不超过当前参考中最大的差分范数。这只是一个便于控制数值幅度的性质，不代表生成质量或语义保留的保证。

`K=1` 主要改变门控，方向仍是 `a−e`；`K>1` 才有状态相关的方向组合。应分别报告这两部分的贡献。

### 3.5 一个很容易漏掉的细节：底量 η 具有实际作用

在单对情况下，如果把 `η` 设成零，沿差分轴的垂直距离会在分子、分母中约掉。即使用户速度离两端都很远，仍可能得到较大的归一化系数。

因此 `η` 不能只当成机器精度级的防除零常数。它负责保留“本次没有参考支持”的选项。分母使用 `ηK`，使完全重复一组成对参考不会改变总修正。

### 3.6 最小伪代码

```text
准备少量固定的成对文本条件，预编码并复用文本 embedding

对 sampler 的每个实际求值状态 (x, t)：
    u = 当前用户提示下、准备交给 sampler 的速度
    若当前步不在实验规定的干预范围：使用 u
    否则：
        在相同 x、t、guidance 配置下计算所有 e_j、a_j
        跳过差分长度近零的配对
        由式 (1) 计算两端的核相似度
        由式 (2) 得到 u'
        把 u' 交回原 sampler
```

第一版只做这一件事：全局速度上的成对核传输。先不加入额外分类器、VAE 预览、内部注意力掩码、动量、可学习门控或子空间保护模块。

### 3.7 计算量与“少量提前计算”的边界

设一次正常 sampler 求值需要 `B` 次网络前向，总共 `T` 次求值，其中 `L` 次启用干预。在线参考版本的调用数为 `BT+2KL`。普通单条件模型 `B=1`；标准 CFG 可复用同一状态的 unconditional 预测，参考条件共享该结果。批处理能改善耗时，但不会把这些调用数消掉。

| 方法配置 | 额外前向数 | 应如何理解 |
|---|---|---|
| 单对 DVE / 成对中心化 / 单对 PKVT，全部步 | `2T` | 可直接控制计算预算比较门控 |
| K 对 PKVT，全部步 | `2KT` | 验证多模式价值的研究版本 |
| K 对 PKVT，仅 L 次求值 | `2KL` | 需与相同干预范围的 DVE 比较 |
| 例如 `B=1,T=28,K=2,L=7` | 额外 `28`，总共 `56` | 约为基础前向次数的两倍；实际耗时需测量 |

该方法模型参数冻结、无需梯度训练。少量校准只用于固定提示对、选 `σ、λ`，以及决定干预时间范围；这属于离线校准，应单列其图像数和前向成本。

**默认不跨 seed 缓存完整速度张量。** 本方法的距离依赖当前状态，直接换成其他轨迹的速度，可能破坏其依据。DVE 已有平均差分缓存；若后续研究缓存或蒸馏，须独立验证，不能提前宣称“离线算一次即可零额外前向”。

### 3.8 必须先解决的失败可能

| 可能失败的原因 | 应观察什么 | 结果如何影响决策 |
|---|---|---|
| 长提示的场景变化远大于目标概念差异 | 明确包含目标的提示，两个核仍都接近零 | 模板参考不足；若少量增加上下文仍无效，放弃全局核版本 |
| 不同语义在速度空间混叠 | 近邻保留概念也得到较大 `β` | 相对距离不能可靠判断概念；不能靠继续堆门控掩盖 |
| 某对 anchor 接近另一对 target | 安全样本因其他配对被干预 | 配对间冲突，需要筛选并报告；单对端点性质不自动推广到多对 |
| 不同模式仍抵消或重复 | 多对核选择与均值差分效果相同 | 多模式假设缺少支持，应缩减方法主张 |
| 替代概念覆盖了其他内容 | target 减少，但背景、姿态或其他主体变化明显 | “残余速度保留”只是代数构造，须以实际保留指标判断 |
| 少步模型一开始就确定概念 | 晚期门控触发但擦除无效 | 重新验证前几步；不把跨多步累积当作必然条件 |

空间局部版本只在第一个问题被实测证实后再考虑：将**最终输出速度**按 latent 空间划为窗口，分别计算相似度和修正。它仍不要求内部 attention，但会引入窗口大小、语义定位与边界连续性问题。不能把输出位置天然当作可靠概念分割。

## 4. 相减之外，还有哪些数学工具

首先要明确：任意映射都能写成 `T(u)=u+[T(u)−u]`。因此判断方法是否突破单一 steering vector，应该看映射如何依赖当前输入、保留了哪些配对结构，而非最终更新式有没有减号。

| 工具 | 怎样构造编辑 | 优点 | 当前判断 |
|---|---|---|---|
| **二维旋转 / 正交 Procrustes** | 在 target 与 anchor 张成的平面内旋转；多对时拟合小型正交映射 | 可控制方向变化与范数变化，形成清楚的几何对照 | 可作为非加性备选；旋转概念擦除已有 OCE、SafeRoPE |
| **低秩成对线性映射** | 保存 target 到 anchor 的对应关系，以小矩阵解出速度响应映射 | 多种编辑模式不必先平均，少量样本可闭式校准 | 与 AcT、MidSteer 很接近；仅移到 velocity 不足以确认创新 |
| **协方差 / 广义特征方向** | 比较两组速度响应的变化范围，提取 target 特有的变化模式 | 能表达均值差分遗漏的多方向变化 | 高维小样本估计可能不稳定，适合作探索而非第一版主线 |
| **核回归 / 局部重心传输** | 根据当前速度的邻域关系，选择相应的成对位移 | 不要求统一全局方向，不必拟合复杂网络 | 本文优先路线；须区别于已有核排斥和自适应负引导 |
| **有限差分 / 局部导数 / Lie bracket** | 比较略微移动 latent 后的条件速度响应，或比较条件流的作用顺序 | 可刻画单次差分看不到的局部变化 | 额外前向多，方向符号缺少天然语义；暂不推荐主做 |

### 4.1 旋转：确实改变算子，但保范数不等于保内容

一个清楚的非加性候选是：在同一状态减去共同参考速度 `v_ref`，得到条件响应；只在 target/anchor 的二维平面内旋转用户响应，然后加回共同参考。

最小规则可写为 `u'=v_ref+R(u−v_ref)`，平面外分量保持原样。二维平面能用两个基向量实现，不需要构造 latent 维度的巨大矩阵。若要同时调整强度，可另比较带缩放的版本，但它已经失去严格保范数性质。

这里仍需要单侧门控：对所有输入都旋转，可能继续改变已经安全的响应。两个响应长度不同时，纯旋转不能将 target 精确映成 anchor；方向近乎平行时缺少转动空间，近乎反向时转动平面也不唯一。

[OCE](https://arxiv.org/html/2605.28902) 已用正交 Procrustes 做参数编辑，并包含 DiT 扩展；[SafeRoPE](https://arxiv.org/html/2604.01826v1) 已研究 rectified-flow Transformer 内部 head 的旋转。输出速度上的局部旋转仍可研究，但“使用旋转”本身不是空白。

### 4.2 低秩映射：从“往哪推”变成“怎样把这一类响应改成另一类”

把成对 target 响应列为矩阵 `E`、anchor 响应列为 `A`，可以求一个接近单位映射的 `M`，让 `ME≈A`。这是小样本配对回归，可在样本数维度求解，避免形成巨大的全维参数矩阵。

它比平均差分多保留了输入和输出之间的对应关系。但只要求 target 被映到 anchor，并不保证 anchor 和其他良性响应保持不变；添加保留样本会产生约束冲突，且需要更多校准数据。不同状态之间是否能共享同一个映射，也必须验证。

[AcT](https://arxiv.org/html/2410.23054) 已通过激活分布传输控制生成，[MidSteer](https://arxiv.org/html/2605.05220v3) 已研究最小扰动的仿射概念变换。因此这条路线适合作为强对照或后续扩展，论文需要证明 flow 输出速度这一接口带来的具体新问题与解决办法。

### 4.3 在差分上继续创新：哪些有价值，哪些容易重复

- **更值得检验：** 保留成对关系、识别多种局部编辑模式、让门控具有相对参考和无支持时不干预的能力。
- **可作为对照：** 均值改中位数、差分做 SVD、平滑时间权重。这些可以改善稳定性，单独的新颖性通常有限。
- **已有高度相邻工作：** 把差分在 retain subspace 上的分量去掉。[RASteer](https://arxiv.org/abs/2610.01969) 已直接研究 retain-orthogonal steering 与重叠自适应校准。用于输出速度可能有迁移价值，但不能把该操作本身当新贡献。

## 5. 与最近邻方法怎样划清研究问题

| 最近邻 | 已有的关键内容 | PKVT 必须单独证明的内容 |
|---|---|---|
| Semantic Steering | 多组成对提示、平均表示差分、内部文本分支干预 | 不平均掉配对模式，且仅用输出速度仍有效 |
| DVE | 在线差分场、单侧投影、缓存、早期纠正、多概念求和 | 相对两端与有限支持是否提高选择性；多模式是否优于等预算 DVE |
| [Dynamic Negative Guidance](https://proceedings.iclr.cc/paper_files/paper/2025/hash/5647763d4245b23e6a1cb0a8947b38c9-Abstract-Conference.html) | 状态和时间相关的负引导，近似跟踪类别后验 | 当前速度邻域中的几何规则；不声称 RBF 得到了正确类别后验 |
| [SGF](https://arxiv.org/abs/2603.13300) / Safe Denoiser | 对负参考数据进行核加权或势能排斥 | 当前状态上成对条件速度之间的选择与替换，而非对参考图像的排斥 |
| AcT / MidSteer | 表示传输与仿射概念控制 | 无需学习内部层映射的输出接口，以及有限参考下的实际效果 |
| OCE / RASteer | 正交编辑与保留子空间设计 | 不将正交化或保留投影重复计为创新 |

[VESFlow](https://arxiv.org/html/2606.23267v2) 也是必须注意的输出速度相关工作，其实现使用图像安全 scorer 的梯度。它适合作为相关工作或效果参照，本候选的机制不依赖该组件。

**还要排除一个表面的区别：velocity 与预测干净样本之间可存在仿射等价。** 对本文第 2 节的线性路径，在同一状态和时间，预测干净 latent 为 `x̂_0=x_t−t v`。所以式 (1) 的归一化距离也能用各条件的 `x̂_0` 表示，式 (2) 能改写为成对干净预测的位移组合。这是当前局部预测的代数等价，不保证一次预测等于最终采样结果。与 SGF 等工作的实质比较应落在**同一生成器当前状态上的成对条件参考、配对选择与修正规则**，不能仅以“我们改 velocity、它们改 x̂_0”宣称区别；本候选也不主张算子在数学上只适用于 flow。

“核权重”“自适应强度”“输出 velocity”“成对样本”分别都有相关先例。**本轮只提出一个值得实验的组合性研究问题，没有确认完整组合的首创性。** 查新要核对操作空间、参考来源、是否保留配对、门控依据以及是否需要反向传播，不能只搜方法名字。

## 6. 实验顺序：先判断机制，再决定是否扩展

### 6.1 第一轮：最小诊断

先用一个对象或风格概念，在一个 flow-matching DiT 上做 4 组提示，每组 8 条、2 个 seed：共 64 条基础轨迹。四组分别为明确 target、隐式/改写 target、语义近邻保留概念、无关长提示。先固定少量时间点记录 `u、e、a` 的投影、相对距离和核系数。

比较基础模型、单对 DVE、成对中心化、单对 PKVT。三种干预使用相同参考条件、guidance、时间范围和前向预算，并分别扫描适当强度。不要用相同数值的超参数代替相同擦除强度或相同保留水平。

这一轮回答：原始投影和相对距离的门控是否有实际差异？差异是否减少良性误触发，同时保持 target 的干预能力？如果长提示的核几乎始终为零，应先停止扩展，检验全局距离是否不适合本任务。

### 6.2 第二轮：多模式是否有独立价值

比较以下配置：

| 配置 | 要隔离的因素 |
|---|---|
| DVE 原始单对 | 原始参照 |
| DVE 使用 K 个上下文差分的均值 | 多参考本身的收益 |
| 对同一概念 K 对参考独立做 DVE 修正后求和，标明这是适配对照 | 独立投影与局部选择的区别 |
| PKVT `K=1` | 两端门控与有限支持 |
| PKVT `K=2、4` | 当前状态选择编辑模式的增益 |
| PKVT `η=0` | 无支持时拒绝干预是否必要 |
| 固定均匀系数替代 PKVT 的系数 | 收益是否只来自差分数量或幅度 |
| 所有配对使用同一个 anchor，或置换 anchor 配对 | 收益是否真的需要对应关系；置换结果需同时检查配对合理性 |

至少增加风格、实例或安全概念中的另外两类，再复用固定协议测试第二种 flow DiT。FLUX.1-dev 与 SD3.5 系列可作为起点；两者之间的成功不能代表所有 DiT 架构均已验证。

第一轮不改内部结构。使用标准 CFG 时先组合出真正交给 sampler 的用户与参考速度，再统一编辑，避免后续 CFG 改写编辑强度。guidance-distilled 模型使用其原生 guidance 输入。高阶 sampler 在每次实际模型求值处使用同一规则，并按真实 NFE 统计。

### 6.3 至少报告四类结果

1. **擦除与鲁棒性：** 明确、隐式、改写提示的 target 生成率；固定攻击集和针对当前 wrapper 的自适应攻击应分开。主方法不依赖外部模型，不妨碍离线使用标准评估器。
2. **保留与图像质量：** 近邻保留概念、其他主体、属性、背景，以及无关提示的质量。小规模先做图像对照和人工核验；FID 需在足够样本下正式报告。
3. **模式与门控诊断：** 分组触发率、核支持度、每对贡献、修正范数，以及当前修正与平均差分的夹角。这些用于解释机制，不当成擦除成功率的替代指标。
4. **成本与多样性：** 离线校准图像数、网络调用数、每图耗时、显存、跨 seed 多样性。报告擦除—保留曲线和成本，而非只选一张好看的图。

若 PKVT 只因为更少干预而提高保留，但在相同擦除率下不优于 DVE，主假设不成立。若多对选择不优于均值差分，就没有证据声称需要多模式传输。若只在一个概念、一个 anchor、一个架构有效，则应缩小适用范围。

## 7. 对本轮约束的检查

| 要求 | 本候选的落实方式 |
|---|---|
| 优先 flow-matching DiT | 直接以 flow 输出速度为干预对象，主实验只选该类模型 |
| 与具体 DiT 架构尽量无关 | 主方法只依赖最终输出与 sampler，不读取内部层 |
| 操纵 velocity 预测 | 相似度、方向和修正全部在输出速度空间 |
| train-free 或少量校准 | 冻结模型、纯前向；小规模选模板与超参数，单列校准成本 |
| 不过度依赖外部组件 | 无 VLM、图像分类器、SAE 或额外生成器参与干预 |
| 数学与工程平衡 | 核心只有距离核、非负系数、成对位移组合；不假定全局线性可分或高斯语义分布 |
| 参考两篇重点论文 | 继承成对上下文和输出接口，直接对照其差分、投影及已有加速设计 |

方法属于推理期抑制：关闭 wrapper 后仍是原模型。若目标转为发布永久擦除后的权重，需要另行研究蒸馏或参数更新。

## 8. 建议的推进选择

优先完成**单对 DVE → 成对中心化 → 单对核门控 → 多对局部传输**的逐项对照。前三者可以先用相同参考计算预算，快速判断问题是否真实；只有多对选择带来独立收益，再把 PKVT 发展成论文方法。

旋转与低秩映射保留为数学上不同的备选。当前不建议先投入复杂的最优传输分布建模、完整高维协方差估计或多模块系统。
