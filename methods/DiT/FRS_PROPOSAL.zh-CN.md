# FRS：流响应校准的安全语义注入

日期：2026-10-25。工作名：**Flow-Response-Calibrated Semantic Steering（FRS）**。

本提案替代 CFG-PTE 与 CFTR，针对最新约束：不依赖生成模型之外的模型；推理不增加轨迹、采样分支或候选搜索；使用适量数学明确安全语义如何构造、如何注入。

当前状态：完成构思、相关工作边界核对与实验设计。尚未实现模型 hook、运行校准或开展 DiT 图像实验。

## 1. 核心切入点

**一个隐藏空间中的“安全方向”，需要通过模型后续计算，才能变成有效的生成修改。构造方向时，应把这段计算的实际响应纳入，而不能仅根据隐藏表示之间的距离选择方向。**

FRS 先从冻结 DiT 中提取少量候选语义方向，再用 DiT 自身测量它们对两步 flow 采样的影响。通过一个小规模线性方程，联合确定各候选方向的系数：目标提示的响应接近预先指定的安全替代语义，保留提示的响应接近原模型。

部署时只注入预先合成好的向量。没有另一个判别器、VLM、CLIP 图像模型、控制网络或每张图的优化循环。基础生成管线原有的文本编码器属于生成模型本身，不引入额外编码器。

这里包含少量数据依赖的系数拟合，准确分类为 **冻结模型、无梯度的少参数校准，推理时进行 activation steering**。不是零校准，也不把解线性方程误称为完全没有参数估计。

## 2. 与先前两种构思的区别

- 不定义新的目标概率分布，也不求解连续性方程或训练输运控制器。
- 不生成候选图再判断安全，不做回退、重生成或多图筛选。
- 研究对象转为“内部语义修改经过 DiT 后，会怎样改变实际采样更新”。

安全替代语义由研究者指定，例如 `Snoopy → ordinary cartoon dog`。这种指定与擦除任务一致：若目标是整个“狗”类别，就不能用普通狗作为安全替代。模型提供该语义的生成响应，不承担对图像安全与否的自我认证。

## 3. 动机及其可检验性

Semantic Steering 从中间块提取安全／目标语义差，再把向量注入多个块。[原文](https://arxiv.org/html/2608.12829)

由此可以提出两个需要实测的问题：

1. **表示方向与生成效果是否失配？** 两个向量在隐藏空间中同样接近安全表示，经过后续网络后，可能具有不同的擦除效果和附带影响。
2. **单步变化能否维持？** 本步注入后，下一步仍使用原提示；后续计算可能减弱或改变本次干预。因此，单步输出对齐不一定等于一段采样后的状态对齐。

这两个问题都能直接测量，不预设“真实概念线性可分”“flow 轨迹严格笔直”或“某个 block 永远编码同一语义”。它们尚未在本项目中得到实验验证。

## 4. 先提取候选方向，暂不把它们认定为最终安全向量

### 4.1 构造成对文本

准备少量模板，保持上下文相同，只替换擦除部分。例如：

```text
Snoopy sitting beside a golden retriever on a beach.
An ordinary cartoon dog sitting beside a golden retriever on a beach.

A drawing of Snoopy in a garden.
A drawing of a generic cartoon dog in a garden.
```

另准备普通狗、金毛、其他角色、人物与风景等保留提示。近邻保留提示必须包含在内，避免仅用差异很大的风景图代表所有保留能力。

这些模板可人工编写，不调用外部语言模型。校准阶段不自动改写用户提示；部署时保留用户原提示。

### 4.2 在相同状态、相同时间提取成对表示

用基础模型自己的采样获得少量 noisy latent。固定同一个 `z_k` 和 timestep，分别输入目标提示与对应替代提示，读取候选块中的文本 token 隐藏状态。

对被替换文本片段对应的 token 分别池化，然后求差：

\[
d_{\ell,j}
=\operatorname{mean}_{i}
\left[\bar h_{\ell}(z_i,k_i,p_{i,j}^{\mathrm{safe}})
-\bar h_{\ell}(z_i,k_i,p_i^{\mathrm{target}})\right].
\]

`ℓ` 是注入块，`j` 是替代措辞类别。目标词与替代短语的 token 数可以不同，分别池化即可。padding 不参与统计。

每层使用该层自己的向量，不把一个块的坐标直接视作其他块的坐标。时间上先分两个粗区间；每个区间独立统计。

第一版可用四个候选块、两种替代措辞，形成每个时间区间八个“方向＋注入位置”候选。按本层激活的 RMS 统一尺度，避免最小二乘仅因向量数值大小不同而偏好某个候选。

成对激活差是已有构造，本身不作为创新。它只提供一个小型候选集合，最终安全语义还要经过生成响应校准。

## 5. 只用生成器自身测量两步响应

### 5.1 两步脉冲试验

从校准状态 `z_k` 出发：

1. 第一个采样步，在选定块注入候选语义。
2. 第二个采样步不注入，继续使用原提示和原生采样器。
3. 记录两步之后的 latent。

这直接测量一次干预在下一步之后留下的变化。两次前向都来自原本的生成器，不需要 VAE 解码或图像评分。

记 `F_i(a)` 为上述两步程序的终点：`a` 是各候选方向的系数，`F_i(0)` 是未注入的两步结果。两步都使用本模型原生 CFG / guidance 配置。这个符号只是两步真实程序的简写，不是另一个学习到的模型。

对目标提示，用同一个起点执行两步替代提示采样，得到 `F_i^safe(0)`。期望的修改是：

\[
b_i=F_i^{\mathrm{safe}}(0)-F_i(0).
\]

保留提示的期望修改为零。

这个目标表示“接近模型在替代语义下的短程响应”，不保证替代提示生成的最终图像绝对无目标，也不等于已验证的图像语义标签。

### 5.2 无梯度测量每个候选的作用

对第 `j` 个候选单独施加小幅度 `ε`：

\[
A_{i,j}=\frac{F_i(\varepsilon e_j)-F_i(0)}{\varepsilon}.
\]

每列都是一个实际测量到的 latent 响应。它已经包含后续 blocks、第一个 solver 更新，以及第二个无注入采样步的影响。

不计算高维 Jacobian，不反向传播，也不构造全尺寸逆矩阵。每个响应只用于累计一个很小的 Gram 矩阵。

主要近似是：在所用幅度附近，多候选同时注入的响应可以用各列的线性组合近似。这是局部近似，必须在留出状态上比较 `F_i(a)-F_i(0)` 与 `A_i a` 的实际误差。

## 6. 用一个小规模问题构造最终安全语义

将目标样本的响应堆叠为 `A_F`，保留样本的响应堆叠为 `A_R`，目标修改堆叠为 `b`。按样本数归一化后，求：

\[
a^* = \arg\min_a
\underbrace{\|A_Fa-b\|_2^2}_{\text{接近替代语义的生成响应}}
+\lambda\underbrace{\|A_Ra\|_2^2}_{\text{保持保留提示的生成响应}}
+\eta\underbrace{\|a\|_2^2}_{\text{限制系数大小}}.
\]

其解由小矩阵线性系统得到：

\[
(A_F^\top A_F+\lambda A_R^\top A_R+\eta I)a^*
=A_F^\top b.
\]

实现时用稳定的线性求解，不显式求逆。八个候选只需解一个 `8×8` 系统。两个时间区间共拟合十六个标量，基底向量和原型则由前向统计获得。

该式的意义很直接：一个候选若能产生期望的替代响应，并且对保留提示影响小，会更值得使用。不同层的响应若相互重复、抵消或互补，也会通过矩阵的交叉项影响系数。

数学贡献不在岭回归公式本身。候选创新是：**用短程 flow 生成响应校准安全语义，并把不同层的注入作为一个联合作用的问题处理。**

正则化不能自动保证局部近似准确。校准后需用真实两步程序验证；若拟合系数过大、近似误差高或目标残差始终很大，应报告这一小型候选集合不足，而不宣称已找到正确擦除语义。

## 7. 部署时怎样注入

每层、每个时间区间预先合成：

\[
s_{\ell,b}=\sum_j a^*_{\ell,j,b}d_{\ell,j,b}.
\]

推理时只做：

\[
h_{\ell,i}\leftarrow h_{\ell,i}+g_{\ell,i}s_{\ell,b}.
\]

其中 `i` 为文本 token。固定脉冲表采用“本步注入、下一步不注入”，与两步校准程序保持一致。偶数步数的采样可以直接分组；奇数步数最后的单步应单独处理，不能把两步校准直接视作相同情况。

两段时间区间是起始实现，用于容纳早晚响应差异。它们不表示概念一定在两个固定阶段形成；区间数量和每步注入版本需要消融。

### 7.1 内部软门控

第一版可以复用已有 steering 路线常用的原型相似度门控：比较当前文本 token 与目标原型、替代／近邻原型的相似度，经截断线性函数得到 `g∈[0,1]`。

这些原型全部来自当前 DiT 的上述前向统计；操作只是当前隐藏状态上的点积。没有外部概念判断器，也不训练 SVM 或 MLP。门控所用公式和阈值在校准前固定，响应测量与部署使用完全相同的门控规则。

门控是减少无关输入干预的基础部件，不作为新的贡献。它也可能漏掉隐式目标或误触发近邻概念。必须设置无门控消融，并让关键 steering 基线使用同样的门控，以分离校准的收益。

### 7.2 真实 CFG 与原生 guidance

对于真实 CFG，默认仅修改条件分支；校准时测量的是组合后的实际采样结果，因此包含该 CFG 系数下的响应。默认不新增分支。

FLUX.1-dev 的原生 guidance embedding 直接沿用，不把它误认为真实两分支 CFG。若改变 guidance、步数或 scheduler，响应会改变；应进行跨配置测试，必要时为配置重新离线校准。

### 7.3 架构接口

第一版在 FLUX.1-dev 与 SD3.5 上读写文本位置的 residual hidden states。双流结构使用文本流；单流结构需要准确索引联合序列中的文本位置。

它不修改 attention head、Q/K/V 或 RoPE，但仍需各模型的 hidden-state hook 和 token 位置适配。对于没有对应文本隐藏状态接口的模型，不能未经实现就宣称自动兼容。

## 8. 成本边界

### 在线推理

- 原生采样步数不变；FLUX.1-dev 仍可使用此前确定的 28 步。
- DiT NFE 与相同配置的基础模型一致。
- 不额外编码每张图的安全提示，不解码中间图像，不做候选续程。
- 新增计算为少数层中的原型相似度和向量加法；运行时开销需要实测，NFE 相同不等于时延严格相同。

### 离线校准

设目标状态数为 `N_F`、保留状态数为 `N_R`、候选数为 `K`。采用单边有限差分和两步响应时，响应测量与安全参考大致需要：

```text
2 × [(K + 1) × (N_F + N_R) + N_F]
```

次采样步计算，另加状态采集、方向提取和留出验证。真实 CFG 的分支数需再计入模型前向总量。

例如 `K=8`、目标与保留各 16 个状态，测量部分是 608 次采样步计算；若分布在两个时间区间，按各区间实际状态数累计，不重复把样本数翻倍。这是预算算例，不是实测耗时。状态采集等成本也不可省略。

因此这条路线省的是每张生成图的额外采样成本。每概念、每 backbone 的离线校准仍需付费，不能描述为“瞬间得到安全向量”。无需构建训练控制器的数据集与反向传播管线。

## 9. 两项候选贡献及检验方式

### A. 功能校准的安全语义构造

安全方向由其实际生成响应和保留响应共同决定，而不仅由激活差、余弦相似度或隐藏空间中的正交关系决定。

验证：相同候选方向、模板、门控与注入预算，对比均匀平均、隐藏空间保留投影、单步响应校准。若响应校准没有改善擦除／保留曲线，不能主张这一贡献。

### B. 两步脉冲响应与跨层联合注入

构造时纳入一个无注入的后续采样步，部署时使用一致的脉冲策略；各层系数联合求解，考虑它们对同一生成更新的共同作用。

验证：单步校准与两步校准；逐层独立求解与联合求解；每步注入与隔步脉冲。对比应同时控制总注入量和生成配置，避免把单纯减小强度误认为新的持续性机制。

两个贡献都有可能失败。特别是两步校准只是对局部持续性的检验，不提供整个采样轨迹的安全保证。

## 10. 与相关工作怎样区分

| 工作 | 相关点 | 本方案需要证明的增量 |
|---|---|---|
| [Semantic Steering](https://arxiv.org/html/2608.12829) | 成对内部表示差与激活注入 | 相同方向集合下，生成响应校准和脉冲策略带来的收益 |
| [RASteer](https://arxiv.org/html/2610.01969) | 用保留子空间处理目标／保留方向重叠 | 保留约束落在实际采样响应上，而非仅隐藏空间几何；需直接对比 |
| [MidSteer](https://arxiv.org/html/2605.05220) | 仿射 steering 与最小扰动 | 不将线性求解或最小扰动目标本身当作新贡献 |
| [GEM](https://arxiv.org/html/2606.00140) | 使用冻结教师的生成响应进行擦除 | 候选空间是固定语义方向上的少量系数，具有无额外在线模型的部署形式 |
| [AcFlow](https://arxiv.org/html/2609.10723) | 把生成控制蒸馏到激活空间 | 不学习 FlowBlock 或状态依赖向量场；应比较表达能力损失与成本收益 |
| [DVE](https://arxiv.org/html/2602.01089) | 在生成输出中利用替代／目标条件差异 | 本方案将短程响应离线转成内部注入，在线不计算或投影额外概念速度 |
| [Principal Steering Subspaces](https://arxiv.org/html/2609.33765) | 用有限差分的生成器响应构造控制坐标 | 该思想在机器人策略上已有先例；不能把“有限差分响应空间”泛称为首次 |

ARCE 的 eraser token 训练、UVR 的 attention 信息流调制、VESFlow 的外部评分梯度均不属于本方案步骤。

这次检索不能保证不存在完全同类工作。论文新意应围绕 flow 文生图擦除中的可测量增量，不以单个数学工具或更换干预层作为充分论据。

## 11. 最小可行实验

从 FLUX.1-dev 开始：bf16、512×512、28 步。之后用 SD3.5 检验是否依赖 FLUX 的特定表征。

先选择一个身份／角色概念和一个局部属性概念。每个概念准备成对模板、近邻保留模板和完全无关模板；留出不同上下文、别名、描述性提示及种子。

首先做四个版本：

1. 相同候选方向的普通 Semantic Steering 式注入。
2. 单步响应校准，包含保留项。
3. 两步脉冲响应校准，逐层独立求解。
4. 完整 FRS：两步响应、联合求解、匹配的脉冲注入。

要求模板、候选层、内部门控、生成预算一致。另做去掉保留项、无门控和随机方向候选的消融。

校准与推理全程不读取外部模型分数。最终效果可用人工概念标注和独立评测指标判断，这些评测不反馈给算法。先验证擦除和近邻保留，再扩展 COCO 一般生成能力与攻击提示测试。

## 12. 分析与可视化

- **隐藏空间与响应空间的差别**：比较方向的隐藏余弦相似度、实际 flow 响应相似度，以及最终擦除／保留表现。
- **层 × 时间系数图**：哪些方向在什么阶段有用；不同模板和种子下是否稳定。
- **两步持续性图**：第一步注入后的状态变化，到第二步之后如何改变；使用模型自身响应测量，并配合最终图像。
- **线性近似误差**：预测响应与实际多方向共同注入响应的偏差，随注入强度变化的曲线。
- **保留权重曲线**：`λ` 改变时擦除与近邻保留的折中，避免只报告单个最佳点。
- **实际成本**：离线校准时间、峰值显存、在线时延、NFE、缓存大小。

## 13. 必须如实保留的限制

1. 少量系数拟合仍属于校准；它的成本和使用数据需要披露。
2. 替代提示是语义意图，不是可靠图像标签。教师自身不能表达该替代时，响应目标也会有问题。
3. 有限方向集合可能无法同时实现强擦除与保留；高拟合残差可提示这一点。
4. 局部线性响应只在有限幅度附近有效；大幅度组合可能失配。
5. 原始采样状态与干预后的状态可能不同，离线校准存在状态分布偏移。
6. 内部相似度门控可能漏掉隐式概念；不能用其低响应替代最终擦除评测。
7. 缓存向量依赖 backbone 与采样配置；多概念叠加也需要重新验证。

这些限制对应可以测量的残差、泛化与效率问题。第一阶段不增加新的控制网络或数学分布模型去掩盖它们。
