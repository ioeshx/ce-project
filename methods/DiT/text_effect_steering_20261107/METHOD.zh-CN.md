**通过离线视觉效应提纯的文本 Steering：DiT 概念擦除方案**

日期：2026-11-07。状态更新于 2026-11-08：用户认可 joint attention 的文本干预方向；已否决本文依赖最终生成响应与外部指标的向量提纯，以及复杂数学建模。本文保留为历史讨论记录，不作为当前方法计划。后续设计遵循[项目研究约束](/home/shx/code/ce-new/AGENTS.md)。

直接干预放在联合注意力的 text Value。先由正负提示词统计得到少量文本方向，再对这些方向做离线、同 prompt 同 seed 的正负扰动试验；用最终图像上目标概念与其余内容的实际变化，求出目标效应明确、无关损伤较低的组合。部署时保存固定向量和校准参数，仅在 text Value 上施加加减。

这条路线对应三个问题：文本候选方向来自哪里；如何按生成作用剔除无关分量；如何在正常范围内控制干预剂量。image 特征和解码图像用于离线测量与验证，直接写入对象为 text Value。

**1. 选择 text Value 作为直接写入位置。**

一个 head 的联合注意力中，图像输出写成

\[
O_I=A_{II}V_I+A_{IT}V_T.
\]

其中 A 是原模型由 Q、K 计算的联合 softmax 权重。对文本 token j 施加

\[
V_{T,j}'=V_{T,j}-\alpha\,a_jv,
\qquad 0\leq a_j\leq 1.
\]

在这一层、相同输入下，Q/K 不变，因此 A 不变，并有精确关系

\[
\boxed{\Delta O_I=-\alpha\,(A_{IT}a)v^\top.}
\]

这让文本内容的改变沿原有的 text-to-image 注意力路径传播。image Value、图像 residual 和噪声预测均由模型正常计算。上述 A 不变的性质限于当前层；经过此次变化后，后续层和后续采样步的注意力仍会自然改变。

多头情况对各 head 的 Value 切片应用向量的相应部分，随后经过原有输出投影和 residual gate。text query 对应的输出也会按原有注意力读取被修改的 text Value，后续文本状态随之演化。

FLUX double-stream 使用 `add_v_proj(norm_encoder_hidden_states)` 的输出，FLUX single-stream 使用拼接序列 Value 中的文本切片；SD3.5 使用联合注意力的 `add_v_proj` 输出。应在普通与 fused QKV 路径上使用同一个语义位置。首轮只选择一个 double-stream 位置与一个噪声区间，避免先引入多个控制位置的相互作用。

当前实现可核对 [FLUX Value 投影及拼接](/software/anaconda3/envs/shx/lib/python3.13/site-packages/diffusers/models/transformers/transformer_flux.py:45)。

**2. 正负提示词只负责提供概念相关的候选空间。**

对场景、姿态、颜色和其他主体相同的提示词构造概念有无配对。实例身份擦除以多个相近普通实例为负条件，例如 Snoopy 对比多种普通狗描述；风格擦除以多个中性风格条件作对照。用多个负条件降低单一替代物偏好的影响。

负条件定义擦除任务：将 Snoopy 变为普通狗属于身份擦除；让狗也从场景中消失属于对象删除，应分别评价。

离线采样原模型，在某个实际中间状态 z_t 上固定 latent、时间和其他输入，分别使用正、负提示词做一次 forward。记录所选位置的 text Value：

\[
D_i=\operatorname{pool}_{\mathrm{role}}
\left(V_T(z_t,p_i^+)-V_T(z_t,p_i^-)\right).
\]

pool_role 表示按配对提示词中对应短语或共享文本跨度对齐后聚合，而不是假定相同序号的 subword 总是对应。不同长度的替换短语分别池化到同一角色；内容 token 与特殊或填充位置分别记录统计，避免长度差异成为主要信号。线上门控覆盖所有文本位置，不依赖目标词字面匹配。

按模板组、同义表达组和负条件等权，先得到稳健均值差 d。再从成组差分围绕 d 的变化中保留少量方向，形成候选基

\[
B=\operatorname{basis}\left[d,\ \text{leading directions of }(D_i-d)\right]
\in\mathbb R^{D\times K}.
\]

K 可先取 4。这里分解的是配对差分的变化，均值方向单独保留。候选可以同时含有有效概念成分、措辞成分和其他语义；下一步按实际生成作用决定它们的组合。

**3. 通过离线正负文本扰动测量视觉效应。**

定义 G_{p,s}(w) 为完整生成过程：在选定窗口执行 `V_T ← V_T - a_j B w`，其余操作按模型原有流程执行。门控规则与上线版本完全相同。每个候选方向 k，固定 prompt p 和 seed s，生成

\[
I_{i,k}^{+}=G_{p_i,s_i}(+\varepsilon e_k),\qquad
I_{i,k}^{-}=G_{p_i,s_i}(-\varepsilon e_k).
\]

随机采样器应同步所有逐步随机数；仅设置最初 seed 而让其他随机源变化不足以隔离干预效应。

用连续图像概念分数 q_c 测量目标响应，定义

\[
g_{i,k}=\frac{q_c(I_{i,k}^{-})-q_c(I_{i,k}^{+})}{2\varepsilon}.
\]

按此符号定义，g_{i,k}>0 表示沿第 k 个方向相减能局部降低目标概念分数。目标包含身份、风格或对象，应使用相应的视觉测量；不能只用整段原 prompt 的 CLIP 相似度充当目标分数。

在包含目标的提示词上，定义其余内容描述函数 phi_keep，包括其他对象、动作、颜色、背景和关系的分数。计算

\[
J_{\mathrm{keep},i,:,k}=
\frac{\phi_{\mathrm{keep}}(I_{i,k}^{+})-
\phi_{\mathrm{keep}}(I_{i,k}^{-})}{2\varepsilon}.
\]

例如擦除 Snoopy 身份时，仍应检查狗这一上位类别、红球、草地和坐姿。目标图像需要改变，目标提示词上的完整图像漂移不适合作为唯一保持目标。

对完全不含目标的提示词，用固定图像编码器的空间特征和低频图像表示 phi_img 测量完整生成变化，同样得到 J_normal。保留特征的分量与各评估器分数要做尺度校准，避免某个高维或大数值表示支配矩阵。

\[
M_{\mathrm{keep}}=\mathbb E[J_{\mathrm{keep}}^\top J_{\mathrm{keep}}],
\qquad
M_{\mathrm{normal}}=\mathbb E[J_{\mathrm{normal}}^\top J_{\mathrm{normal}}].
\]

这些矩阵的维度都是 K×K。

保留项使用有符号特征的有限差分。对正常图像直接微分“相对原图的 LPIPS 距离”容易在零扰动附近失去一阶信息；LPIPS 用于候选最终验证。较大位移还需检测正负扰动的共同漂移，防止只看反对称响应而漏掉二阶损伤。

**4. 用目标作用和无关损伤共同求解最终向量。**

令 g=E_i g_i，为每种模板等权的平均目标响应，令

\[
M=M_{\mathrm{keep}}+
\lambda M_{\mathrm{normal}}+
\gamma\operatorname{Cov}(g_i)+\eta I,
\qquad \eta>0.
\]

Cov(g_i) 用于抑制只在少数模板上有效、跨上下文波动大的组合。求解

\[
\min_w w^\top M w\qquad
\text{subject to }g^\top w=1.
\]

其解为

\[
\boxed{
w^*=\frac{M^{-1}g}{g^\top M^{-1}g},\qquad v=Bw^*.
}
\]

归一化约束中的 1 只约定方向尺度，真实部署使用验证集选定的 alpha。实际计算解线性系统即可。目标响应 g 接近零或上述归一化分母过小时，该候选窗口没有足够的局部控制依据，跳过它。

这个求解保护的是向量实际造成的视觉变化。一个分量如果主要改变颜色而不降低目标身份分数，会增加 M_keep 中的代价；一个分量如果在正常提示词上改变布局，会增加 M_normal 中的代价。方向通过这些统计被抑制。相反，跨模板稳定降低目标分数、其他变化较小的分量会得到较高权重。

这里的“提纯”是按生成作用的操作性定义。实际效果由采用的视觉测量、候选空间的覆盖和有限差分有效区间决定。

**5. 线上只削弱超过正常范围的文本概念证据。**

在 text Value 上另估计一个低成本 reader u，并保存正常均值 mu_R、正常尺度和阈值 tau。reader 可以采用收缩协方差的线性判别器等常规统计工具；训练与校准样本需覆盖真实文本 token 的分布，不能直接把 pooled 特征上的阈值当作逐 token 阈值。

\[
s_j=u^\top(V_{T,j}-\mu_R),\qquad
a_j=\operatorname{clip}\left(\frac{s_j-\tau}{h},0,1\right),\qquad
\boxed{V_{T,j}'=V_{T,j}-\alpha a_jv.}
\]

h>0 是过渡区间的尺度。u 负责读取概念证据，v 负责施加实际有效的干预，两者分别估计。该规则的作用是限制干预范围与幅度，阈值及剂量本身不作为原创贡献。

tau 用完整正常轨迹的最高标准化证据分数标定，并分别检查近邻内容和开放域提示词。每个 token 的低误触发率不能直接解释为整张图像的低误触发率。如果一条正常轨迹所有窗口的门控均为零，且其他计算相同，那么该轨迹的输出与原模型一致。

线上每个窗口只需逐 token 的 reader 点积、标量门控与向量加减。构造和正负扰动试验都在离线完成。当前层注意力保持不变的性质仍成立，因为门控也只用于修改 V。

所有离线有限差分都必须运行这一完整门控规则。冻结 reader 与阈值后估计响应并求解 writer；若更改 reader、门控、窗口或分支配置，应重新估计对应的响应统计。

**6. 最小实验与继续投入的依据。**

先固定 FLUX.1-dev、一个概念、一个 double-stream 位置、一个噪声区间和 K=4。使用八条目标提示词与八条正常提示词，正负扰动约需要 `2×4×16=128` 次额外生成；另计构造候选与原模型参考图像。只为少量候选位置做这一完整测量。该开销在离线阶段。

先用两个扰动半径检查局部响应的方向稳定性，再按模板划分验证集选择 alpha、lambda 和 gamma。较大幅度必须重新检验最终图像，局部导数不能保证强擦除区间的行为。推广至多个窗口时，需要联合测量，避免简单叠加独立最优向量。

首轮对照保持同一 text Value 位置和相同门控，只替换构造方式：普通均值差、稳健匹配均值差、只根据目标响应求解、完整的目标与保持响应求解。同时加入没有门控的固定剂量对照，判断保持收益究竟来自向量还是门控。

基线包括 SHIFT、CASteer、RASteer 与 AdaVD。在相同擦除率下比较正常内容保持；单独检查目标提示词中的其余实体、属性和关系。正常提示词报告近邻保留率、同 seed LPIPS、图文一致性及足够样本量下的分布指标。评估器和测试模板应独立于方向标定，防止对某个视觉分数的优化被当作实际擦除。

继续投入的依据是：独立测试中，响应提纯比同位置的均值差获得更好的擦除—保持曲线。如果图像目标响应始终很弱，先检查是否由门控关闭、测量分数饱和或扰动过小造成，再用固定门控的诊断对照判断候选空间及窗口的控制能力。向量构造再精细也无法补出该通道没有的控制作用。

**7. 与已有工作区分贡献。**

| 工作 | 已有机制 | 本方案进一步研究的部分 |
|---|---|---|
| [SHIFT](https://arxiv.org/html/2604.09213) | pooled embedding 与 DiT 文本 attention 输出的均值差或 SVM 方向、分类门控 | 将候选文本方向的实际视觉干预响应纳入向量构造 |
| [RASteer](https://arxiv.org/html/2610.01969) | 保留方向的子空间投影及重叠校准 | 用生成图像的目标作用与无关变化构造代价矩阵 |
| [AdaVD](https://arxiv.org/html/2412.06143) | text Value 空间的正交分解与自适应力度 | Value 位置属于已有基础；新研究对象为离线效应提纯 |
| [ICM](https://arxiv.org/html/2604.06052) | 用生成图像标注激活，通过探针定位和 steering | 同状态正负可控文本扰动用于估计干预效应，图像结果标签本身属于已有技术 |
| [Semantic Surgery](https://arxiv.org/html/2510.22851) | 初始文本 embedding 算术和视觉反馈 | 离线估计 DiT text Value 的目标与无关视觉响应，部署固定 writer |

[Activation Flow](https://arxiv.org/abs/2609.32530) 和 [Principal Steering Subspaces](https://arxiv.org/abs/2609.33765) 已有响应反演与有限差分控制基的先例。小矩阵求解、有限差分和控制代价本身属于通用技术。此次查新支持与上述概念擦除方案的具体机制区分，完整的新颖性判断还需围绕这一具体组合继续核查。

拟验证的论文主张是：**通过同 prompt 同 seed 的 text Value 正负干预，离线估计概念作用与附带视觉变化，并据此提纯统计 steering 向量，改善 DiT 概念擦除的擦除—保持权衡。**
