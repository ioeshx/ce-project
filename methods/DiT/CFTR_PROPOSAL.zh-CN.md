# CFTR：反事实轨迹回填擦除

日期：2026-10-25。工作名：**Counterfactual Trajectory Restoration（CFTR）**。

这是替代 CFG-PTE 的研究提案。当前完成的是方法设计、相关工作核对和实验方案，尚未运行真实 DiT 实验。方法不训练生成器、探针、控制器、adapter 或软提示，也不进行逐样本梯度优化；代价转移到推理时的少量候选续程。

## 1. 核心想法

**先生成一个不含待擦除概念的反事实版本，再尝试把原本想保留的内容从原轨迹搬回来。每搬一次，都让模型真正生成到终点，检查目标是否重新出现、非目标内容是否恢复。只有通过检查的回填才被接受。**

例如原提示是“Snoopy 和一只金毛犬坐在海边”。改写提示为“一个普通卡通犬角色和一只金毛犬坐在海边”，可能去掉 Snoopy，却同时改变金毛、海浪和构图。CFTR 用原始轨迹的局部 latent 恢复这些内容。如果某一块回填会让 Snoopy 再次出现，就拒绝它或拆成更小的区域测试。

这里的“回填”发生在中间采样状态，之后继续用正常 flow 采样器生成；最终图像由生成器完成。方法不要求模型语义位于线性子空间，也不要求真实轨迹严格为直线。

第一版优先研究具有空间位置的概念：角色、身份、对象及局部视觉属性。全局艺术风格可以作为扩展，但不能预先假定也有同样的局部保留收益。

## 2. 研究问题与相关工作的启发

有三个可测量的问题支撑这条路线：

1. **提示改写造成的附带变化，有多少能从原轨迹中恢复？** 擦除后的普通狗、背景或共现物体发生变化，不代表这些变化都是去掉 Snoopy 所必需的。原轨迹是本次生成的内容参考。
2. **看起来属于非目标区域的信息，是否仍会使目标重新出现？** 图像区域、latent 空间位置和语义的对应并不精确。用一次实际回填与续程验证这一点，避免把分割掩码直接解释成“可以安全保留的全部信息”。
3. **多个回填区域之间是否存在组合效应？** A 单独恢复、B 单独恢复都通过，并不能保证 A+B 也通过。因此每次测试都基于当前已经接受的区域集合。

这些是需要在 FLUX / SD3.5 上验证的研究假设，不是已经发现的实验事实。

相关工作给出的背景包括：ARCE 评测了额外视觉上下文引起的概念恢复；UVR 分析了语义传播；PCI 研究了时间上的概念可插入性及删除行为。这些工作支持研究中间状态和上下文，但没有直接证明本方案的有效性。

特别是 [PCI](https://arxiv.org/html/2512.08486) 已经采用中途切换提示研究概念时机，其附录 A.4 讨论删除与锁定。因此，**“概念有关键时间窗口”“换提示晚了可能删不掉”不作为本方法的新发现**。该附录的删除曲线示例主要是 SD2.1 / SDXL；本文仍需独立验证 flow DiT 上的回填行为。

## 3. 输入、依赖与任务定义

输入为原提示 `p`、待擦除概念 `c`、随机种子，以及保留意图。保留意图可以直接从原提示中删去目标身份得到，例如保留海滩、金毛、坐姿和两主体关系。

预先确定目标的处理方式：删除对象、替换身份、还是替换某一属性。三者的保留要求不同；擦除 Snoopy 身份时可以保留普通狗，擦除“狗”类别时则不能把普通狗当作成功输出。

所需组件：

- 冻结的 flow matching 文生图 DiT 和原生采样器。
- 冻结的概念判断器 `R_c(image)`，用于确认目标是否存在。可以是已有检测器或 VLM；不要求可微，不做概念专属训练。
- 保留评估：原提示中非目标实体／关系的检查，以及原图非目标区域的感知相似度。第一版使用简单、固定的规则，避免再引入学习到的奖励网络。
- 可选的冻结定位器。它只用于候选区域排序；不决定某块信息是否一定可以回填。没有定位器时仍可使用规则网格。

因此准确分类为：**无新增训练、无反向传播、使用冻结评估器的推理期概念抑制**。修改发生在本次采样状态，移除插件后基础模型仍保留原有能力。

## 4. 具体流程

### 4.1 保存原始结果及少量中间状态

用原提示完成正常采样，得到原图 `I_orig`。保存两个候选时间点的状态 `z_orig[k]`、对应 scheduler 索引及必要的求解器状态。

若原图被判断为不含目标，直接返回原图。这样正常输入不增加 DiT 前向调用，只增加一次图像评估。

第一版采用确定性、单步 Euler flow scheduler，便于直接从缓存状态继续。多步求解器需要正确恢复其历史量，不能只替换 latent 后沿用不匹配的求解器缓存。

### 4.2 生成反事实参考

构造保留非目标信息的提示 `p_keep`。用相同初始噪声、相同 scheduler、分辨率和 guidance 设置生成 `I_safe`，缓存对应的 `z_safe[k]`。

显式命名概念可以先使用人工确定的替换模板；隐式描述则需要冻结的文本或视觉语言模型识别语义并改写。方法评估必须包含后者，不能仅测试删掉目标名称。

`I_safe` 必须实际通过目标判断，才能作为回填起点。删掉名称后仍然出现目标的结果不能被当作有效 donor。

相同噪声能减少一个变化来源，但**不保证两条轨迹空间对齐**。保留对象的位置偏差需实际测量；严重失配会限制局部回填收益。

默认先尝试一个改写版本。扩展实验可允许第二个版本，但它的生成和选择成本需要计入，并给改写基线相同的候选集合。若没有合格参考，记录 donor failure，不能把这类样本从总成功率的分母移除。

### 4.3 一次局部状态回填

令 `M` 表示已决定从原轨迹恢复的空间区域。对于同一个采样时间点 `k`，构造：

\[
z_k(M)=M\odot z_k^{\mathrm{orig}}+(1-M)\odot z_k^{\mathrm{safe}}.
\]

`M=0` 表示从反事实轨迹继续；`M=1` 的位置使用原轨迹状态。各 latent 通道使用同一个空间掩码。候选回填后，使用 `p_keep` 和正常采样器完成剩余步骤。

这是第一版唯一的生成干预。不做速度差投影、attention 修改或语义向量注入。也不在后续每一步强行钉住原背景：是否恢复成功，由最终输出决定。标准掩码混合本身是已有操作，不作为独立创新。

实现时应在模型 VAE 的空间 latent 网格上定义区域。FLUX 若使用 packed latent，需要正确映射空间坐标和打包索引；这不要求访问 DiT 内部的注意力头或特定 block。

### 4.4 按组合效果接受或拒绝回填

从空回填集合开始，当前结果就是已通过检查的 `I_safe`。将原图划分成较大的区域，优先尝试与目标无直接重叠、且在反事实图中变化较大的区域。

对于候选块 `B`：

1. 在当前已接受的掩码上加入 `B`。
2. **重新从同一对缓存状态构造混合 latent**，完成剩余采样。
3. 检查最终图像的目标分数、保留实体／关系和非目标区域相似度。
4. 目标仍低于阈值、保留确有改善且没有明显质量退化时，接受该块。
5. 否则保留上一次通过检查的结果；较大的失败块可拆分后再试。

候选不以自己的上一张终点图重新加噪，避免逐轮编码／加噪造成额外漂移。每次都从相同时间的源／反事实缓存构造状态，便于解释具体改动。

回填评分只衡量需要保留的内容，不奖励恢复目标身份本身。例如不能用整张图的相似度单独决定是否接受，以免把 Snoopy 恢复得更像当作保留提升。

必须逐次检查**已接受区域与新区域的组合**。不能先独立评分全部块，再把所有“安全块”一次性合并。即使逐次验收也不表示找到了全局最优区域集合；搜索顺序和预算需要消融。

### 4.5 有限预算内比较少数时间点

先比较两个中间 checkpoint，例如按采样步进度约 50% 和 75% 选取，并记录它们真实的 sigma / timestep。它们是起始实验设置，不是跨模型通用的概念时机。

早些回填给模型更多重整空间，晚些回填的续程成本较低；哪一种更有效由最终输出决定。不假设风险或保留对时间单调，也不采用依赖单调性的二分查找。

不同时间点维护各自的已接受掩码与结果。在统一的候选续程预算内，返回保留效果最好的合格结果。时间搜索是方法的预算分配部分，不单独包装为第三项重大创新。

## 5. 最小算法

```text
输入：原提示 p、概念 c、seed、候选时间 K、总续程预算 B

I_orig, Z_orig = 原生采样(p, seed, 缓存 K)
若目标判断通过：返回 I_orig

p_keep = 保留非目标意图的提示改写(p, c)
I_safe, Z_safe = 原生采样(p_keep, seed, 缓存 K)
若 I_safe 未通过目标判断：结束本次擦除尝试，记录 donor failure，不进入回填

best = I_safe
对每个 k 初始化：M[k] = 空，accepted[k] = I_safe
建立由粗到细的候选区域队列

在全局续程预算 B 内：
    选择时间 k 和区域 B_region
    M_trial = M[k] 与 B_region 的并集
    z_trial = M_trial * Z_orig[k] + (1-M_trial) * Z_safe[k]
    I_trial = 原生续程(z_trial, k, p_keep)

    若目标检查通过、保留改善且质量检查通过：
        M[k] = M_trial
        accepted[k] = I_trial
        更新 best
    否则：
        保持 M[k] 和 accepted[k]
        预算允许时拆分失败区域

返回 best，并保存各次尝试及总成本
```

有限搜索始终保留已经验收的候选，只能保证不会主动接受一个已被当前判断器判为失败的结果。这个简单程序性质不等于真实语义擦除保证；论文结果必须用独立评估器复核。

## 6. 可主张的两项方法贡献

### A. 以反事实轨迹为起点的内容恢复式擦除

把问题具体化为：已经取得无目标输出后，怎样通过原始生成状态恢复被改写损伤的非目标内容？源轨迹不仅用于算损失，也作为每个候选的实际内容来源。

需要证明：相同改写提示和相同 donor 下，回填能显著恢复共现实体、关系和背景，同时维持目标抑制；收益不能仅来自更好的 prompt rewriting。

### B. 按最终生成行为验证的组合回填搜索

每块 latent 是否保留，由它加入当前集合后的完整生成结果决定。分割和显著性只提供候选顺序；失败后拆分使保留粒度由实际效果决定。

需要证明：这种组合验收在相同候选预算下，优于固定区域拼接、独立块评分后合并、随机掩码搜索；并能识别一部分“视觉上无关、回填后却使目标重现”的状态区域。

机制分析可以展示时空回填图、区域组合效应、搜索预算曲线，但不把已有的 mask mixing、共享 seed、粗到细搜索或时间窗口分别计作新算法。

**论文价值取决于这两项增量是否成立。如果只有“改提示＋固定 mask 拼接”有效，而组合回填不增加收益，这个方案的创新性就不足。**

## 7. 与用户指定的五篇论文的区别

| 工作 | 主要机制 | CFTR 的差异 |
|---|---|---|
| [Semantic Steering](https://arxiv.org/html/2608.12829) | 提取并注入内部文本分支表示差 | 在采样状态上回填；不提取或注入内部 steering vector |
| [DVE](https://arxiv.org/html/2602.01089) | 构造条件速度差并做选择性投影纠正 | 不构造概念速度方向；候选操作是源／反事实 latent 的局部替换 |
| [ARCE](https://openaccess.thecvf.com/content/CVPR2026F/html/Schechter_Concept_Erasure_via_Attention_Redirection_CVPRF_2026_paper.html) | 训练 eraser token 的 key／尺度，重定向注意力 | 无 eraser token 和训练；判定回填后概念是否复现 |
| [UVR](https://proceedings.mlr.press/v306/yang26an.html) | 定位不安全 patches 并限制 MM-Attn 信息流 | 不检查或调制 attention；在实际续程输出上验收源内容的恢复 |
| [VESFlow](https://arxiv.org/html/2606.23267v2) | 用安全评分梯度编辑 velocity | 判断器只用于接受／拒绝候选，不求梯度，不推导安全后验速度 |

ARCE 的本轮在线 CVF 入口返回 403；机制核对使用已下载正式版 `papers/inference_plugins_20261023/text/ARCE.txt`，尤其 §3.2–3.3。其余四篇本轮读取了原文／官方论文页。

## 8. 更接近、必须认真比较的已有工作

避开上述五篇不等于完成创新性核对。更接近的先例是图像编辑与局部状态修复：

- [SAM-Flow](https://arxiv.org/html/2606.06228)：根据 source/scout 的 token-grounded attention 定位编辑区域，局部施加差分速度，并在各步锚定源图背景。本方案应比较其直接做相同概念替换的版本。CFTR 的候选区别是实际输出驱动的组合回填搜索，而非“有两个轨迹、局部 mask、保留背景”。
- [Concept Replacer](https://openaccess.thecvf.com/content/CVPR2025/papers/Zhang_Concept_Replacer_Replacing_Sensitive_Concepts_in_Diffusion_Models_via_Precision_CVPR_2025_paper.pdf)：少样本训练定位器，使用双提示交叉注意力替换目标。局部替换并保留周围内容已有先例；本方案不应将任务目标本身当作新贡献。
- [M-ErasureBench / IREECE](https://openaccess.thecvf.com/content/WACV2026/papers/Weng_M-ErasureBench_A_Comprehensive_Multimodal_Evaluation_Benchmark_for_Concept_Erasure_in_WACV_2026_paper.pdf)：利用注意力定位并破坏目标区域 latent，增强已擦除模型的鲁棒性。“局部重置 latent”已有先例；其原始系统依赖擦除模型，比较时应披露这一条件。
- [PCI](https://arxiv.org/html/2512.08486)：已研究提示切换和概念时间动态，必须包含单纯时间自适应提示切换的基线。
- [Iterative Partial Refinement](https://arxiv.org/html/2605.19317)：对部分区域重新加噪和生成，用于具备区域混合噪声训练的 sequential diffusion。该能力不能直接假定在普通 FLUX / SD3 中成立。CFTR 的混合项来自同一噪声水平的真实采样状态，仍需检验局部拼接产生的分布偏移。

本轮没有核实到与全部 CFTR 步骤完全相同的方案，但这不能证明“首次”。尤其要通过同预算实验排除通用编辑与候选搜索已经足够的可能。

## 9. 与 flow matching / CFG 的关系

直接使用模型原生的 velocity 与 scheduler 续程，核心方法不依赖 probability-flow 分布建模。它优先在 flow DiT 上开发，但不以“理论上不能用于扩散模型”作为贡献。

SD3.5 的真实两分支 CFG，以及 FLUX.1-dev 的原生 guidance embedding，都能用于两条参考轨迹及候选续程。各阶段使用同一套 guidance 配置。

这里不把 FLUX 原生 guidance embedding 当作真实 CFG，也不强制添加额外无条件分支。若研究真实 CFG 强度的影响，应单独实验并计入分支成本。

第一版优先 FLUX.1-dev 和 SD3.5-Large；bf16、512×512，FLUX.1-dev 使用此前确定的 28 步。四步 schnell 可后续测试，但它可供回填的 checkpoint 和续程长度很少，不预先声称同等有效。

## 10. 成本与实现规模

无需离线训练。工程上包括：保存采样状态、恢复 scheduler、提示改写、一次 latent 混合、现成评估器和一个有限候选循环。无需训练数据管线、控制器蒸馏或 DiT 反向传播。

但 **train-free 不等于低推理成本**。设每条参考轨迹 N 步，第 j 次试验从第 k_j 步结束后的状态继续：

\[
\text{采样步调用数}=2N+\sum_{j=1}^{B}(N-k_j).
\]

例如 N=28，原始和反事实各一条，六次候选都从第 14 步续程，总计 140 次采样步调用，是基础生成的 5 倍。这是预算算例，不是实测时延。实际还包括 VAE 解码、判断器和提示处理。

若每个采样步需要两次 CFG 分支计算，上式还需按实际模型前向数计费；批处理不会使两个分支变成一次计算量。候选 donor 增多也需额外计费。

因此本方案适合“用更多推理计算换取精确保留”的研究定位。额外计算带来的收益必须胜过相同预算的 prompt rewriting + best-of-N。

## 11. 最先验证的实验

### 11.1 小规模可行性实验

先用 FLUX.1-dev，选三个局部目标概念，每个十个含共现物体／背景的提示、三个种子，共 90 个请求。提示中加入目标别名和描述性表达。该规模用于判断机制是否值得继续，不是最终论文规模。

先固定同一个 `p_keep` 和 donor，比四种设置：

1. 直接返回改写提示生成的 donor。
2. 固定目标框之外的区域一次回填。
3. 各块独立测量后合并回填。
4. CFTR 的逐次组合验收与失败块细分。

对齐候选续程预算。区域检测不准的影响可另设人工标注 mask 的 oracle 对照，但不能把 oracle 当作主方法结果。

最先回答两个问题：回填是否改善非目标内容？组合验收是否比固定 mask 和独立评分明显更可靠？没有这两个增量就不扩建复杂模块。

### 11.2 主实验与指标

- **目标抑制**：目标出现率、显式／隐式提示、攻击提示。搜索用判断器和最终评测器分开。
- **共现内容保留**：非目标实体与关系准确率、目标区域之外的 LPIPS / DINO 相似度、人物或对象布局偏差。
- **近邻概念保留**：擦除特定角色时仍能生成普通狗及其他角色；擦除某身份时仍能生成人物。
- **一般生成能力**：目标无关的 COCO 子集上质量与文本一致性；同时报告误触发率。目标相关 caption 单独计，不把“目标没生成导致 CLIP 下降”算作无关内容损伤。
- **代价**：总 DiT NFE、时延、解码次数、评估器次数、峰值显存、有效 donor 比例、预算耗尽比例。
- **整体统计**：所有请求均进入分母；同时给 donor 成功子集的条件分析。未修改原图、改写 donor、接受回填、失败请求分别记账。

对比：五篇指定论文中可复现的 inference 方法；prompt rewriting；同预算 best-of-N；PCI 式提示切换；SAM-Flow 等局部编辑；固定 mask 回填。ARCE 等训练方法作为另一资源类别报告，不将其训练成本和本方法搜索成本混为一谈。

同时比较“相同目标抑制率下的保留”和“相同计算预算下的综合表现”。不能只用更多生成次数换一个更好样本后宣称机制优越。

### 11.3 有解释力的可视化

1. 原图 → donor → 接受的几次回填 → 最终图，标出恢复的内容。
2. 区域 × 回填时刻的目标复现热图；由实际续程结果填值。
3. A、B、A+B 回填的对照，检验区域组合效应。
4. 搜索预算 B 与保留收益／目标出现率／时延的曲线。
5. 固定 mask、独立评分、组合验收在同风险水平下的对照。
6. 按源／donor 空间失配程度分组，展示何时局部回填失效。

## 12. 关键失败条件

1. **donor 获取不稳定**：提示改写仍产生目标，后续恢复阶段没有合格起点。
2. **空间不对齐或 latent 混合破坏结构**：相同 seed 不足以保证可回填；完整续程也未必消除伪影。
3. **评估器误判**：搜索可能保留评估器未识别的目标细节，需要独立评估与人工抽检。
4. **全局概念缺少局部可恢复区域**：艺术风格等任务可能只能保留很少源信息。
5. **计算增量不划算**：如果同预算通用编辑或 best-of-N 已取得同等结果，应缩小主张或放弃这条路线。

上述失败模式都能通过直接实验检验，不需要为它们再建立复杂概率模型。
