# CRA：因果标定的残差写入许可

**Counterfactual Residual Admission for Concept Erasure in Flow-Matching DiTs**

日期：2026-10-29。本文是依据本轮要求独立提出的研究方案，尚未实施实验。本轮未读取 `methods/DiT/` 中的既有方法文件；相关工作来自 `papers/` 的论文清单、重点原文，以及在线一手来源。

## 1. 核心方法

**在少数 DiT blocks 的图像侧残差出口，控制当前生成过程新写入的信息量。离线实际比较几种写入强度对最终图像的影响，训练一个小型结果预测器；在线据此选择是否允许这段残差更新。**

方法包含两个轻量功能：

- **定位器 D**：从当前图像 token 与原生残差中，识别哪些位置正在形成已配置的目标概念。
- **动作结果预测器 Q**：预测在一个短采样窗口内采用“正常写入、减半写入、阻止写入”后，最终出现各目标概念的概率，以及损伤其他内容的风险。

论文的核心贡献放在**用真实干预结果标定残差写入决策**。检测到概念只说明“这里有相关信息”；对同一生成状态进行不同写入干预，并继续生成到终点，才能判断“抑制这些更新是否有助于擦除”。

整体属于**冻结生成主干、少量训练辅助模块、推理期执行门控**的路线。全部训练发生在缓存特征上，DiT 不参与反向传播。

## 2. 干预对象与执行规则

### 2.1 只需一个残差操作

在指定 block 中，令 `h_i` 为第 i 个图像 token 的输入，`r_i` 为该 block 原本计算出的完整残差更新，包括其原有 modulation gate。对选中位置采用：

\[
h_i^{\mathrm{out}}
=h_i+\bigl[1-(1-a)m_i\bigr]r_i,
\qquad a\in\{1,\tfrac12,0\}.
\]

其中 `m_i=1` 表示定位器认为该位置涉及至少一个目标概念。`a=1` 正常写入，`a=1/2` 减半，`a=0` 保留当前 token 输入、阻止本次 block 更新。未选中位置的本次更新按原样执行。

**实际缩放的是本次样本自身的残差。**它无需预存一个安全替代向量。抑制后的具体画面由原模型根据当前状态和剩余提示继续生成。

这个操作控制本次写入量；已经存在于 `h_i` 中的概念信息不会自动消失。因此，干预位置必须通过最终输出上的实验筛选，不能仅凭激活大小确定。

### 2.2 动作作用于短窗口

初版设置至多两个采样窗口、全模型共 2–4 个干预 blocks。窗口可包含数个连续采样步，具体位置从标定数据中选择。

在每个窗口的第一个干预出口，Q 同时预测三种动作的结果，选定一个 `a`。该窗口内所有指定出口复用这个强度，D 则在各出口根据当前状态重新定位。下一窗口重新选择强度。

这样，离线比较的动作与在线执行的动作具有相同含义，也能测量一段持续抑制的作用，避免把单次微小扰动的效果误当成整段控制的效果。

### 2.3 为什么能接入 flow-matching DiT

flow matching 模型通过 DiT 预测 velocity，再由原生采样器推进状态。CRA 在 velocity 网络内部改变少数残差写入，随后照常输出 velocity、执行原生采样步骤；无需针对旧式噪声预测模型推导转换公式。

FLUX 的官方实现中，双流块分别对 attention 和 MLP 输出做残差相加，单流块把 attention 与 MLP 结果融合后做残差相加。这提供了明确的出口接口。[FLUX 官方代码](https://github.com/black-forest-labs/flux/blob/main/src/flux/modules/layers.py)

- **双流块**：正常计算完整 block，以图像输出与图像输入之差作为 `r`，在 block 出口执行一次门控。
- **单流块**：在融合残差出口，仅对图像 token 行执行门控。

两种情形都可保留原生 attention kernel。文本行保留该 block 的原生输出；后续层会正常接收已改变的图像状态。

建议首轮使用 FLUX.1-dev，再在另一种 flow-matching DiT 上单独标定和验证。跨模型、采样配置的效果需要实测。[Rectified-flow Transformer 架构依据](https://arxiv.org/abs/2403.03206)

## 3. 离线准备：把干预结果编译成小模块

### 第一步：准备目标与保留数据

构建时明确待擦除集合，例如 `{Pikachu, nudity}`。每个概念准备三类提示：

1. 直接点名目标的提示。
2. 不出现目标名称、通过外观、场景或同义表达描述目标的提示。
3. 语义相近的保留提示，例如普通黄色动物、穿衣人物，以及共享背景或属性的正常场景。

对少量种子运行原模型，保存最终图像及候选位置的 `h、r、采样时间`。正负标签根据**最终实际生成内容**确定，避免把“提到目标”直接等同于“生成目标”。

对象、角色和局部属性使用离线检测或分割获得目标区域，再映射到图像 token 网格。该映射用于训练空间定位，是近似监督；早期 token 的语义位置是否可辨别仍需验证。全局风格使用图像级标签，单独评估其全局门控效果。

### 第二步：训练定位器，缩小候选范围

D 读取标准化后的当前 `h、r` 与时间信息，使用 32–64 维小瓶颈、浅层网络，输出每个图像 token 对所有目标的独立 sigmoid 分数。多概念可以同时激活。

按提示家族和种子划分训练、标定数据，检查在哪些时间与 blocks 上，目标可与邻近保留概念区分。先保留少量候选位置，再通过真实干预筛选。

DiT 内部表示可被轻量 probe 用于预测概念是否最终出现，已有概念遗漏研究提供了相关证据；其结果涉及文本 token，CRA 对图像残差的可预测性属于需要验证的新假设。[相关 probing 研究](https://arxiv.org/html/2605.14270v3)

### 第三步：对同一状态实施三种真实干预

在候选窗口入口保存完整生成状态。固定 prompt、种子及后续随机数，分别执行 `a=1、1/2、0`，每条分支都继续到最终图像。

每个样本保存：

| 保存内容 | 作用 |
| --- | --- |
| 入口 `h、r` 的低维统计、定位分数、掩码面积、时间 | 在线决策可获得的输入 |
| 采用的动作 `a` | 被比较的写入强度 |
| 最终各目标是否出现 | 动作对应的概念结果标签 |
| 非目标内容及画面质量是否达标 | 动作对应的保留标签 |

保留标签同时考虑非目标语义与图像质量。可以在离线阶段从原提示提取保留描述；局部目标还可比较目标区域之外的背景和布局。这样能区分“目标被擦除”和“画面整体失效”。保留描述仅供离线评价，不作为替代生成条件。

这里的三条分支全部保留同一个原 prompt。被改变的变量只有残差写入动作，从而获得该动作在这些样本上的干预证据。

### 第四步：训练动作结果预测器 Q

Q 输入窗口入口状态摘要和候选动作，输出：

- `p_1(a), …, p_K(a)`：执行该动作后，最终出现各目标概念的预测概率。
- `d(a)`：执行该动作后，非目标保留或画面质量不达标的预测概率。

输入使用 D 的低维特征及其 mean/max 汇聚、残差范数和掩码面积等统计，Q 使用小型 MLP。通过普通监督学习拟合实际分支的标签，不对生成过程求梯度。

有两个窗口时，先标定后一个窗口；标定前一个窗口的分支随后执行已经确定的后窗口策略。这样，Q 学习的后续执行流程与部署流程保持一致。

最后运行一轮完整闭环补样，覆盖前面门控改变后、后面窗口实际遇到的状态，并更新 Q 与阈值。此轮计入离线预算。

### 第五步：导出部署包

部署包包含：D、Q 的权重，各目标的判定阈值，统一选定的 blocks 与时间窗口，以及保留阈值和动作选择权重。

**目标名称只在构建与标注时使用，部署后的目标集合由模块权重及输出头固定。全流程无需指定 anchor 概念。**

## 4. 在线生成：只输入普通 prompt

接口可以保持为：

```text
image = generate(prompt, seed)
```

运行时既不传入待擦除概念，也不检索一条目标或 anchor 提示。对生成内容的判断来自当前正常前向产生的内部状态。

执行流程如下：

1. 原模型照常编码 prompt、计算各 block。
2. 到达指定出口时，D 从当前图像状态与残差定位目标相关位置。
3. 在窗口入口，Q 一次批量评估三个动作对所有已配置概念及保留质量的影响。
4. 若存在预测满足各概念风险阈值与保留阈值的动作，选择其中写入量最大的动作；否则，用预先固定的“最大概念风险超标量＋保留损伤惩罚”选择分数最低的动作。后一种情况不能视为已满足擦除要求。
5. 在该窗口内按选定强度执行门控，并动态更新位置；窗口外执行原模型。
6. 原生 velocity 预测和采样器继续运行，最后正常解码图像。

```text
普通 prompt → 原生 DiT 前向 → 取得当前 h、r
                              ↓
                         D 定位目标区域
                              ↓
            窗口入口：Q 预测三个动作的最终结果
                              ↓
                 选择写入强度并执行残差门控
                              ↓
                    原生 velocity 与采样器
```

在线计算包含小模块前向与残差缩放；反事实续采样、视觉标注和保留评价均已移到离线阶段。

## 5. 单概念与多概念

单概念时，D 和 Q 各有一个概念输出头。

多概念时，D 同时检测所有已配置概念，将超过各自阈值的位置取并集，形成当前掩码。Q 对同一个候选动作输出全部概念的结果预测，联合决定该窗口的一个写入强度。

例如，同一画面包含两个目标角色，两个区域都可进入掩码；若普通小动物也出现在旁边，它能否保留由定位精度和最终保留评价检验。重叠区域只执行一次门控，动作候选数始终为三。

概念数增加带来的在线增长主要是小模块的输出头。DiT 分支数保持不变。但离线成本随概念覆盖增长，多个概念也可能需要不同的有效干预位置。初版应固定全模型 2–4 个 blocks 的预算，并在少量混合提示上联合标定，检验 1、5、10 概念设置；不能直接外推到任意规模。

## 6. 成本与适用条件

### 建议的首轮预算

下列数字是实施起点与预算约束，尚未验证足以取得所需效果。

| 项目 | 单概念初始预算 |
| --- | --- |
| 基础数据 | 24 条目标提示、24 条邻近保留提示，各 2 个种子，共 96 次完整生成 |
| 候选位置筛选 | 至多 8 个入口状态，各增加 2 条干预续采样，共 16 条 |
| 动作结果标定 | 至多 48 个入口状态，各执行 3 个动作，共 144 条续采样 |
| 一轮闭环补样 | 至多 8 次当前策略的完整生成以取得入口，再各执行 3 个动作，共 24 条续采样 |
| 上述生成计算上界 | 288 次完整生成等价量；已计入闭环入口获取，续采样实际只执行剩余部分 |

上述预算要求其余入口来自已计入的轨迹并可复用缓存；新增入口生成另行计入。多概念混合提示的联合标定另外记账；正式评测与标签生成成本也单独报告。冻结主干并不意味着离线采样免费。

辅助网络建议从总计约百万参数以内起步，实际参数量取决于隐藏维度和出口数量。训练只读取缓存，预计比反向传播经过 DiT 的训练轻；论文须报告实际训练时间、标注成本和总 DiT 调用次数。

### 在线成本

相同采样配置下，CRA **不增加完整 DiT 的函数求值次数（NFE）**。新增计算是指定出口上的低维特征提取、定位、小型动作预测，以及图像残差缩放，无需显式展开完整 attention map。

应实际测量端到端延迟和峰值显存。可以将延迟增幅不超过 5% 设为工程目标，不能在实验前声称已达到。

有外部 CFG 的模型需要按其完整原生生成流程重新标定。可对原有条件与无条件分支使用同一组门控，Q 读取两者的低维摘要；这不会新增 CFG 分支。FLUX.1-dev 的 guidance embedding 接口与外部 CFG 分开实现。

### 两个决定方案是否成立的条件

1. **检测与可控制时间有重叠**：在目标已经可被内部状态辨别、但还来得及改变最终结果时，存在有效的干预窗口。
2. **残差有可用的选择性**：少数出口上的局部衰减能降低目标出现率，同时保留其他内容；Q 能预测这种收益与代价。

这两点均通过真实续采样验证。目标信息可能早已写入输入状态，也可能与人物结构、物体形状高度共享；此时单纯衰减更新可能效果有限。部署包也依赖标定时的模型与采样配置。方法定位是推理期概念抑制，持续效果依赖模块处于启用状态。

## 7. 与已有路线的实质区别

本轮比对了 `papers/dit_primary_expanded_20261024/results.json`、`papers/inference_plugins_20261023/results.json`、`papers/inference_preprints_20261023/results.json` 和 `papers/dit_transfer_additions_20261025/results.json`，重点核读相近机制，并补查了下列一手来源。

| 相关路线 | 已有核心操作 | CRA 的操作与训练信号 |
| --- | --- | --- |
| [DVE](https://arxiv.org/html/2602.01089)、[CALM](https://arxiv.org/html/2610.02300)、[CRG](https://proceedings.mlr.press/v306/choi26m.html) | 条件预测差、方向纠正或自适应负引导 | 以同一 prompt 下的残差写入强度为动作，用最终输出结果监督决策 |
| [Semantic Steering](https://arxiv.org/html/2608.12829)、[SHIFT](https://arxiv.org/html/2604.09213) | 构造并注入概念 steering 向量 | 缩放本次样本的原生残差，无需存储替代语义方向 |
| SafeRoPE、Uni-AdaVD、DP/OCE 等 | 对 Q/K、value 或其他表示进行子空间旋转、投影或分解 | 有限标量写入动作，保持该残差的方向 |
| [ActErase](https://arxiv.org/html/2601.00267v2)、SAE 类方法、[BLOCK](https://arxiv.org/html/2606.25548) | 参考激活修补、稀疏特征停用或重建 | 保留当前输入状态，并根据实测干预收益限制新增更新 |
| [Minimalist](https://arxiv.org/html/2507.13386) | 通过生成轨迹优化固定神经元掩码 | 缓存特征上的小型预测器训练，在线状态决定空间位置与动作 |
| [CPE](https://proceedings.iclr.cc/paper_files/paper/2025/hash/f5aed2ae28e51be52c6bcdb2e6f0a8da-Abstract-Conference.html) | 对文本注意力投影添加门控低秩擦除改动 | 图像 block 出口上的原生残差缩放，由真实动作结果监督 |
| [IAM](https://arxiv.org/html/2607.14945v2) | 检测内部风险后，在推理时优化 attention activations | 将候选干预的结果预测移到离线学习，在线执行有限动作 |
| [UVR](https://proceedings.mlr.press/v306/yang26an.html) | 利用不安全视觉 anchors 定位，再调制 attention 信息流并注入噪声 | 图像 block 残差出口控制，以干预后的终点结果训练动作选择器 |
| EraseAnything/GEM/BEM、FlowErase-RL/OPD、Mosaic、Z-Erase | LoRA、生成器优化、蒸馏或多个擦除器的速度融合 | 仅训练定位和结果预测模块，在线运行一条原生生成流程 |

**最接近的比较对象是 UVR、IAM 和 CPE。**空间定位、风险检测、门控均已有先例。CRA 应主张的新增机制是“把短窗口残差干预的终点结果编译为在线写入决策”，而不能把一般性的风险门控当作新贡献。它是否有论文价值，取决于这项结果监督能否在相同擦除强度下改善保留或计算成本。

## 8. 最小验证路线

首先在一个 IP 角色与一个局部属性概念上验证，再扩展多概念。

1. **验证可控制性**：使用真实终点标签，在相同入口的三条分支中选最好动作，得到候选动作的经验上限。如果这个上限仍没有合适的擦除—保留折中，先否定当前动作设计。
2. **验证结果预测是否有用**：比较完整 CRA 与“同一 D、同一出口、固定减半或固定阻止”的门控。两者差异直接检验 Q 的贡献。
3. **验证自动判断**：分别测试显式点名、无名称描述、正常邻近概念，以及模型原本未生成目标的提示；报告检出、漏检和误干预。
4. **验证多概念组合**：区分“部署多个概念、单图出现一个”和“同图出现多个”，报告各概念残留、联合残留及正常内容保留。
5. **验证实际代价**：统一模型、种子与采样步数，比较相近 DiT 方法的擦除—保留曲线，同时报告离线计算、在线 NFE、延迟与显存。

最终评测使用独立于离线标签来源的检测或人工判断，排查只降低某个判别器分数、目标仍在画面中的情况。数据拆分以提示家族与种子为单位，同一轨迹中的大量 token 不作为独立测试样本。

可用于论文的方法表述：

> 我们提出一种面向 flow-matching DiT 的概念抑制方法，通过离线反事实生成，学习短采样窗口内不同残差写入强度对目标出现与内容保留的影响。推理时，轻量模块从当前图像状态识别目标相关区域，并选择原生残差的写入强度，从而在无需额外概念条件分支的单次生成流程中执行单概念或多概念抑制。
